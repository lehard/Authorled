# Бизнес-интент: рабочее место автора — проекты, редактор сценария и чат с агентом

Статус: интент; OpenSpec change по нему не создаём (решение владельца 2026-10-26). Формат совместим с `/opsx:propose`, если change понадобится. Владелец: lehard. Обновлено: 2026-10-26.
Решения по стеку зафиксированы в `openspec/context/ADR/ADR-004-frontend-stack.md`; архитектурные рамки — `openspec/context/03-architecture.md`, ADR-001, ADR-002.

## Why

Системе для сторителлинга нужны три разнородные функции в одном интерфейсе:
- управление проектами (создание документов, иерархия, статусы Д1–Д22);
- профессиональный редактор сценария в стандарте «американка» с инлайн-комментариями и предложениями правок;
- интерактивный чат с ИИ-агентом.

Единого open-source решения с готовым чатом, WYSIWYG-редактором сценария и панелью проектов нет. Монолитные платформы (например, Screenplay Studio) тянут свою логику и хранение и конфликтуют с архитектурой: источник истины — бэкенд, фронтенд — тонкий клиент без своей БД (ADR-001). Простые текстовые редакторы не дают автоматического форматирования и структуры текста по сценам, нужной для версий и поиска.

## What Changes

Модульная сборка (best-of-breed) на React из трёх open-source компонентов поверх API бэкенда, в одной дизайн-системе:

1. **Управление проектами** — Refine: каркас, роутинг, списки и формы проектов и документов, админка.
2. **Редактор сценария** — `@plotwell/editor` (MIT, ProseMirror): ввод и форматирование сценария, пагинация, импорт и экспорт FDX, Fountain, PDF. Поверх него — свои плагины:
   - инлайн-комментарии к фрагменту текста;
   - предложения правок от агента с кнопками «Принять» и «Отклонить».
3. **Чат с агентом** — CopilotKit v2, подключённый к AgentOS через AG-UI.
4. **Дизайн-система** — shadcn/ui на Tailwind CSS: один набор CSS-переменных (цвета, радиусы, шрифты, светлая и тёмная темы) для shadcn, CopilotKit и редактора.

На стороне бэкенда (этот репозиторий) — контракты, без которых фронтенд не работает:
- сохранение фрагмента сценария (сцены) как новой версии;
- комментарии к фрагменту: создать, ответить, закрыть, список;
- предложения правок агента: создать (агент), принять или отклонить (автор);
- после сохранения — пересчёт поискового индекса через очередь Agno.

## Обоснование выбора

**`@plotwell/editor`:**
- Встраиваемый компонент без своего бэкенда и базы: содержимое передаётся в редактор, изменения отдаются через `onChange`; хранение и версии остаются на бэкенде.
- Стандарт «американка» из коробки: сцена, действие, персонаж, реплика, ремарка, переход; умный Enter и Tab, номера сцен, живая пагинация.
- Открытый `EditorView` и свои плагины ProseMirror (`extraPlugins`): правки, комментарии и предложения добавляются без форка.
- Версионирование на уровне фрагментов (сцен), а не целых файлов, ложится на структуру документа редактора.

**CopilotKit:** чат со стримингом и управлением промптом с нуля — недели работы; готовые компоненты подключаются к AgentOS через AG-UI за часы. v2 построен на Tailwind и shadcn, стилизуется нашими токенами.

**Refine:** берёт на себя CRUD-интерфейсы проектов и документов; есть официальная интеграция с shadcn/ui (компоненты из реестра `ui.refine.dev` ставятся в код проекта).

**shadcn/ui + Tailwind:** единственная система, в которую все три компонента ложатся без второй системы стилей.

Отклонённые варианты — в ADR-004 (screenplay-editor, `@sutrata/editor`, OpenDraft, Fairfax; Ant Design, MUI, Mantine).

## Scope

- Контракты бэкенда для фрагментов сценария, комментариев и предложений правок (маршруты через `base_app`, ADR-002), с проверкой доступа к проекту.
- Пересчёт индекса после сохранения через durable-очередь Agno.
- Описание контракта для фронтенда в OpenAPI.
- Требования к фронтенду (`authorled-web`) как спецификация поведения: редактор, комментарии, предложения, чат, тема.

## Non-goals

- Реализация фронтенда в этом репозитории: код интерфейса живёт в `authorled-web`.
- Совместная правка в реальном времени (Yjs) — отдельный change.
- Авторизация через Authentik — change `auth-module`.
- Свой редактор с нуля или форк `@plotwell/editor` без необходимости.
- Утверждение документов и план пересмотра — отдельные changes ядра.

## Constraints (из контекст-пака)

- Фронтенд не хранит своих данных и не содержит продуктовой логики; источник истины — ядро бэкенда (инвариант 1, анти-паттерн 10).
- Сохранение правки — детерминированный маршрут API без LLM, а не вызов агента (анти-паттерн 7).
- Данные произведения — в ядре, не в Session State, таблицах или памяти Agno (анти-паттерн 8).
- Правка автора — новая версия фрагмента, история не теряется (инвариант 5).
- Векторный индекс строится из канона через очередь, не при каждом нажатии (анти-паттерны 9, 13).
- Предложения агента не меняют текст автора напрямую (инвариант 3); предложения правок и комментарии агент создаёт MCP-инструментами ядра (подтверждено владельцем).
- Каждый маршрут проверяет доступ к проекту (анти-паттерн 11).
- Без телеметрии CopilotKit и сборщика фронтенда (анти-паттерн 17).
- Без fallback: ошибка конфигурации — явный отказ.

## Acceptance criteria

- Автор пишет сцену в стандарте «американка» на русском языке; после паузы правка сохраняется на бэкенде как новая версия фрагмента.
- Автор выделяет текст и оставляет комментарий; комментарий виден у фрагмента после перезагрузки и не меняет текст сценария.
- Агент предлагает правку к фрагменту; она видна в тексте и в чате; «Принять» создаёт новую версию фрагмента, «Отклонить» оставляет текст без изменений.
- Чужой проект недоступен: маршруты фрагментов, комментариев и предложений отвечают 404 или 403.
- Импорт FDX и Fountain и экспорт в PDF сохраняют разметку элементов сценария, включая кириллицу.
- Светлая и тёмная темы и акцентный цвет задаются одним набором токенов для всех трёх компонентов.

## Risks

- `@plotwell/editor` молодой (beta, один релиз): фиксируем версию, готовы поддерживать форк; запасной вариант — расширения редактора из OpenDraft (MIT, Tiptap).
- Схема редактора фиксирована (метки только bold, italic, underline): комментарии и предложения — декорации с пересчётом позиций, а не метки в тексте.
- Шрифт по умолчанию Courier Prime, вероятно, без кириллицы: замена на моноширинный шрифт с кириллицей (кандидат Cousine) через `--pw-font`; проверить пагинацию (10 символов на дюйм).
- Ссылка «Powered by plotwell» включена по умолчанию: отключить `attribution: false`.

## Open Questions

- Intent Router из исходной формулировки интента отсутствует в контекст-паке и коде. Пока не нужен (решение владельца 2026-10-26); вернуться к вопросу позже.

## Изменения относительно исходной формулировки

Исходный текст интента расходился с контекст-паком; в этой редакции:
- «При каждом изменении текста React отправляет дельту в Agno Tool» → правка уходит в маршрут бэкенда по фрагменту с задержкой (анти-паттерн 7).
- «Agno обновляет вектор в Knowledge Base и Session State» → текст хранится в ядре, индекс пересчитывается из канона через очередь (анти-паттерны 8, 9, 13).
- «Agno остаётся единственным источником истины» → источник истины — ядро бэкенда поверх AgentOS (инвариант 1).
- Редактор screenplay-editor (MdSponx) заменён на `@plotwell/editor`: у первого нет лицензии, это приложение со своей Firebase, проект не развивается.
