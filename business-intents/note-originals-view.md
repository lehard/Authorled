# Бизнес-интент: оригинал и текст материала в заметке

Статус: решения согласованы с владельцем 2026-11-10; OpenSpec change `note-originals-view` реализован и архивирован 2026-11-10 (`openspec/changes/archive/2026-11-10-note-originals-view/`). Владелец: lehard. Обновлено: 2026-11-10.
Рамки: ADR-006 (заметки — узкое исключение из «только структурированные документы»), `business-intents/story-materials.md` (материал — это заметка с приложенным оригиналом), мастер-спеки `web/workspace` («Оригинал заметки», «Длинный материал для чтения»), `api/files` («Извлечение текста»), `api/stories`, `core/database`.

## Why

Загрузка файлов в заметки работает, но выглядит плохо, и за неё стыдно (владелец, 2026-11-10). Автору на экране показан текст, извлечённый для соавтора: PDF с разорванными строками, Markdown с `#` и `**`. Сам файл можно только скачать. Оригинала не видно, хотя автор загрузил PDF или DOCX, чтобы видеть именно их.

Что есть в коде (сверка 2026-11-10):
- Заметка из файла хранит извлечённый текст в `notes.body` и ссылку на оригинал (`files`, `file_contents`); извлечение в `agno/core/files.py` (`extract_text`, `_text_of_pdf`, `text_of_docx`).
- `web/src/screens/project/docs/NoteDoc.tsx`: карточка «Название», строка оригинала с «Скачать оригинал», под ней текст заметки на листе — поле правки или, при тексте длиннее 50 000 знаков, режим чтения.
- На экране текст прижат к левому краю листа без отступа, ширина листа не совпадает с карточкой над ним, поле «Название» повторяет заголовок.
- Текст из PDF разбит по строкам страницы: переносы строк и слов остаются в тексте, и соавтор читает его таким же.
- Удалить оригинал отдельно от заметки нельзя.
- В `web/package.json` уже есть `react-markdown`.

## What Changes

Главная мысль: у материала два вида. Оригинал — для автора, текст — для соавтора. Новой сущности нет, это по-прежнему заметка с оригиналом (`story-materials`); меняется показ и два действия.

1. **Две вкладки у заметки с оригиналом: «Оригинал» и «Текст для соавтора».** По умолчанию открыт оригинал. Во второй вкладке текст, который читает соавтор, с подписью «Этот текст видит соавтор»; он правится как сейчас (режим чтения длинного материала сохраняется). У заметки без оригинала вкладок нет.
2. **Оригинал показывается по формату, без универсального просмотрщика:**
   - PDF — встроенным просмотрщиком браузера во фрейме (страницы, прокрутка, поиск браузера), без библиотек; рядом «Открыть в новой вкладке».
   - DOCX — как оформленный документ нашими шрифтами: заголовки, жирный, курсив, списки, таблицы. Перевод DOCX в HTML в браузере (библиотека уровня mammoth, загружается только при открытии такой заметки); HTML очищается перед показом. Точной вёрстки Word нет.
   - MD — отрисованный Markdown.
   - TXT — текст для чтения с нормальными отступами листа.
   - Fountain, FDX, STARC — в этом шаге показываются как текст для чтения; вид сценария — следующий шаг (Non-goals).
3. **«Удалить оригинал, оставить текст».** Действие в меню «…» заметки с оригиналом. Подтверждение называет освобождаемый объём и говорит, что вернуть оригинал нельзя. Оригинал удаляется навсегда, место в пределе тарифа освобождается, заметка становится обычной. Обратного действия (удалить текст, оставить оригинал) нет.
4. **«Вернуть текст из оригинала».** Действие в меню «…» заметки с оригиналом: текст заметки заменяется заново извлечённым из оригинала, с подтверждением, что правки текста пропадут. Без ИИ и без затрат, тем же извлечением, что при загрузке; правка идёт с ревизией, как другие правки заметки.
5. **Чище текст из PDF.** Извлечение склеивает строки страницы в абзацы и убирает переносы слов по дефису в конце строки. Действует на новые загрузки и на «Вернуть текст из оригинала»; старые заметки не переписываются.
6. **Шапка и навигатор.**
   - Название правится прямо в заголовке документа; карточка «Название» у заметки уходит.
   - Имя файла, размер и «Скачать» — одна тонкая строка под заголовком.
   - В навигаторе и списке заметок у заметки с оригиналом значок типа файла (PDF, DOCX, текст, сценарий), чтобы материалы отличались от своих записей.
   - Лист текста получает отступы, его ширина согласована с шапкой.

## Scope

- `agno/core/files.py`: склейка строк PDF в абзацы.
- `agno/core/notes.py`, `agno/core/files.py`: удаление оригинала заметки с освобождением места; текст заметки заново из оригинала.
- `agno/app/api/notes.py` (или маршруты заметок, где они сейчас): два действия под `/api/v1/` с проверкой доступа и `If-Match`.
- `web/src/data/`: два действия в провайдерах и данных примера.
- `web/src/screens/project/docs/NoteDoc.tsx` и соседние: вкладки, просмотр оригинала по формату, шапка, меню; навигатор и список заметок — значки.
- `web/package.json`: библиотека DOCX → HTML и очистка HTML, точные версии.
- Спеки `web/workspace`, `api/files`, `api/stories`, `core/database` (если меняется связь заметки и файла).
- Промпт соавтора: справка «О сервисе «Соавтор»» описывает экран заметки — обновить.

## Non-goals

- Вид сценария для Fountain, FDX и STARC в оригинале (следующий шаг).
- Точная вёрстка Word, свой просмотрщик PDF (pdf.js), просмотр на телефоне сверх того, что даёт браузер.
- Разметка, комментарии и выделения в оригинале.
- Замена оригинала, несколько оригиналов у заметки.
- Переизвлечение текста у всех старых заметок.
- Картинки, ссылки, голос, сканы — шаги 2–3 `story-materials`.

## Constraints (из контекст-пака)

- Каждый маршрут проверяет доступ к истории; тест доступа на чужую заметку и чужой оригинал обязателен.
- Правки заметки с ревизией и `If-Match`; конфликт показывается автору.
- HTML из DOCX показывается только очищенным: скрипты, обработчики событий и внешние ресурсы не проходят.
- Текст материалов и имена файлов не попадают в логи.
- Цвета только из семантических токенов дизайн-системы.
- Миграция Alembic, если нужна, — только схема `authorled`, вперёд, одна голова.
- Ядро не вызывает биллинг; освобождение места видно по тому же подсчёту объёма файлов пользователя.

## Acceptance criteria

- Заметка из PDF открывается на вкладке «Оригинал» и показывает сам PDF; «Открыть в новой вкладке» открывает его.
- Заметка из DOCX показывает документ с заголовками, списками и таблицами; заметка из MD — отрисованный Markdown.
- Вкладка «Текст для соавтора» показывает и правит текст, который читает соавтор.
- «Удалить оригинал, оставить текст» после подтверждения удаляет оригинал навсегда: заметка остаётся с текстом, без вкладок и строки файла, занятый объём уменьшается на размер файла.
- «Вернуть текст из оригинала» после подтверждения заменяет текст заметки извлечённым из оригинала.
- Текст нового PDF идёт абзацами, без разрывов посреди предложения и без переносов слов по дефису.
- Название правится в заголовке; карточки «Название» у заметки нет; текст на листе с отступами.
- В навигаторе у заметок с оригиналом значок типа файла.
- Чужая заметка и чужой оригинал недоступны: маршруты отвечают отказом.
- `./scripts/validate.sh` и `./scripts/dev.sh test` проходят.

## Risks

- **PDF во фрейме на телефоне.** Мобильные браузеры показывают PDF во фрейме хуже (иногда только первую страницу). Остаются «Открыть в новой вкладке» и «Скачать».
- **Склейка строк PDF — эвристика.** Стихи, таблицы и списки могут склеиться лишнего. У автора есть вкладка текста, чтобы поправить.
- **Вес библиотеки DOCX.** Загружается только при открытии заметки из DOCX, в общий бандл не входит.
- **Название в заголовке.** У других документов карточка «Название» остаётся — заметка будет выглядеть иначе. Перенос того же решения на другие документы — отдельное решение.
