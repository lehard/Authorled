# Кадры концепта «Кабинет»

Сняты с кликабельного макета `openspec/context/_raw/design/kabinet` (демо-история «Тихая вода») для кейса на glavai.ru; скопированы из репозитория glavai, `public/cases/authorled-concept-*.webp`, 2026-11-08. Ширины 720, 1080 и 1440. В бете этих экранов нет: на сайте они всегда подписаны как концепт.

| Файл        | Что на кадре                                                                                                               |
| ----------- | -------------------------------------------------------------------------------------------------------------------------- |
| `path`      | Путь истории: 22 шага от замысла до финального текста. Каждый шаг утверждает автор, следующий открывается после чек-листа. |
| `impulses`  | Карта импульсов: образы, фразы и вопросы, из которых растёт история. Соавтор предлагает группы и связи.                    |
| `relations` | Отношения персонажей: кто с кем связан и как связь меняется от сцены к сцене.                                              |
| `rhythm`    | Ритм: кривая напряжения по страницам сценария поверх опорных точек структуры.                                              |
| `timeline`  | Таймлайн: когда события случились, в каком порядке их видит зритель и кто что знает к каждой сцене.                        |
| `impact`    | Автор меняет утверждённое решение, а соавтор показывает, какие документы оно задело и чем.                                 |
| `home`      | Главный экран истории: следующий шаг, противоречия и статистика письма с целью на день.                                    |
