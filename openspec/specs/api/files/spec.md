# api/files Specification

## Purpose
Файлы истории через `/api/v1`: загрузка с антивирусной проверкой и извлечением текста до сохранения, выдача метаданных и содержимого, удаление. Файлы нужны беседе с соавтором и импорту.

## Requirements

### Requirement: Загрузка файла
`POST /api/v1/projects/{id}/files` (multipart: `file`, `purpose` — `chat` или `import`, у `chat` — `session_id` беседы этой истории) MUST в одном запросе проверить размер и тип, проверить файл ClamAV, извлечь текст и только затем сохранить файл. Ответ `201` MUST содержать `id`, `name`, `media_type`, `size_bytes`, `purpose`, `session_id`, `created_at`. Статусов обработки MUST NOT быть.

#### Scenario: Документ в чат
- WHEN автор загружает `заметки.docx` с `purpose` `chat` и беседой `{projectId}:{uuid}`
- THEN ответ MUST быть `201`, и соавтор MUST мочь прочитать текст файла

#### Scenario: Беседа другой истории
- WHEN `session_id` не начинается с `{projectId}:`
- THEN ответ MUST быть `422`, файл MUST NOT сохраняться

### Requirement: Допустимые файлы
Размер файла MUST быть не больше 20 МБ, иначе `413`. Тип определяется по расширению и содержимому: для `chat` и для оригинала заметки — DOCX, PDF, TXT, MD, Fountain, FDX, STARC; для `import` — Fountain, FDX, STARC, DOCX, TXT. Другой тип или несовпадение расширения и содержимого MUST давать `422` с причиной. Пустой файл MUST давать `422`.

#### Scenario: Слишком большой
- WHEN автор загружает файл 25 МБ
- THEN ответ MUST быть `413`, файл MUST NOT сохраняться

#### Scenario: Изображение
- WHEN автор загружает `обложка.png`
- THEN ответ MUST быть `422` с причиной «тип файла не поддерживается»

#### Scenario: PDF для импорта
- WHEN автор загружает PDF с `purpose` `import`
- THEN ответ MUST быть `422`

#### Scenario: Не SQLite под видом STARC
- WHEN автор загружает `проект.starc`, внутри которого текст, а не база SQLite
- THEN ответ MUST быть `422`, файл MUST NOT сохраняться

#### Scenario: Изображение в заметки
- WHEN автор загружает в заметки `обложка.png`
- THEN ответ MUST быть `422` с причиной «тип файла не поддерживается», и заметка MUST NOT появиться

### Requirement: Антивирусная проверка
Каждый файл MUST проверяться ClamAV до разбора и до сохранения. Найденная угроза MUST давать `422` с причиной «файл не прошёл антивирусную проверку». Если ClamAV недоступен, MUST возвращаться `503` с причиной, и файл MUST NOT сохраняться и MUST NOT разбираться; пропускать проверку MUST NOT.

#### Scenario: Тестовый вирус
- WHEN автор загружает тестовый файл EICAR
- THEN ответ MUST быть `422`, и в базе MUST NOT появиться записи файла

#### Scenario: Антивирус недоступен
- WHEN сервис ClamAV остановлен, и автор загружает TXT
- THEN ответ MUST быть `503`, файл MUST NOT сохраняться

### Requirement: Извлечение текста
Для каждого принятого файла ядро MUST сохранять извлечённый текст: DOCX — абзацы, PDF — текст страниц абзацами (см. «Абзацы текста PDF»), TXT и MD — содержимое в UTF-8, Fountain, FDX и STARC — текст сценария абзацами. Файл, который не удаётся разобрать (битый архив, не UTF-8, PDF без текстового слоя), MUST давать `422` с причиной и MUST NOT сохраняться.

#### Scenario: PDF без текста
- WHEN автор загружает в чат PDF из одних сканов
- THEN ответ MUST быть `422` с причиной, что в файле нет текста

#### Scenario: STARC в чат
- WHEN автор прикрепляет к беседе проект `.starc` со сценарием
- THEN соавтор MUST мочь прочитать текст сценария этого файла

### Requirement: Метаданные и содержимое файла
`GET /api/v1/files/{id}` MUST возвращать метаданные, `GET /api/v1/files/{id}/content` — исходные байты с типом файла и `Content-Disposition: attachment` с именем файла. Файлы MUST быть доступны только владельцу истории.

#### Scenario: Скачивание
- WHEN автор скачивает загруженный `заметки.docx`
- THEN байты ответа MUST совпадать с загруженными

### Requirement: Удаление файла
`DELETE /api/v1/files/{id}` MUST удалять файл навсегда с содержимым; ответ `204`. Оригинал заметки MUST удаляться только вместе с заметкой или действием «Удаление оригинала заметки» (`api/stories`): `DELETE` для него MUST давать `409` с причиной, и файл MUST остаться. Удаление истории навсегда MUST удалять все её файлы.

#### Scenario: Удалённый файл
- WHEN автор удалил файл и запрашивает его метаданные
- THEN ответ MUST быть `404`

#### Scenario: Оригинал заметки
- GIVEN у заметки есть оригинал
- WHEN автор вызывает `DELETE` для этого файла
- THEN ответ MUST быть `409`, и заметка и её оригинал MUST остаться

### Requirement: Абзацы текста PDF
Текст страницы PDF MUST собираться в абзацы: строка, за которой идёт строка со строчной буквы, или строка, кончающаяся запятой, MUST склеиваться со следующей через пробел; дефис в конце строки перед строкой со строчной буквы MUST убираться, и части слова MUST склеиваться без пробела. Остальные переводы строк MUST сохраняться, страницы MUST разделяться пустой строкой.

#### Scenario: Предложение через две строки
- WHEN загружается PDF, где строка «Для пополнения счета используйте реквизиты для» продолжается строкой «оплаты по договору.»
- THEN извлечённый текст MUST содержать «реквизиты для оплаты по договору.» одной строкой

#### Scenario: Перенос слова
- WHEN строка PDF кончается на «сцена-», а следующая начинается с «рист пишет»
- THEN извлечённый текст MUST содержать «сценарист пишет»

#### Scenario: Строки реквизитов не склеиваются
- WHEN строка PDF «Банк ГПБ (АО) БИК 044525823» продолжается строкой «Сч. № 30101810200000000823»
- THEN в извлечённом тексте они MUST остаться на разных строках
