# Agent Tracing Specification

## Purpose
Журнал работы агентов: что агенты и команды делали по шагам, сколько длился каждый шаг, сколько токенов ушло и где была ошибка. Журнал ведётся в своём экземпляре Phoenix, без текстов авторов, и открыт только владельцу сервера.

## Requirements

### Requirement: Журнал запусков агентов в Phoenix
Каждый запуск агента или команды приложения (в том числе `coauthor`, `claude-engineer`, `os-manager-internal`, `company-manager-internal`) MUST записываться трассой в сервис Phoenix из состава приложения. Трасса MUST содержать вложенные шаги: вызовы модели, вызовы инструментов, вызовы участников команды. У каждого шага MUST быть имя, время начала и длительность, статус, а у вызова модели — имя модели и число токенов. Трассы MUST NOT записываться в таблицы Agno `ai.agno_traces` и `ai.agno_spans`.

#### Scenario: Запуск соавтора в журнале
- **GIVEN** API и Phoenix запущены
- **WHEN** автор отправляет сообщение соавтору и получает ответ
- **THEN** не позже чем через 10 секунд после ответа в Phoenix MUST быть трасса этого запуска с шагом вызова модели (имя модели, токены, длительность)
- **AND** если соавтор вызывал инструмент, в трассе MUST быть шаг с именем этого инструмента

#### Scenario: Таблицы Agno не растут
- **GIVEN** API запущен, число строк в `ai.agno_traces` и `ai.agno_spans` запомнено
- **WHEN** автор отправляет сообщение соавтору и получает ответ
- **THEN** число строк в обеих таблицах MUST NOT измениться

#### Scenario: Ошибка шага видна
- **GIVEN** вызов инструмента соавтора завершился ошибкой
- **WHEN** администратор открывает трассу этого запуска в Phoenix
- **THEN** шаг инструмента MUST иметь статус ошибки и текст ошибки

### Requirement: Корень трассы — запуск агента
Корнем трассы MUST быть запуск агента или команды, а не HTTP-запрос. У корня MUST быть указаны агент или команда, пользователь (`sub` токена) и сессия, чтобы журнал фильтровался по ним. HTTP-запросы к API (маршруты `/api/v1/...`, `/health`, маршруты Agno) MUST NOT создавать трасс.

#### Scenario: Фильтр по сессии
- **GIVEN** автор провёл в одном разговоре с соавтором два запуска
- **WHEN** администратор фильтрует журнал Phoenix по сессии этого разговора
- **THEN** MUST находиться обе трассы, и корень каждой MUST быть запуском `coauthor`

#### Scenario: Щелчки в интерфейсе не пишутся
- **GIVEN** API и Phoenix запущены
- **WHEN** автор открывает полку, историю и комментарии (запросы `GET /api/v1/...`) без обращения к соавтору
- **THEN** в Phoenix MUST NOT появиться новых трасс

### Requirement: Журнал без текстов
Шаги журнала MUST NOT содержать содержимого: текста сообщений модели, системного промпта, ответа модели, входов и выходов агентов, аргументов и результатов инструментов. Имена шагов, модели и инструментов, время, токены, статус и текст ошибки MUST оставаться.

#### Scenario: Фразы автора нет в журнале
- **GIVEN** автор отправил соавтору сообщение с уникальной фразой, соавтор прочитал сценарий инструментом и ответил
- **WHEN** администратор ищет эту фразу и фразу из ответа соавтора в атрибутах всех шагов трассы
- **THEN** ни одна из фраз MUST NOT находиться

### Requirement: Срок хранения журнала
Phoenix MUST хранить трассы 30 дней и удалять более старые сам, без действий администратора.

#### Scenario: Политика хранения
- **GIVEN** Phoenix запущен из состава приложения
- **WHEN** администратор открывает настройки хранения в интерфейсе Phoenix
- **THEN** срок хранения по умолчанию MUST быть 30 дней

### Requirement: Доступ к журналу только с сервера
Интерфейс Phoenix и приём трасс MUST быть доступны только на `127.0.0.1` хоста и из сети контейнеров приложения. Обратный прокси MUST NOT публиковать Phoenix. Администратор MUST открывать журнал сервера через SSH-туннель к `127.0.0.1` сервера. Своего входа у Phoenix нет.

#### Scenario: Снаружи закрыто
- **GIVEN** продакшн запущен
- **WHEN** клиент с другой машины обращается к порту Phoenix на внешнем адресе сервера
- **THEN** соединение MUST быть невозможно

#### Scenario: Через туннель
- **GIVEN** у администратора есть SSH-доступ к серверу
- **WHEN** он выполняет `ssh -L 6006:127.0.0.1:6006 authorled` и открывает `http://127.0.0.1:6006`
- **THEN** MUST открываться интерфейс Phoenix с трассами сервера

### Requirement: Отдельные данные Phoenix
Phoenix MUST хранить данные в своей схеме `phoenix` общего PostgreSQL под своей ролью. Роль Phoenix MUST NOT иметь доступа к схемам `ai`, `authorled`, `billing` и `authentik`. Роль API `agentos` MUST NOT иметь доступа к схеме `phoenix`.

#### Scenario: Роль Phoenix не видит данные продукта
- **GIVEN** стек запущен
- **WHEN** под ролью Phoenix выполняется чтение из `authorled.projects`
- **THEN** PostgreSQL MUST отказать в доступе

### Requirement: Phoenix без внешних запросов
Phoenix MUST быть запущен с выключенной собственной телеметрией и MUST NOT отправлять данные за пределы сервера.

#### Scenario: Телеметрия Phoenix выключена
- **GIVEN** стек запущен
- **WHEN** проверяется окружение контейнера Phoenix
- **THEN** телеметрия Phoenix MUST быть выключена явной настройкой

### Requirement: Обязательный Phoenix при старте
Адрес Phoenix MUST задаваться переменной окружения без значения по умолчанию. API MUST NOT стартовать, если адрес не задан, или если Phoenix не отвечает на проверку при старте. Сообщение об ошибке MUST называть переменную или адрес.

#### Scenario: Нет адреса
- **GIVEN** переменная адреса Phoenix не задана
- **WHEN** запускается API
- **THEN** запуск MUST завершиться ошибкой, называющей переменную

#### Scenario: Phoenix не отвечает при старте
- **GIVEN** адрес задан, но Phoenix остановлен
- **WHEN** запускается API
- **THEN** запуск MUST завершиться ошибкой, называющей адрес

### Requirement: Потеря Phoenix во время работы
Если Phoenix недоступен после старта API, запуски агентов MUST продолжаться и отвечать как обычно. Каждая неудачная отправка трасс MUST писаться в лог API на уровне ошибки с адресом Phoenix. Трассы за это время теряются. Это исключение из правила «без запасных путей», согласованное владельцем 2026-11-09 только для журнала.

#### Scenario: Phoenix остановлен при работающем API
- **GIVEN** API запущен, после этого Phoenix остановлен
- **WHEN** автор отправляет сообщение соавтору
- **THEN** соавтор MUST ответить
- **AND** в логе API MUST появиться ошибка отправки трасс с адресом Phoenix
