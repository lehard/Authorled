# Web App Specification

## Purpose
Каркас фронтенда Соавтора в каталоге `web/` монорепозитория: из чего он собирается, какие запросы делает, как запускается и проверяется. Продуктовые экраны добавляются отдельными changes поверх этого каркаса.

## Requirements

### Requirement: Расположение и состав фронтенда
Фронтенд MUST находиться в каталоге `web/` и MUST собираться в статические файлы одностраничного приложения на React и TypeScript. Зависимости MUST быть закреплены точными версиями в `web/package.json` и `web/package-lock.json`; версия Node.js MUST быть указана в `web/.nvmrc` и в поле `engines`. Фронтенд MUST NOT содержать своей базы данных и продуктовой логики (ADR-001).

#### Scenario: Чистая сборка
- GIVEN установлен Node.js из `web/.nvmrc`
- WHEN выполняются `npm ci --prefix web` и `npm run build --prefix web`
- THEN сборка MUST завершиться кодом `0` и положить статические файлы в `web/dist/`

### Requirement: Язык интерфейса
Корневой документ приложения MUST иметь `lang="ru"`. Все строки интерфейса MUST быть на русском.

#### Scenario: Язык документа
- GIVEN приложение открыто в браузере
- WHEN читается атрибут `lang` элемента `<html>`
- THEN значение MUST быть `ru`

### Requirement: Без телеметрии и внешних запросов
Приложение MUST NOT отправлять телеметрию и MUST NOT обращаться к сторонним хостам при загрузке: шрифты, иконки и стили MUST поставляться из собственной сборки. Телеметрия встроенных библиотек (каркаса приложения и других) MUST быть выключена явно в коде. Единственные внешние адреса, к которым приложение обращается, — Authentik из `AUTH_ISSUER` (вход) и API бэкенда; другие хосты MUST NOT использоваться.

#### Scenario: Только свой хост
- GIVEN собранное приложение открыто с локального сервера предпросмотра
- WHEN открыта витрина `/showcase`
- THEN все сетевые запросы MUST идти на тот же хост

#### Scenario: Окно истории без лишних хостов
- GIVEN пользователь вошёл и открыл историю
- WHEN страница загружена полностью
- THEN сетевые запросы MUST идти только на хост приложения и на хост из `AUTH_ISSUER`

### Requirement: Команды разработки
`web/package.json` MUST предоставлять команды `dev` (сервер разработки на `127.0.0.1`), `build`, `preview`, `lint`, `format`, `format:check`, `typecheck` и `check:contrast`. Приложение в разработке MUST открываться по адресу с тем же хостом и портом, что и `AUTH_FRONTEND_REDIRECT_URI`.

#### Scenario: Сервер разработки
- GIVEN зависимости установлены
- WHEN выполняется `npm run dev --prefix web`
- THEN сервер MUST слушать только `127.0.0.1`

#### Scenario: Адрес для входа
- GIVEN `AUTH_FRONTEND_REDIRECT_URI=http://localhost:5173/auth/callback`
- WHEN запущен сервер разработки
- THEN приложение MUST открываться по `http://localhost:5173`

### Requirement: Заставка и отказ загрузки
Страница приложения MUST показывать заставку до прихода скриптов: знак и название «Соавтор» и признак загрузки. Заставку MUST сменять первый экран приложения. Если скрипт или стиль приложения не загрузился, MUST показываться «Не удалось загрузить Соавтор» с кнопкой «Обновить», которая перезагружает страницу. Приложение MUST NOT повторять загрузку само и MUST NOT подменять недостающую часть.

#### Scenario: Заставка до скрипта
- GIVEN скрипт приложения ещё не пришёл
- WHEN страница получена браузером
- THEN MUST быть видны название «Соавтор» и признак загрузки
- AND экран MUST NOT быть пустым

#### Scenario: Скрипт не пришёл
- GIVEN главный скрипт приложения отвечает ошибкой или соединение оборвалось
- WHEN страница открыта
- THEN MUST показываться «Не удалось загрузить Соавтор» и кнопка «Обновить»
- AND нажатие «Обновить» MUST перезагрузить страницу

### Requirement: Окно истории отдельной частью
Окно истории (адреса `/p/...`) и витрина `/showcase` MUST загружаться отдельными частями, только когда их открывают. Вход, возврат из Authentik, полка, корзина, настройки и «Не найдено» MUST открываться без этих частей. Пока часть окна истории загружается, MUST показываться «Открываем историю…». Если часть не загрузилась, MUST показываться «Не удалось загрузить Соавтор» с «Обновить».

#### Scenario: Полка без окна истории
- GIVEN пользователь вошёл
- WHEN открыта полка `/` и фоновая подгрузка ещё не началась
- THEN среди загруженных скриптов MUST NOT быть части окна истории

#### Scenario: Прямая ссылка на историю
- GIVEN пользователь вошёл и часть окна истории ещё не загружена
- WHEN он открывает `/p/water/d/<draft>/text`
- THEN MUST показываться «Открываем историю…», затем окно истории

#### Scenario: Часть окна истории не загрузилась
- GIVEN часть окна истории отвечает ошибкой
- WHEN пользователь открывает историю
- THEN MUST показываться «Не удалось загрузить Соавтор» и кнопка «Обновить»

### Requirement: Фоновая подгрузка окна истории
Полка, показав истории, MUST начинать загрузку части окна истории в фоне, и открытие истории MUST использовать эту загрузку. Неудача фоновой загрузки MUST NOT показываться на полке; её MUST показать открытие истории.

#### Scenario: Неудача в фоне
- GIVEN часть окна истории отвечает ошибкой, а полка показала истории
- WHEN фоновая загрузка не удалась
- THEN полка MUST NOT показывать ошибку
- AND открытие истории MUST показать «Не удалось загрузить Соавтор» и кнопку «Обновить»

#### Scenario: Открытие истории после фоновой подгрузки
- GIVEN полка показала истории и фоновая подгрузка завершилась
- WHEN пользователь открывает историю
- THEN часть окна истории MUST NOT запрашиваться снова

### Requirement: Бюджет первого экрана
`npm run build --prefix web` MUST завершаться ошибкой, если скрипты, которые страница загружает до первого экрана, вместе больше 300 КБ в gzip, или если среди них есть часть окна истории или витрины. Ошибка MUST называть части и их размер.

#### Scenario: Бюджет превышен
- GIVEN скрипты первого экрана вместе больше 300 КБ в gzip
- WHEN выполняется `npm run build --prefix web`
- THEN сборка MUST завершиться ненулевым кодом
- AND сообщение MUST называть части и их размер в gzip

#### Scenario: Окно истории попало в первый экран
- GIVEN экран полки импортирует модуль окна истории напрямую
- WHEN выполняется `npm run build --prefix web`
- THEN сборка MUST завершиться ненулевым кодом с указанием, что окно истории попало в скрипты первого экрана
