# Fade In (Professional Screenwriting Software 5, Fade In Access, Fade In Mobile)

## 1. Что это и для кого

Недорогой кроссплатформенный сценарный редактор от GCC Productions, позиционируется как альтернатива Final Draft («made by humans for human writers», без ИИ). Сайт: https://www.fadeinpro.com/. Версия 5.0.15 от 2026-09-25 (https://www.fadeinpro.com/page.pl?content=version_notes). Дата проверки 2026-10-27.

## 2. Цена, тарифы, платформы

- Десктоп: $79.95 разово (зачёркнуто $99.95), обновления бесплатны (https://www.fadeinpro.com/page.pl?content=purchase, https://www.fadeinpro.com/kb/content/1/121/en/are-updates-free.html). Студенческая цена и групповые лицензии есть.
- Бесплатное демо без срока: все функции, кроме онлайн-коллаборации, водяной знак на печати, напоминание после 10 страниц (https://www.fadeinpro.com/page.pl?content=download).
- Fade In Access: опциональная месячная или годовая подписка на облако, версии, браузерный редактор, совместную работу, публикацию PDF; 7 дней пробного периода (https://www.fadeinpro.com/page.pl?content=support, https://www.fadeinpro.com/kb/content/1/79/en/what-is-the-refund-policy.html). Цена на открытых страницах не найдена.
- Платформы: Windows 7+, macOS 10.10+ (Intel и Apple Silicon), Linux x64; Fade In Access и Fade In Mobile для iOS и Android.

## 3. Сильные стороны

- Цена и бессрочные бесплатные обновления; работа без аккаунта (https://www.fadeinpro.com/page.pl?content=comparison).
- Все десктопные ОС, включая Linux.
- Открытый формат Open Screenplay Format (XML) с SDK (https://www.fadeinpro.com/page.pl?content=download).
- Широкий импорт: FDX, Fountain, Scrivener, Celtx, StudioBinder, Word, RTF, PDF, HTML (https://www.fadeinpro.com/page.pl?content=features, версия 5.0.14).
- Инструменты переписывания: Dialogue Tuner, Scene Versions, подгонка длины строк, частоты слов.
- Table Read, режим фокуса, session statistics.

## 4. Функции по разделам таксономии

Полная оценка в `fade-in.csv`. Коротко:

- Редактор прозы: шрифты, стили элементов, изображения, орфография и тезаурус, полноэкранный и фокус-режим, тёмные цвета страницы. Грамматики нет (по решению разработчика: https://www.fadeinpro.com/kb/content/1/94/en/does-fade-in-include-a-grammar-checker.html), RTL не поддерживается (https://www.fadeinpro.com/kb/content/3/50/en/does-fade-in-support-right_to_left-text.html).
- Сценарий: автоформат, автодополнение, dual dialogue, шаблоны (кино, ТВ, пьеса, радио, A/V, манускрипт), ревизии цветом, блокировка, отчёты, теги.
- Структура: Navigator с вложенными sequences, index cards, цветовая разметка. Corkboard базовый.
- Библия проекта: нет сущностей; списки персонажей и локаций.
- Версии: Compare to Previous, Scene Versions, бэкапы. Track Changes сознательно нет (https://www.fadeinpro.com/kb/content/1/141/en/does-fade-in-have-a-track-changes-feature.html).
- Совместная работа: через Fade In Access; прежняя realtime-сессия устарела (https://www.fadeinpro.com/kb/content/1/123/en/methods-of-collaborating.html).

## 5. ИИ

Нет. Слоган главной страницы «made by humans for human writers». В 5.0.11 убрали интеграцию с Grammarly и откатили автоперевод вставляемого текста (https://www.fadeinpro.com/page.pl?content=version_notes). Table Read читает системными голосами ОС, не ИИ.

## 6. Импорт, экспорт, формат

- Импорт/экспорт: FDX (fdr — только импорт), Fountain, .docx (с 5.0.14, 2026-09-20), RTF, HTML, текст, OSF XML, StudioBinder (.sbx), PDF (импорт), Scrivener, Celtx. EPUB-экспорт по таблице сравнения. Экспорт в Movie Magic невозможен (закрытый формат): https://www.fadeinpro.com/kb/content/1/85/en/export-to-movie-magic-scheduling-or-movie-magic-budgeting.html
- Нативный формат .fadein на основе OSF.

## 7. Жалобы пользователей

Отзывы собраны на самом сайте вендора (NYT, Hollywood Reporter, PCWorld, Macworld, подкаст Scriptnotes): https://www.fadeinpro.com/. Независимых жалоб в открытых источниках за этот проход не собрано. Из справки вендора видны ограничения: Fade In Access не отображает точную пагинацию и титульные страницы (https://www.fadeinpro.com/kb/content/5/186/en/page-numbers-in-fade-in-access.html, https://www.fadeinpro.com/kb/content/5/187/en/title-pages-in-fade-in-access.html); длина сценария после импорта FDX отличается (https://www.fadeinpro.com/kb/content/3/29/en/why-is-my-script-a-different-length-than-in-final-draft.html).

## 8. Что взять Authorled

- Открытый XML-формат + SDK и импорт из максимума форматов как способ снять страх привязки.
- Dialogue Tuner: все реплики одного персонажа в одном окне для проверки голоса.
- Scene Versions: несколько вариантов сцены без веток всего документа.
- Бессрочное демо: все функции, ограничение только на печать.
- Позиционирование «сделано людьми» как контраст; для Authorled важно решить, как подавать ИИ.
- Чего не брать: отсутствие реальных треков правок и слабая облачная часть.

## 9. Не проверено и расхождения

- Цена Fade In Access на открытых страницах не найдена (сайт /access/ требует JavaScript).
- Сравнительная таблица на сайте вендора — маркетинговая и устаревшая (сравнивает с Final Draft 11); использована только для подтверждения собственных функций Fade In, а не конкурентов.
- Fountain-экспорт и PDF-импорт подтверждены косвенно (таблица сравнения, справка).
- Нет данных о русском интерфейсе приложения (справка доступна на многих языках, включая русский, но интерфейс программы не проверен).
- Локальные функции вроде закладок и Dialogue Tuner описаны только на странице функций, без справки.
