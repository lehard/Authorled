# NovelAI

## 1. Что это и для кого

ИИ-инструмент для художественного письма и интерактивных историй (текст), плюс генерация аниме-изображений. Позиционирование: «пишет вместе с вами, а не за вас». Сайт: https://novelai.net/. Модели по сайту: GLM 4.6 (текст), NovelAI Diffusion V5 (картинки). Проверено 2026-10-27 по документации https://docs.novelai.net/en/ и официальному сайту.

## 2. Цена и тарифы, платформы

- Paper: бесплатный разовый пробный тариф, 50 текстовых генераций, 30 изображений, 100 озвучек TTS (https://docs.novelai.net/en/subscription).
- Tablet $10/мес: безлимит текста и TTS, 1000 Anlas; Scroll $15: больший контекст; Opus $25: наибольший контекст до 28 672 токенов, доступ к Xialong, Krake, Erato, 10 000 Anlas (там же).
- Anlas тратятся только на изображения; докупаются при активной подписке (там же).
- Платформа: только браузер, можно поставить как PWA; нативных приложений нет (https://docs.novelai.net/en/faq). Интерфейс EN/JP.
- Расхождение: сторонние источники по-разному называют, какой тариф получает какой размер контекста, и отдельно сообщают, что GLM-4.6 стала доступна всем тарифам с декабря 2025 (пост на Reddit, пересказ).

## 3. Сильные стороны

- Безлимитная текстовая генерация за фиксированную подписку, без кредитов.
- Глубокий лорбук с условиями активации и управлением бюджетом контекста (https://docs.novelai.net/en/text/lorebook).
- Прозрачность: видно, что именно уходит в модель; вероятности токенов; тонкие настройки сэмплинга.
- Скриптовый API для расширений (https://docs.novelai.net/en/scripting/introduction).
- Заявленная приватность: истории шифруются в браузере (https://docs.novelai.net/en/faq).

## 4. Функции по разделам таксономии

- Редактор: undo/redo с ветвящейся историей, темы, Editor V2 с форматированием, TTS (https://docs.novelai.net/en/text/editor). Дистракшн-режимов, счётчиков и поиска/замены в доках не нашли (не проверено).
- Сценарный редактор, доски, структура проекта: отсутствуют в оглавлении документации; продукт — «одно полотно текста» плюс лорбук. Библиотека историй с папками (https://docs.novelai.net/en/misc/uifunctionalities).
- Библия: лорбук (записи по ключам, категории, регулярные выражения, Lore Generator, импорт/экспорт .lorebook/.json/.png).
- Версии: ветки и история правок в самой истории; ручных снимков и diff не нашли.
- Совместной работы нет в оглавлении.

## 5. ИИ

- Модели (https://docs.novelai.net/en/text/models): Xialong (355B, дообучен на прозе поверх GLM-4.6; контекст 28 672 + 8 192 скользящих), GLM-4.6 (без дообучения), Erato (Llama 3 70B), Kayra (13B, 8 192). Устаревшие: Euterpe, Sigurd; закрыты Clio, Krake и др.
- Режимы: продолжение текста (Ctrl+Enter), Retry, генерация с любой точки (Inline Generation), Text Adventure (действия через `>`), Instruct-блоки `{...}` (только Kayra/Clio, Editor V2) (https://docs.novelai.net/en/text/specialmodules), Prose Augmenter.
- Hypebot: ИИ-болельщик, комментирует историю и предлагает сюжетные ходы (https://docs.novelai.net/en/text/editor).
- Контекст: Memory (в начале), Author's Note (ближе к концу, сильнее влияет), лорбук по ключам, вид Context для просмотра; на Xialong/GLM-4.6 Placement недоступен, но есть продвинутые условия.
- Оплата: фиксированная подписка, текст безлимитный; Anlas только для картинок. Нет BYOK (не нашли в тарифах и FAQ).
- Обучение на стиле: пользовательские модули больше не обучаются, работают лишь на старых моделях (https://docs.novelai.net/en/text/modules).
- Картинки (Vibe Transfer, Inpaint, Director Tools, Canvas), TTS v1/v2 (https://docs.novelai.net/en/text/usersettings/tts).
- Политика данных: тексты историй зашифрованы, генерации картинок не сохраняются; текст при генерации уходит модели незашифрованным и, по FAQ, не хранится. Явного отказа от обучения на текстах на странице нет.
- Подача в UI: единый редактор с боковыми панелями Story/Lorebook/Settings; ИИ не навязывает правки, а продолжает текст.

## 6. Импорт, экспорт

Экспорт: .story (все ветви), .scenario (шаблон с плейсхолдерами), .txt, буфер, картинка, массовая выгрузка zip (https://docs.novelai.net/en/text/editor/storysettings). DOCX/PDF/EPUB нет. Импорт: .story, .scenario, лорбуки.

## 7. Жалобы пользователей

По Reddit (пересказы, апрель-май 2026): Xialong торопит сцены, мало описаний, хуже держит лорбук, чем GLM; часть предпочитает GLM для серьёзной прозы (https://reddit.sentinel-team.org/posts/1sz964n/snapshots/2026-05-01T02%3A53%3A13.9129Z и соседние снимки). Данных о нон-фикшене нет.

## 8. Что взять Authorled

- Вид «что видит ИИ» и бюджетирование контекста (ИИ-прозрачность).
- Условная активация библии (по ключам, цепочкам).
- Ветвящаяся история вариантов генерации.
- Модель «безлимит по подписке» как контрпример кредитам.

## 9. Не проверено и расхождения

- Составы форматирования, поиск/замена, счётчики, цели, автосохранение, синхронизация между устройствами: не проверено.
- Какой тариф получает какую модель и контекст: расхождение между официальной страницей подписки и сторонними обзорами.
- Лимит страницы docs.novelai.net/en/subscription расходится с ранними сторонними данными (Anlas, лимиты бесплатной пробы).
- Страницы сайта novelai.net/pricing отдают 404; цены взяты из документации.
