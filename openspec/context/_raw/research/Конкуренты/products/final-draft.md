# Final Draft (13 / Suite / Cloud / Go)

## 1. Что это и для кого

Отраслевой стандарт сценарного ПО для кино и ТВ (заявлено «95% профессионалов кино и ТВ»). Сайт: https://www.finaldraft.com/products/final-draft-13/. Текущая версия десктопа 13.5 (Mac App Store: https://apps.apple.com/dk/app/final-draft-13/id6450966627). FD13 вышел 9 января 2024 (https://nofilmschool.com/final-draft-13-arrives). Дата проверки 2026-10-27; сверка с мануалом FD13 (Windows) 2026-10-28.

## 2. Цена, тарифы, платформы

- Final Draft 13, разовая покупка: $249.99, на странице $199.99 (https://www.finaldraft.com/products/final-draft-13/). Лицензия на два компьютера, 30 дней возврата.
- Final Draft Suite (FD13 + Final Draft Cloud): $99.99 в год или $16.99 в месяц, 5 дней бесплатного триала (https://www.finaldraft.com/products/final-draft-cloud/).
- Final Draft Go (iPhone/iPad): по подписке; на странице продукта встречаются две пары цен, $1.99/мес и $9.99/год, а также $3.99/мес и $19.99/год (https://www.finaldraft.com/products/final-draft-iphone-ipad/).
- Платформы: macOS 12+, Windows 11+; нет Chromebook, Linux, Android-приложения не найдено. Браузерный Writer в Cloud. Интернет нужен при первом входе.
- Бесплатного тарифа нет, только триал.

## 3. Сильные стороны

- Формат и производственный набор: цветные ревизии, блокировка страниц, нумерация сцен, отчёты, теги (https://apps.apple.com/dk/app/final-draft-13/id6450966627).
- Планирование: Beat Board (с Flow Lines), Outline Editor с неограниченными lanes, Structure Lines, Outline Elements (https://www.finaldraft.com/learn/final-draft-quick-start/).
- Real-time Collaboration над сценарием и Beat Board (FD13 только с FD13): https://kb.finaldraft.com/hc/en-us/articles/15575058271508-Does-Final-Draft-offer-real-time-collaboration
- Navigator: таблица сцен и персонажей со своими вкладками, колонками, фильтром, CSV-экспортом, Character Arcs по сценам, Traits персонажей, Inclusivity-графики, голоса для чтения вслух (https://www.finaldraft.com/downloads/manuals/fd13-user-guide-win-exported.pdf#page=376, #page=392, #page=402). Мануал не подтверждает «экранное время» и «взаимодействия персонажей» из описания сайта: в колонках только число диалогов и сцен.
- Writing Stats: цели, серии, спринты (https://nofilmschool.com/final-draft-13-arrives).
- Позиционирование «стандарт индустрии» и обмен FDX.
- Мелочи, которые есть только в мануале: Alt Dialogue (варианты реплики на одном месте), Format Assistant, Names Database (90 000+ имён), Script Compare, Omit Scene, Macros с алиасами (автозамена), Character Sides для читок (https://www.finaldraft.com/downloads/manuals/fd13-user-guide-win-exported.pdf#page=170, #page=227, #page=224, #page=231).

## 4. Функции по разделам таксономии

Полная оценка в `final-draft.csv`. Коротко:

- Прозаический редактор: не целевой сценарий использования, но мануал покрывает его полно. Есть: жирный/курсив/подчёркивание/зачёркивание, шрифт и размер, выравнивание, отступы и интервалы, картинки, Undo/Redo, поиск и замена, умные кавычки, Typewriter (строка фиксируется примерно на 1/3 экрана, не по центру), Focus Mode, Night и Midnight Mode (https://www.finaldraft.com/downloads/manuals/fd13-user-guide-win-exported.pdf#page=138, #page=144, #page=80, #page=123). Нет: таблиц, сносок, регулярных выражений, поиска по нескольким файлам, подсветки наречий и штампов, затемнения остального текста, счётчика слов в статус-баре. Гиперссылки только внутри ScriptNote, повторы слов ловит проверка орфографии. Русской проверки орфографии нет: только латиница, 15 языков без русского (https://www.finaldraft.com/downloads/manuals/fd13-user-guide-win-exported.pdf#page=540).
- Сценарный редактор: автоформатирование, SmartType (имена, локации, время суток: https://www.finaldraft.com/downloads/manuals/fd13-user-guide-win-exported.pdf#page=506), Dual Dialogue, Shot, Cast List, пользовательские элементы (https://www.finaldraft.com/downloads/manuals/fd13-user-guide-win-exported.pdf#page=324), титульная, блокировка, цветные ревизии, нумерация сцен, отчёты, теги для разбивки, экспорт для планировщиков (EP Scheduling, Avid, Movie Magic через FDX). Читка голосами Windows (Speech Control, https://www.finaldraft.com/downloads/manuals/fd13-user-guide-win-exported.pdf#page=211).
- Структура и доска: Beat Board (свободное поле, Flow Lines, картинки), Outline Editor (линейка по страницам, lanes, родитель-потомок), Structure Lines, Index Cards и Scene View с перетаскиванием, шаблоны структур (https://update.finaldraft.com/13/0/release_notes.html, https://www.finaldraft.com/downloads/manuals/fd13-user-guide-win-exported.pdf#page=333, #page=358, #page=409). Сюжетные линии A/B/C делаются тегами и показываются колонками в Navigator (#page=452). В мануале нет: календаря мира, графика напряжения, майнд-карт, карт мира, групп и областей на доске, миникарты.
- Библия проекта: сущностей нет, есть таблица персонажей с Traits и произвольные категории тегов (предметы, локации, свои), без карточек, картинок и связей; персонажи в Navigator и кастомные свойства персонажей для отчёта разнообразия (https://kb.finaldraft.com/hc/en-us/articles/15575055785620-Does-Final-Draft-offer-a-character-diversity-report).
- Цели и статистика: Writing Stats (цели в страницах, словах или времени на день…год, графики), Sprint Timer (25 мин по умолчанию, секундомер), Statistics Report (доля элементов, статистика по персонажам и сценам). Серии дней в мануале (Windows) не описаны (https://www.finaldraft.com/downloads/manuals/fd13-user-guide-win-exported.pdf#page=242). Хронометраж не считается: ориентир 1 страница = 1 минута.
- Версии и рецензирование: Track Changes (принять/отклонить, https://www.finaldraft.com/downloads/manuals/fd13-user-guide-win-exported.pdf#page=86), Script Compare двух файлов (#page=231), Auto-Save (15 мин) и Auto-Backup с датированными копиями (#page=236), File > Backup и Save As вручную; веток и истории изменений нет. ScriptNotes в десктопе: тип, цвет, автор, даты, без ответов-тредов и ролей (они у Cloud по сайту).
- Совместная работа: realtime через Session ID (хост подтверждает вход, таймаут около 20 минут без активности, только FD13 с FD13), текстовый чат, цветные маркеры участников; голоса и видео нет, ролей в десктоп-мануале нет (https://www.finaldraft.com/downloads/manuals/fd13-user-guide-win-exported.pdf#page=215).

## 5. ИИ

Генеративных и аналитических ИИ-функций в официальных описаниях (страница FD13, Quick Start, Cloud) и в мануале FD13 (558 страниц, все ленты) нет. Cloud подаёт «защиту от AI-скрейпинга» как преимущество (https://www.finaldraft.com/products/final-draft-cloud/). Единственная внешняя «умная» функция: Grammarly. Мануал показывает, что она есть и в FD13 для Windows (настольный клиент Grammarly, виджет на экране: https://www.finaldraft.com/downloads/manuals/fd13-user-guide-win-exported.pdf#page=539), а не только в Go. Оплаты ИИ, выбора модели, BYOK нет.

## 6. Импорт, экспорт, форматы

- Импорт (мануал: https://www.finaldraft.com/downloads/manuals/fd13-user-guide-win-exported.pdf#page=43): FDX/FDXT, FDR/FDT старых версий, PDF (только текстовый), TXT, RTF, .fcf; Word через PDF, RTF или TXT (#page=300). Fountain открыть нельзя, обходной путь через txt (https://kb.finaldraft.com/hc/en-us/articles/15575252515988-What-file-formats-can-I-import-into-Final-Draft, https://kb.finaldraft.com/hc/en-us/articles/15575076862228-Can-Final-Draft-import-a-file-written-in-a-Fountain-based-screenwriting-program).
- Экспорт (мануал: https://www.finaldraft.com/downloads/manuals/fd13-user-guide-win-exported.pdf#page=52): FDXT, RTF, TXT, Text with Layout, HTML, .sex для EP Scheduling, FCF, Avid Script-Based Editing, PDF, Tab-delimited Dialogue; Beat Board в PDF; CSV из Navigator. Fountain, DOCX, EPUB, Markdown нет. В Word через RTF с потерями (https://kb.finaldraft.com/hc/en-us/articles/27525594609684-How-do-I-export-a-Final-Draft-file-to-a-different-format-like-RTF-or-TXT, https://kb.finaldraft.com/hc/en-us/articles/15575257621908-How-can-I-export-my-script-to-Microsoft-Word-or-other-word-processors).
- Custom Color PDFs (тёмные темы).

## 8. Что взять Authorled

- Beat Board + Outline Editor lanes + Structure Lines как цветовой слой структуры поверх текста.
- ScriptNotes: заметки, не меняющие текст, с ролями и тредами.
- Writing Stats (серии, спринты, пики по часам) как мягкая мотивация.
- Navigator персонажей: экранное время и «кто с кем» без ручной разметки.
- Подача «защита от AI-скрейпинга» как явное обещание по данным.
- Что не брать: подписка + разовая покупка + отдельное мобильное приложение с разными ценами создаёт путаницу.

## 9. Не проверено и расхождения

- Мануал FD13 (Windows), 558 страниц: https://www.finaldraft.com/downloads/manuals/fd13-user-guide-win-exported.pdf. Проверен 2026-10-28 по тексту, ссылки в CSV вида `<url>#page=N` ведут на страницу PDF. Мануал закрыл большинство строк «не проверено» (осталось 5). Как «нет» отмечено то, чего нет в полных разделах мануала по всем лентам; это относится к десктопу Windows. Cloud, Go, Vault и Sync Utility в мануале не описаны, их строки остаются на сайте и в справке. Для Mac мануал не проверялся.
- KB (kb.finaldraft.com) закрыт для прямой загрузки (403); факты оттуда взяты из выдачи поисковых сниппетов. Там, где мануал покрывает ту же функцию, источник заменён на страницу мануала.
- Расхождения с прежними находками: (1) Typewriter держит строку на 1/3 экрана, не по центру; (2) Navigator Characters не показывает «экранное время» и «взаимодействия», только число диалогов и сцен; (3) серии дней (streaks) в Writing Stats мануала нет, строка GO-03 снята в «не проверено»; (4) ответы-треды и роли в ScriptNotes относятся к Cloud, в десктопе их нет; (5) Grammarly есть и в FD13 для Windows; (6) Focus Mode не затемняет остальной текст; (7) «Automatic version saving» на деле Auto-Save плюс Auto-Backup, не история версий.
- Цены Go противоречивы на одной странице (см. п.2).
- Страница FD13 не показывает набор «Final Draft Cloud» подробно; сторонние ресерсы пишут «облачное сохранение» в FD13, официального подтверждения нет (Cloud — часть Suite).
- Fountain: нет ни импорта, ни экспорта (мануал). Movie Magic Scheduling 5+ читает FDX напрямую (https://www.finaldraft.com/downloads/manuals/fd13-user-guide-win-exported.pdf#page=53). Android и русский интерфейс: не проверено.
- Версия 13.5.0 и «Netflix-approved шаблон» взяты из описания Mac App Store.
