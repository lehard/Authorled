# Scrivener

## 1. Что это и для кого
Десктопный редактор длинных текстов (романы, сценарии, научные работы) с «переплётной» структурой: Binder, корк-доска, outliner. Сайт: https://www.literatureandlatte.com/scrivener/overview. Версии на 2026-10-27: macOS 3.5.2 (декабрь 2025), Windows 3.1.6 (сентябрь 2025), iOS 1.2.4 (https://www.literatureandlatte.com/scrivener/faqs, https://releasebot.io/updates/literature-and-latte/scrivener). Новых релизов после этого в открытых источниках не найдено.

## 2. Цена и платформы
- Разовая покупка, лицензия на каждую платформу отдельно; iOS 23.99 USD (https://www.literatureandlatte.com/store/scrivener). Цены macOS/Windows в открытых источниках не получены.
- Триал: 30 дней использования (не календарных); на iOS триала нет. Возврат 30 дней. Минорные обновления бесплатны, новая мажорная версия потребует платного апгрейда (https://www.literatureandlatte.com/scrivener/faqs).
- macOS 11+, Windows 10+ 64-bit, iOS 11+. Официального Linux нет (https://en.wikipedia.org/wiki/Scrivener_(software)). Веба нет.

## 3. Сильные стороны
Гибкая структура (Binder, Scrivenings, corkboard, outliner), сильный Compile во множество форматов, снимки версий, исследовательские материалы внутри проекта, разовая цена, офлайн. (https://www.literatureandlatte.com/scrivener/features, https://www.literatureandlatte.com/introducing-scrivener-3)

## 4. Функции по разделам
- Редактор: bold/italic, списки, картинки, таблицы, сноски, комментарии, аннотации, стили (H1, H2, свои), composition mode, split до 4 документов, поиск и замена по проекту (https://www.literatureandlatte.com/scrivener/overview). Linguistic Focus (подсветка частей речи) только на macOS (https://scrivenerville.com/scrivener-software/scrivener-3-vs-2-features-comparison/).
- Сценарии: режим сценария, переключение элементов Tab/Return, свои элементы, шаблоны Screenplay и Stage Play (https://www.imore.com/scrivener-101-how-call-shots-screenplay-mode, https://forum.literatureandlatte.com/t/importing-fountain-syntax-to-scrivener-question/141882). Нумерации сцен, ревизий, пагинации в источниках не найдено.
- Структура: Binder, drag-and-drop, метки, статусы, синопсис, collections, outliner с колонками. Корк-доска со свободным режимом и цветными линиями по меткам.
- Цели и статистика: цели по словам/символам (проект, секция, сессия), Writing History, дедлайн-цели, статистика проекта, время чтения (https://scrivenerville.com/scrivener-software/scrivener-3-vs-2-features-comparison/).
- Версии: автосохранение, snapshots со сравнением.
- Совместной работы нет в перечне функций.

## 5. ИИ
Собственного ИИ нет: в релизе 3.4.0 (2024-12-11) «Scrivener itself contains no AI»; поддержаны системные Apple Writing Tools на macOS (https://releasebot.io/updates/literature-and-latte/scrivener). L&L готовят новое более простое приложение (бета, выход перенесён на 2026, без деталей об ИИ) (https://forum.literatureandlatte.com/t/l-l-new-product/152462).

## 6. Импорт, экспорт, формат
Импорт Word, OpenOffice, текст, Final Draft, Fountain (перетаскиванием, с разбиением по сценам), изображения, PDF, медиа, web. Compile: Word, RTF, OpenOffice, PDF, текст, Final Draft, ePub, Markdown через MultiMarkdown/Pandoc, Fountain (по Wikipedia); Kindle .mobi убран в 3.5.0 (https://releasebot.io/updates/literature-and-latte/scrivener). Проект .scriv — папка; синхронизация iOS только через Dropbox, iCloud между Mac (https://forum.literatureandlatte.com/t/syncing-with-dropbox-for-ios-and-also-icloud-for-mac/41844).

## 7. Жалобы
Крутая кривая обучения, сложный Compile (https://writerunboxed.com/2018/04/05/scrivener-3s-new-approach-to-compile/, комментарии у https://www.writerscookbook.com/scrivener-3-review/); конфликты синхронизации Dropbox/iOS (форум L&L, см. заметки проекта `Дизайн писательских инструментов с ИИ/notes/prose_writing_tools.md`); разрыв Mac/Windows (Linguistic Focus только на Mac; https://forum.literatureandlatte.com/t/looking-for-a-list-of-differences-between-mac-and-windows-versions/132590).

## 8. Что взять Authorled
«Один объект, много видов» (карточки/outliner/текст над одними сущностями); автоматические снимки вместо ручных; Linguistic Focus как готовый образец подсветки; цели от дедлайна; Compile как отдельная настраиваемая стадия.

## 9. Не проверено и расхождения
Цены macOS/Windows; подчёркивание, зачёркивание, выравнивание, отступы, межстрочный интервал, спеллчек, regex, корзина, split сцен; нумерация сцен, ревизии, пагинация, автодополнение (подтверждено только слабым источником, Udemy); экспорт Fountain подтверждён только Wikipedia. Список CO-* отмечен «нет» по полноте списка функций, прямого отрицания не найдено. Руководство (PDF) недоступно для скачивания без браузера, поэтому детали редактора из мануала не сверены.
