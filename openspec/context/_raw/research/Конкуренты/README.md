# Конкуренты: разборы и таблица функций

Цель — понять, какие функции есть у писательских инструментов (сценарии, книги, ИИ-соавторы, русские площадки), и отметить, что из этого есть у Authorled.

## Файлы

- `taxonomy.csv` — список функций: `id, раздел, группа, функция`. Общий для всех разборов.
- `products/<продукт>.md` — разбор продукта по шаблону ниже.
- `products/<продукт>.csv` — оценки продукта по таксономии: `id, значение, источник, комментарий`.
- `authorled.csv` — статус Authorled и важность для нас по каждой функции.
- `Фичи.csv` — сводная таблица: функции × продукты + статус Authorled + важность. Собирается из `taxonomy.csv`, `products/*.csv` и `authorled.csv`.
- `new-features.csv` — функции, которых нет в таксономии (строки `NEW-*` из всех разборов).
- `Сводка.md` — выводы.

## Значения в `products/*.csv`

- `есть` — функция есть и подтверждена источником.
- `частично` — есть в урезанном виде, на платном тарифе-надстройке или через плагин; пояснение в комментарии.
- `нет` — источник прямо говорит, что функции нет, или полный список функций её не содержит.
- `не проверено` — подтверждения не нашлось. Не угадываем.

Новые функции, которых нет в таксономии, добавляются строками с id `NEW-<раздел>-<n>` и названием в комментарии.

## Статусы Authorled

- `в коде` — работает в `web/` или в API.
- `в макете` — нарисовано в `_raw/design/kabinet/`.
- `в спеке` — описано в `openspec/specs` или контексте, но не нарисовано.
- `нет` — нигде нет.
- `не делаем` — осознанно вне продукта.

Важность: `must-have`, `nice-to-have`, `не нужно` — предложение агента, решает владелец.

## Шаблон разбора продукта

1. Что это и для кого (одна-две фразы), сайт, версия и дата проверки.
2. Цена и тарифы, платформы.
3. Сильные стороны и чем выделяется.
4. Функции по разделам таксономии — коротко, со ссылками.
5. ИИ: что умеет, как оплачивается, как подан в интерфейсе.
6. Импорт, экспорт, формат файлов.
7. Жалобы пользователей (отзывы, форумы).
8. Что взять Authorled.
9. Не проверено и расхождения в источниках.

## Метод

Только открытые источники: сайт, справка, changelog, обзоры, отзывы. Аккаунты и триалы не создавались. Дата сбора — 2026-10-27.
