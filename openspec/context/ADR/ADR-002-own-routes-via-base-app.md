# ADR-002: Свои продуктовые маршруты в приложении AgentOS
## Status: Accepted
## Context
Шаблон AgentOS запрещает собственные маршруты FastAPI. Но продуктовые действия (проекты, документы, правки, утверждение, файлы, поиск) не должны идти через LLM, а утверждение должно быть доступно только автору.
## Decision
Свои маршруты подключаются в приложение, которое возвращает `agent_os.get_app()`: роутер под `/api/v1/` ставится перед монтированием MCP на корень. Параметр `base_app` не используется: с ним Agno 3.1.10 не ставит свои обработчики ошибок на свои маршруты (уточнено 2026-11-01, change `user-cabinet`). Ядро доступно маршрутам как код, агенту — как MCP-инструменты. Утверждение документа — только маршрут; у агента такого инструмента нет.
## Consequences
Отменяет правило шаблона «своих маршрутов нет» (`openspec/specs/overview`, `CLAUDE.md`) — их нужно обновить через change. AgentOS остаётся единым шлюзом.
