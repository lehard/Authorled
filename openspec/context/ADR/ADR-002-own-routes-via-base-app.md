# ADR-002: Свои продуктовые маршруты через base_app
## Status: Accepted
## Context
Шаблон AgentOS запрещает собственные маршруты FastAPI. Но продуктовые действия (проекты, документы, правки, утверждение, файлы, поиск) не должны идти через LLM, а утверждение должно быть доступно только автору.
## Decision
Свои маршруты подключаются в AgentOS через `base_app`. Ядро доступно маршрутам как код, агенту — как MCP-инструменты. Утверждение документа — только маршрут; у агента такого инструмента нет.
## Consequences
Отменяет правило шаблона «своих маршрутов нет» (`openspec/specs/overview`, `CLAUDE.md`) — их нужно обновить через change. AgentOS остаётся единым шлюзом.
