## MODIFIED Requirements

### Requirement: Действия навигатора
У узлов навигатора MUST быть меню (правый клик и кнопка «⋮») с действиями узла: добавить документ в группу, сортировать по алфавиту, открыть, удалить в корзину, очистить корзину. Кнопка «Добавить документ» MUST создавать персонажа, локацию, мир или заметку и MUST давать «Загрузить файл» в заметки; пустое имя MUST давать ошибку. У раздела «Заметки» в меню MUST быть «Загрузить файл». Вне раздела «Заметки» добавить свободный документ или папку MUST NOT быть возможно.

#### Scenario: Пустое имя
- GIVEN открыт диалог «Добавить документ»
- WHEN пользователь сохраняет персонажа без имени
- THEN MUST показаться ошибка у поля имени, и документ MUST NOT создаваться

#### Scenario: Заметка из «Добавить документ»
- GIVEN открыт диалог «Добавить документ»
- WHEN автор выбирает «Заметка», вводит «Финал» и добавляет
- THEN заметка MUST появиться в разделе «Заметки», раздел MUST раскрыться, и MUST открыться заметка

#### Scenario: Заметка без названия
- GIVEN открыт диалог «Добавить документ» с выбранной заметкой
- WHEN автор добавляет её без названия
- THEN MUST показаться ошибка у поля названия, и заметка MUST NOT создаваться

#### Scenario: Файл из меню раздела
- GIVEN источник `api`
- WHEN автор выбирает «Загрузить файл» в меню раздела «Заметки» и выбирает `Эпоха.pdf`
- THEN заметка «Эпоха» MUST появиться в разделе, раздел MUST раскрыться, и MUST открыться заметка

## ADDED Requirements

### Requirement: Загрузка файла в заметки
«Загрузить файл» MUST быть в меню раздела «Заметки», на странице списка заметок и в «Добавить документ». Выбор MUST принимать DOCX, PDF, TXT, MD, Fountain, FDX и STARC. Пока файл проверяется, экран MUST показывать, что идёт загрузка. Отказ (тип, размер, антивирус, нечитаемый файл, длина текста, место по тарифу) MUST показываться с причиной из ответа, и заметка MUST NOT появляться. С источником `fixtures` загрузка MUST давать отказ с причиной.

#### Scenario: Место кончилось
- GIVEN место для оригиналов заметок занято до предела
- WHEN автор загружает файл в заметки
- THEN экран MUST показать причину с занятым местом и пределом, и заметка MUST NOT появиться

#### Scenario: Скан
- WHEN автор загружает PDF из одних сканов
- THEN экран MUST показать, что в файле нет текста

### Requirement: Оригинал заметки
Заметка с оригиналом MUST показывать над текстом имя файла, его размер и «Скачать оригинал», которое MUST скачивать файл с исходным именем. Текст такой заметки MUST правиться как у обычной заметки. Отдельного удаления оригинала MUST NOT быть: он уходит в корзину и удаляется вместе с заметкой. Заметка без оригинала MUST выглядеть как раньше.

#### Scenario: Скачать оригинал
- GIVEN открыта заметка «Эпоха» из `Эпоха.pdf`
- WHEN автор нажимает «Скачать оригинал»
- THEN MUST скачаться `Эпоха.pdf` с теми же байтами

#### Scenario: Обычная заметка
- GIVEN открыта заметка «Финал» без оригинала
- WHEN автор смотрит на заметку
- THEN «Скачать оригинал» MUST NOT быть

### Requirement: Файл чата в заметки
У каждого прикреплённого и проверенного файла в поле ввода чата MUST быть действие «В заметки». Оно MUST создавать заметку из этого файла, MUST показывать, что заметка создана, с переходом к ней, и MUST оставлять файл прикреплённым к сообщению. Отказ MUST показываться под полем с причиной.

#### Scenario: Сохранить и спросить
- GIVEN автор прикрепил `Эпоха.pdf` к сообщению
- WHEN он выбирает «В заметки» у файла
- THEN в разделе «Заметки» MUST появиться «Эпоха», а файл MUST остаться в поле ввода
