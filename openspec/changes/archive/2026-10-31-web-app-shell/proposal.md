# Proposal

## Why

Интерфейс писателя пока существует только как HTML-макет v2 (`openspec/context/_raw/design/kabinet-starc/`), а `web/` показывает одну витрину дизайн-системы. Владелец решил 2026-10-31: сначала собрать полноценный фронт на React по макету v2, а форк редактора (`fork-screenplay-editor`) встраивать уже в готовое приложение. Фундамент `web/` (дизайн-система, проверки, сборка, компоненты shadcn) сохраняется; заново пишется приложение поверх него.

Это первый из четырёх этапов:
1. каркас приложения — этот change;
2. чат с агентом CopilotKit v2 через AG-UI;
3. редактор сценария (`fork-screenplay-editor`);
4. поэпизодник, карточки, драфты, комментарии, предложения правок, поиск.

## What Changes

- Каркас на Refine (ADR-004) и React Router: адреса `/`, `/trash`, `/p/:projectId/:doc`, `/showcase`, `/auth/callback`; неизвестный адрес — страница «Не найдено».
- Вход через Authentik по OIDC с PKCE (спека `auth`, требование «Вход фронтенда»): без входа приложение уводит на страницу входа Authentik, после входа возвращает на исходный адрес; выход. Настройки берутся из корневого `.env` (`AUTH_ISSUER`, `AUTH_FRONTEND_CLIENT_ID`, `AUTH_FRONTEND_REDIRECT_URI`); без них — экран ошибки с именем переменной.
- Данные — через провайдер данных Refine. Продуктовых маршрутов бэкенда ещё нет, поэтому единственный источник на этом этапе — данные примера из макета v2 в памяти страницы, который включается явно (`VITE_DATA_SOURCE=fixtures`); другое значение или его отсутствие — ошибка. Замена на API бэкенда — один новый провайдер, экраны не меняются.
- Экраны по макету v2:
  - полка историй: создать, переименовать, удалить в корзину;
  - корзина историй: восстановить, удалить навсегда;
  - окно истории в три колонки: навигатор, рабочее поле, колонка чата; на узком экране навигатор выезжает, чат — лист снизу;
  - навигатор: история, персонажи, локации, миры, сценарий (титульная страница, синопсис, текст), корзина; меню узла; «Добавить документ» (персонаж, локация, мир);
  - документы: история, сценарий, титульная страница, синопсис, списки и профили персонажей, локаций и миров, корзина истории;
  - текст сценария — только чтение (редактор — этап 3);
  - колонка чата — заголовок и пустое состояние (чат — этап 2).
- Витрина дизайн-системы переезжает с корня на `/showcase`.
- **BREAKING**: удаляются `StatusBadge` и `statuses.ts` — методологию Д1–Д22 в интерфейсе не показываем (решение 2026-10-31); токены `--status-*` остаются.
- Телеметрия Refine выключена; приложение не обращается к сторонним хостам.

## Scope

- `web/src/` — приложение (`app/`), экраны, провайдер данных примера, вход; `web/src/showcase/` — новый адрес и без статусов; `web/src/design-system/` — удаление статусов.
- `web/package.json`, `package-lock.json` — Refine, React Router, `oidc-client-ts`.
- `web/vite.config.ts` — передача трёх переменных входа из корневого `.env`.
- `auth/blueprints/20-oidc.yaml` — scope `offline_access`, чтобы фронтенд продлевал сессию refresh-токеном (Access Token живёт 10 минут); `example.env` — `VITE_DATA_SOURCE=fixtures`.
- `.claude/launch.json` и README `web/` — адрес `http://localhost:5173` (совпадает с `AUTH_FRONTEND_REDIRECT_URI`).
- Спеки: новая `web/workspace`, дельты `web/app` и `web/design-system`.
- Проверки и ограничения — в `tmp/VERIFY.md`.

## Non-goals

- Бэкенд: продуктовые маршруты историй и документов, схема БД, AG-UI. Провайдер данных API — когда появятся маршруты.
- Чат CopilotKit, файлы в чат (этап 2).
- Редактор сценария, поэпизодник, карточки, драфты и сравнение, рецензирование, предложения правок, поиск и замена, автодополнение, сбор персонажей из текста (этапы 3–4).
- Импорт и экспорт файлов, обложка истории.
- Экраны входа из макета v1 (код из письма) — позже, через настройку шагов входа Authentik.
- Настройки и переключатель темы в приложении (скрыты, как в макете). Тема работает как сейчас: по настройке системы или по выбору, сохранённому переключателем на витрине.
- Перетаскивание сцен и документов.
- Правка `openspec/changes/archive/**`.

## Capabilities

### New Capabilities
- `web/workspace`: рабочее место писателя: вход, адреса экранов, источник данных, полка и корзина историй, окно истории, навигатор, документы истории, текст сценария для чтения, место чата.

### Modified Capabilities
- `web/app`: сервер разработки открывается по адресу, совпадающему с адресом возврата входа; без телеметрии каркаса; обязательные настройки входа и источника данных.
- `web/design-system`: витрина на `/showcase`, без статусов; требование «Статусы документов» удаляется.

## Impact

- `web/` получает зависимости `@refinedev/core`, `@refinedev/react-router`, `react-router` 7, `@tanstack/react-query`, `oidc-client-ts`.
- Для входа нужен запущенный Authentik (`docker compose up -d`) и заполненные `AUTH_*` в `.env`.
- Change `kabinet-palette-tokens` меняет то же требование «Витрина»; его нужно архивировать раньше этого (текст дельты здесь построен на его версии).
- `fork-screenplay-editor` после этого change встраивает редактор в экран «Текст сценария», а не только на витрину (`/opsx:update`).
