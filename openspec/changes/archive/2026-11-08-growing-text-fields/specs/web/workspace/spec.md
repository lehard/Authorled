## ADDED Requirements

### Requirement: Поле ввода чата растёт с текстом
Пустое поле ввода чата соавтора MUST быть высотой в одну строку и MUST расти с текстом (спека `web/design-system`, «Многострочные поля растут с текстом») до трети высоты окна. После отправки поле MUST снова стать в одну строку. Если в поле остался текст, поле MUST сразу быть высотой под него. Клавиши, скрепка и «Отправить» MUST работать как прежде.

#### Scenario: Длинное сообщение видно целиком
- GIVEN открыто окно истории в Safari на macOS Ventura (WebKit 18), поле ввода чата пустое и высотой в одну строку
- WHEN автор пишет «Добавь персонажа Василия, который бомж и дикий шизанутый» и текст переносится на три строки
- THEN поле MUST вырасти до трёх строк, и все три строки MUST быть видны без прокрутки

#### Scenario: Предел трети окна
- GIVEN окно высотой 900 px
- WHEN автор вставляет в поле ввода чата текст из сорока строк
- THEN поле MUST быть не выше 300 px, внутри MUST появиться прокрутка, и каретка в конце текста MUST быть видна

#### Scenario: После отправки
- GIVEN в поле ввода чата пять строк
- WHEN автор нажимает Enter и сообщение уходит
- THEN поле MUST стать пустым и высотой в одну строку

#### Scenario: Текст остался в поле
- GIVEN в поле ввода чата четыре строки, и колонка чата скрыта
- WHEN автор снова открывает колонку чата
- THEN поле MUST быть высотой в четыре строки и показывать прежний текст

### Requirement: Высота полей документов и комментариев
Многострочные поля окна истории MUST расти с текстом с такими пределами:
- комментарий и ответ в ветке — от 2 строк до трети высоты окна;
- поле профиля — от нынешних 3–4 строк, без предела;
- биты сцены — от 4 строк, без предела;
- текстовые части сценария и заметка — от нынешних ~320 px, без предела.

#### Scenario: Длинный синопсис в Safari
- GIVEN в WebKit 18 открыт синопсис из тридцати абзацев
- WHEN автор прокручивает документ до конца
- THEN прокручиваться MUST страница, весь текст MUST быть виден без прокрутки внутри поля

#### Scenario: Длинный комментарий
- GIVEN окно высотой 900 px, автор пишет комментарий к фрагменту
- WHEN текст комментария становится выше 300 px
- THEN поле MUST остановиться на 300 px и прокручиваться внутри, каретка MUST быть видна

#### Scenario: Поле профиля растёт
- GIVEN в WebKit 18 открыт профиль персонажа
- WHEN автор пишет в многострочное поле профиля восемь строк
- THEN поле MUST вырасти до восьми строк без прокрутки внутри
