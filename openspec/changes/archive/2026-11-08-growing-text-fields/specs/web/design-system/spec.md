## ADDED Requirements

### Requirement: Многострочные поля растут с текстом
Многострочное поле MUST расти вместе с текстом в Safari (WebKit) 17 и новее и в Chrome (Chromium): при наборе, вставке, смене значения и изменении ширины поля. Наименьшую высоту в строках и предел роста (в строках, долей высоты окна или «без предела») MUST задавать каждое место. До предела поле MUST NOT прокручиваться внутри; дальше предела MUST прокручиваться внутри, и каретка MUST оставаться видна. Длинное слово MUST переноситься без прокрутки вбок.

#### Scenario: Поле растёт в Safari
- GIVEN открыто окно истории в WebKit 18, поле с наименьшей высотой в 1 строку и пределом в треть окна
- WHEN автор набирает пять строк через Shift+Enter
- THEN поле MUST вырасти до пяти строк, и внутри поля MUST NOT быть прокрутки

#### Scenario: Предел роста
- GIVEN поле с пределом в треть окна
- WHEN автор вставляет текст выше трети окна
- THEN поле MUST остановиться на трети окна, внутри MUST появиться прокрутка, и каретка в конце текста MUST быть видна

#### Scenario: Поле без предела
- GIVEN в WebKit 18 открыт синопсис, текст которого выше окна
- WHEN автор прокручивает документ
- THEN прокручиваться MUST страница, а поле MUST быть высотой во весь текст, без прокрутки внутри

#### Scenario: Ширина меняется
- GIVEN в поле три строки текста, и окно сужается так, что текст переносится на пять строк
- WHEN ширина поля изменилась
- THEN поле MUST стать высотой в пять строк без ввода автора

### Requirement: Одно многострочное поле
Каждое многострочное поле интерфейса MUST быть общим полем дизайн-системы. В `web/src` MUST NOT быть элемента `<textarea>` вне общего поля и CSS-свойства `field-sizing`.

#### Scenario: Поле вне компонента
- GIVEN в файле `web/src` есть элемент `<textarea>` вне общего поля или свойство `field-sizing`
- WHEN выполняется `./scripts/validate.sh`
- THEN проверка `check:native-ui` MUST завершиться ошибкой, называющей файл
