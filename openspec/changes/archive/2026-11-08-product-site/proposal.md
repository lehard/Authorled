# Proposal: сайт продукта Authorled

Источник решений: `business-intents/product-site.md` (согласовано владельцем 2026-11-08).

## Why

У продукта нет своего сайта: на `coauthor.glavai.ru` сразу открывается сервис с полкой историй. Показать продукт новому человеку нечем, и некуда вести его, чтобы он оставил заявку в закрытую бету и потом вошёл. Владелец выбрал схему «сайт в корне своего домена, сервис и вход на поддоменах»; домен появится позже, поэтому сейчас готовим сайт и смотрим его локально.

## What Changes

- **Новый модуль `site/`** — четвёртый модуль монорепозитория рядом с `agno/`, `web/`, `auth/`: статический сайт продукта, страницы заранее собраны в HTML (title, description, Open Graph, canonical, `sitemap.xml`, `robots.txt`, 404). Своего сервера и своих данных у сайта нет.
- **Страницы:** главная (суть продукта, принцип «ИИ предлагает, автор решает», возможности беты, методология из 22 этапов с пометкой «скоро», скриншоты, вопросы и ответы, «Войти» и «Хочу в бету»), политика обработки персональных данных, 404.
- **Общий вид с сервисом:** сайт берёт токены, тему «Утро» и шрифты из `web/src/design-system`, не копируя их; цвета только семантическими токенами.
- **Заявка в бету:** форма на сайте (почта, имя, кто вы, согласие) отправляет заявку новым маршрутом ядра `POST /api/v1/beta-requests` **без токена**. Ядро хранит заявки в таблице `authorled.beta_requests`; повторная заявка с той же почтой не создаёт дубль; общий поток заявок ограничен по частоте.
- **Команда администратора `beta-requests`:** `python -m admin beta-requests` печатает список заявок; скрипт `./scripts/usage.sh local|prod` её запускает.
- **Маршрут без токена:** проверка токена Agno пропускает только этот маршрут (`excluded_route_paths`), остальные защищённые маршруты не меняются.
- **Проверки:** `validate.sh` проверяет и собирает `site/` (формат, линт, типы, сборка, сырые цвета); CI ставит зависимости сайта.
- **Скиллы:** `landing-page-design`, `copywriting`, `unslop` из репозитория glavai копируются в `.agents/skills/`.
- **Правило процесса:** в `AGENTS.md` — тексты и картинки в `site/` меняются без OpenSpec; новые страницы, формы, сборка и всё, что трогает ядро, — через OpenSpec. Там же `site/` в «Where changes belong».
- Выкладки сайта нет: до домена он только локальный (`npm run dev --prefix site`).

## Capabilities

### New Capabilities
- `web/site`: сайт продукта — модуль `site/`, страницы и их содержание, сборка в готовый HTML, настройки сборки, общий вид с дизайн-системой, форма заявки, локальный запуск.
- `api/beta-requests`: маршрут `POST /api/v1/beta-requests` — тело, проверки, ответы, отказы, ограничение частоты, доступ без токена.

### Modified Capabilities
- `core/database`: новая таблица заявок в бету в схеме `authorled`.
- `core/subscriptions`: «Команды администратора» — добавляется команда списка заявок.
- `auth`: новое требование «Маршруты без токена» — исключение из проверки ровно для маршрута заявки.
- `architecture`: «Раскладка монорепозитория» — четвёртый модуль `site/`.

## Scope

- `site/` целиком: Vite + React + TypeScript, сборка страниц в HTML, Tailwind с токенами `web/src/design-system`, свои `package.json` и `package-lock.json` с точными версиями.
- `agno/core/` (операции заявок), `agno/core/tables.py`, `agno/migrations/` (миграция `0011`), `agno/app/api/` (маршрут), `agno/app/auth/authorization.py` (исключённый путь), `agno/admin/`, `scripts/usage.sh`, тесты ядра в `agno/tests/`.
- `scripts/validate.sh`, `scripts/format.sh`, `.github/workflows/validate.yml`, `example.env` (настройки сайта), `web/scripts/check_web_tokens.sh` (проверка и `site/`).
- `.agents/skills/` (три скилла), `AGENTS.md`, `README.md` (как запустить сайт).
- Мастер-спеки по списку выше.

## Non-goals

- Домен, DNS, Caddy для сайта, выкладка сайта на сервер, временный адрес; перенос сервиса на `app.<домен>` и входа на `auth.<домен>`, переадресации — отдельный интент, когда будет домен.
- Яндекс Метрика (вместе с доменом), страница тарифов и оплата, блог, английская версия.
- Регистрация на сайте; приглашение из заявки одной кнопкой — в бету по-прежнему добавляют через `AUTH_ALLOWED_EMAILS`.
- Письма по заявке (заявителю или владельцу), уведомления в Telegram.
- Изменения в сервисе `web/` и в токенах дизайн-системы.

## Impact

- **API:** новый публичный маршрут `POST /api/v1/beta-requests`; в OpenAPI появляется его контракт. Остальные маршруты и их проверка токена не меняются.
- **База:** миграция `0011_beta_requests`, только схема `authorled`, вперёд.
- **Персональные данные:** почта и имя заявителя — новые ПДн, они хранятся на сервере продукта, который сейчас в Финляндии (принятый риск владельца 2026-11-06 касается тестировщиков из белого списка). Сайт до домена не выкладывается, но маршрут попадёт на сервер с ближайшим релизом API.
- **Разработка:** второй фронтенд-модуль со своими `node_modules`; `validate.sh` требует `npm ci --prefix site`.
- **Процесс:** исключение OpenSpec для текстов и картинок `site/`.
