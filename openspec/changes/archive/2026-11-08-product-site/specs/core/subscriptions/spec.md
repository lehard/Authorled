## MODIFIED Requirements

### Requirement: Команды администратора
Скрипт администратора MUST требовать цель (`local` или `prod`) и выполнять команды в контейнере API через операции ядра:
- `report` — по каждому неудалённому пользователю почта, тариф, начало и конец текущего периода, число запусков, токены (вход, кэш, выход), расход в рублях, лимит, остаток и сумма LiteLLM в долларах за период;
- `set-plan <почта> <тариф>` — смена тарифа пользователя с этой почтой;
- `beta-requests` — список заявок в бету от новых к старым: время заявки (UTC), почта, имя, кто (сценарист, писатель, другое) и отметка, есть ли уже неудалённый пользователь с этой почтой.
Если неудалённых пользователей с почтой нет или их больше одного, `set-plan` MUST завершаться ошибкой и ничего не менять. Других ручных настроек лимита MUST NOT быть. `beta-requests` MUST только читать и при отсутствии заявок MUST печатать, что заявок нет, и завершаться кодом `0`.

#### Scenario: Отчёт
- GIVEN у пользователя за период два запуска соавтора
- WHEN администратор выполняет `report`
- THEN строка пользователя MUST показывать 2 запуска, сумму их токенов и расход, а остаток MUST быть лимитом минус расход

#### Scenario: Неизвестная почта
- GIVEN нет пользователя с почтой `nobody@example.com`
- WHEN администратор выполняет `set-plan nobody@example.com beta`
- THEN команда MUST завершиться ненулевым кодом с сообщением о почте

#### Scenario: Список заявок
- GIVEN есть заявки `anna@example.com` (вчера) и `boris@example.com` (сегодня), пользователь `anna@example.com` уже зарегистрирован
- WHEN администратор выполняет `beta-requests`
- THEN первой MUST идти строка `boris@example.com`, второй — `anna@example.com`
- AND у `anna@example.com` MUST стоять отметка, что пользователь уже есть

#### Scenario: Заявок нет
- GIVEN заявок нет
- WHEN администратор выполняет `beta-requests`
- THEN команда MUST напечатать, что заявок нет, и завершиться кодом `0`
