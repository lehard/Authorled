## ADDED Requirements

### Requirement: Выход к полке
Наверху навигатора истории, над её названием, MUST быть строка «Все истории» со стрелкой назад. Клик по строке MUST открывать полку `/` без перезагрузки страницы. Строка MUST быть видна и в дереве документов, и в списке сцен.

#### Scenario: Выход из документа
- GIVEN открыт текст сценария истории «Тихая вода»
- WHEN пользователь нажимает «Все истории»
- THEN MUST открыться полка, и на ней MUST быть «Тихая вода»

#### Scenario: Выход из списка сцен
- GIVEN в навигаторе открыт список сцен «Текста сценария»
- WHEN пользователь нажимает «Все истории»
- THEN MUST открыться полка

#### Scenario: Выход на узком экране
- GIVEN окно шириной 375 px и открыт навигатор
- WHEN пользователь нажимает «Все истории»
- THEN MUST открыться полка, и навигатор MUST закрыться

#### Scenario: Правка перед выходом
- GIVEN автор только что допечатал фразу в «Тексте сценария»
- WHEN он сразу нажимает «Все истории» и снова открывает историю
- THEN фраза MUST быть в тексте
