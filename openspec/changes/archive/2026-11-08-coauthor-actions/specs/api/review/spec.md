## MODIFIED Requirements

### Requirement: Ветка комментария
`POST /api/v1/documents/{id}/comments` MUST создавать ветку к фрагменту текста сценария: `id` (совпадает с id метки `comment` в тексте), `quote` (цитата фрагмента) и непустой текст первого сообщения. Автор сообщения — вызывающий (`author_kind` `user`), `author_role` — его роль на момент записи. У ветки, созданной так, `scene_uid` пустой; ветку с `scene_uid` создаёт только соавтор инструментом ядра (`api/agents`, «Комментарий соавтором»). Повторный `id` в истории MUST давать `409`; пустой текст — `422`. Драфт MUST NOT принимать комментарии: `409`.

#### Scenario: Новая ветка
- WHEN автор создаёт ветку `c1` с цитатой «Вера смотрит на воду» и текстом «Слишком прямо»
- THEN `GET /api/v1/documents/{id}/comments` MUST вернуть ветку `c1` с одним сообщением автора

#### Scenario: Пустой комментарий
- WHEN автор создаёт ветку с пустым текстом
- THEN ответ MUST быть `422`, ветка MUST NOT создаваться

### Requirement: Список комментариев
`GET /api/v1/documents/{id}/comments` MUST возвращать все ветки документа: `id`, `quote`, `scene_uid` (`null` у веток автора), `resolved_at`, сообщения по времени (`id`, `author_kind` — `user` или `coauthor`, автор, `author_role`, `body`, `created_at`, `edited_at`) и признак, что сообщение принадлежит вызывающему. У сообщения соавтора `author_id` MUST быть `null`, имя автора — «Соавтор», признак собственного сообщения — ложь.

#### Scenario: Свои сообщения
- WHEN в ветке есть сообщения автора
- THEN у них MUST быть признак собственного сообщения

#### Scenario: Сообщение соавтора
- GIVEN соавтор оставил комментарий к цитате «Вера молчит» сцены `s3`
- WHEN автор запрашивает список комментариев
- THEN ветка MUST иметь `scene_uid` `s3`, а её сообщение — `author_kind` `coauthor`, имя «Соавтор», `author_id` `null` и признак собственного сообщения `false`

### Requirement: Ответы и правка сообщений
`POST /api/v1/comments/{id}/replies` MUST добавлять непустой ответ в ветку. `PATCH` и `DELETE` `/api/v1/comments/{id}/messages/{message_id}` MUST менять и удалять только собственное сообщение (`edited_at` заполняется); чужое — `403`. Сообщение соавтора MUST NOT меняться (`403`), а удаление его MUST проходить у любого пользователя с доступом к истории: соавтор работает на автора, и автор убирает его ветку так же, как свою. Удаление первого сообщения MUST удалять ветку целиком.

#### Scenario: Правка чужого
- WHEN пользователь пытается изменить сообщение другого пользователя
- THEN ответ MUST быть `403`, сообщение MUST NOT меняться

#### Scenario: Удаление первого сообщения
- WHEN автор удаляет первое сообщение ветки с двумя ответами
- THEN ветки MUST NOT остаться в списке

#### Scenario: Правка сообщения соавтора
- GIVEN в ветке есть сообщение соавтора
- WHEN автор пытается изменить его
- THEN ответ MUST быть `403`, сообщение MUST NOT меняться

#### Scenario: Удаление ветки соавтора
- GIVEN ветка начинается сообщением соавтора
- WHEN автор удаляет это сообщение
- THEN ветки MUST NOT остаться в списке
