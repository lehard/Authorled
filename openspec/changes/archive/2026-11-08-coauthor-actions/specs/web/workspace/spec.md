## MODIFIED Requirements

### Requirement: Ветка комментария
Клик по подсвеченному фрагменту MUST открывать карточку ветки рядом с текстом, не закрывая чат: цитату фрагмента, комментарии с автором, ролью и временем, поле ответа, «Решено», «Удалить пометку». Свои комментарии MUST правиться и удаляться. Сообщение соавтора MUST подписываться «Соавтор» и MUST NOT предлагать правку; «Удалить пометку» в ветке соавтора MUST удалять её так же, как ветку автора. Escape, ✕ и клик мимо карточки MUST её закрывать.

#### Scenario: Ответ редактору
- GIVEN открыт `/p/water/text`, в реплике Веры есть комментарий Ирины Беловой
- WHEN автор кликает по фрагменту и отвечает «Подумаю»
- THEN в ветке MUST появиться ответ автора с его именем и временем

#### Scenario: Ветка соавтора
- GIVEN соавтор оставил комментарий «Здесь пауза важнее реплики» к «Вера молчит»
- WHEN автор кликает по подсвеченному фрагменту
- THEN карточка MUST показать комментарий с подписью «Соавтор» без кнопки правки, а поле ответа и «Решено» MUST работать

## ADDED Requirements

### Requirement: Режим соавтора в чате
У поля ввода чата MUST быть переключатель режима соавтора: «Спрашивать» (`ask`) и «Сам» (`auto`), выбран сохранённый в аккаунте. Выбор MUST сохраняться через `PATCH /api/v1/me` и действовать во всех беседах. В режиме «Сам» чат MUST отвечать на паузу соавтора «Разрешить» сразу, без карточки. Если сохранение не удалось, MUST показываться причина, и переключатель MUST вернуться к сохранённому режиму.

#### Scenario: Режим на другом устройстве
- GIVEN автор выбрал «Сам» в одном браузере
- WHEN он открывает историю в другом браузере
- THEN переключатель MUST показывать «Сам»

#### Scenario: Сохранение не удалось
- GIVEN API отвечает ошибкой на `PATCH /api/v1/me`
- WHEN автор выбирает «Сам»
- THEN под переключателем MUST показаться причина, и переключатель MUST вернуться к «Спрашивать»

### Requirement: Подтверждение действия соавтора
Когда в режиме «Спрашивать» запуск соавтора встал на паузу перед действием, чат MUST показать карточку с тем, что соавтор хочет сделать (вид действия, название сущности, меняемые поля или цитата), и кнопками «Разрешить» и «Отклонить». Ответ MUST уходить соавтору, и запуск MUST продолжаться в той же беседе. Пока карточка ждёт ответа, отправить новое сообщение MUST NOT быть возможно.

#### Scenario: Разрешить
- GIVEN режим «Спрашивать», и автор написал «заведи персонажа Пётр, брат Веры»
- WHEN в чате появляется карточка «Создать персонажа «Пётр»», и автор нажимает «Разрешить»
- THEN «Пётр» MUST появиться в навигаторе без перезагрузки страницы, а соавтор MUST продолжить ответ

#### Scenario: Отклонить
- GIVEN в чате карточка «Создать заметку «Финал»»
- WHEN автор нажимает «Отклонить»
- THEN заметки MUST NOT появиться, карточка MUST показать «Отклонено», а соавтор MUST продолжить ответ

#### Scenario: Сообщение во время ожидания
- GIVEN карточка подтверждения ждёт ответа
- WHEN автор нажимает Enter в поле ввода
- THEN сообщение MUST NOT отправиться, пока автор не ответил на карточку

### Requirement: Сделанное соавтором в чате
После каждого выполненного действия соавтора чат MUST показывать в ответе строку о сделанном («Создан персонаж «Пётр»», «Изменено: «Вера»», «Комментарий к «Вера молчит»») со ссылкой, которая открывает созданную или изменённую сущность. Отказ ядра MUST показываться строкой с причиной без ссылки.

#### Scenario: Ссылка на персонажа
- GIVEN режим «Сам», и соавтор создал персонажа «Пётр»
- WHEN автор нажимает ссылку в строке «Создан персонаж «Пётр»»
- THEN MUST открыться карточка персонажа «Пётр»

#### Scenario: Отказ
- GIVEN драфт заперт, и соавтор попытался создать заметку
- WHEN запуск закончился
- THEN в ответе MUST быть строка с причиной отказа и MUST NOT быть ссылки

### Requirement: Экраны после действия соавтора
После каждого действия соавтора навигатор, список заметок, комментарии и затронутая открытая карточка или заметка MUST показывать новые данные без перезагрузки страницы. В открытой карточке или заметке поле, которое автор не менял, MUST принять новое значение, а поле с вводом автора MUST сохранить его ввод. Если сохранение автора ушло со старой ревизией, MUST работать путь конфликта ревизий, как при правке в другой вкладке.

#### Scenario: Открытая карточка
- GIVEN открыта карточка «Вера» без несохранённого ввода
- WHEN соавтор меняет её поле «Главный страх»
- THEN поле MUST показать новое значение без перезагрузки

#### Scenario: Несохранённый ввод
- GIVEN автор печатает в описании «Веры», и сохранение ещё не ушло
- WHEN соавтор меняет поле «Главный страх» этой карточки
- THEN ввод автора MUST остаться в описании, а «Главный страх» MUST показать значение соавтора

### Requirement: Комментарий соавтора по якорю
Открытая ветка соавтора без метки в тексте MUST ставиться в «Текст сценария» по якорю: в сцене с её `scene_uid` MUST находиться первое вхождение цитаты внутри одного абзаца, и на него MUST ставиться метка комментария с id ветки, которая сохраняется с текстом и MUST NOT попадать в отмену правок. Метка MUST ставиться один раз. Если якорь не найден, ветка MUST NOT ставиться и MUST показываться в списке комментариев с «Фрагмента в тексте нет».

#### Scenario: Комментарий из чата
- GIVEN открыт «Текст сценария» со сценой `s3`, где есть «Вера молчит.»
- WHEN соавтор комментирует «Вера молчит»
- THEN фрагмент MUST подсветиться без перезагрузки страницы, а счётчик открытых комментариев MUST увеличиться на 1

#### Scenario: Цитату переписали
- GIVEN соавтор оставил комментарий к «Вера молчит», а автор уже переписал эту строку
- WHEN открыт «Текст сценария»
- THEN метка MUST NOT ставиться, а ветка MUST быть в списке комментариев с «Фрагмента в тексте нет»
