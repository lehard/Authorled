# Proposal

## Why

Заметка из файла показывает автору не файл, а текст, извлечённый для соавтора: PDF с разорванными строками, Markdown с `#` и `**`. Оригинал можно только скачать (владелец, 2026-11-10: «за наш интерфейс стыдно»). Материалы — опора соавтора, и автор должен видеть, что именно загрузил. Решения согласованы в `business-intents/note-originals-view.md`.

## What Changes

- У заметки с оригиналом PDF, DOCX или MD две вкладки: «Оригинал» (открыта по умолчанию) и «Текст для соавтора» (правка текста, как сейчас; режим чтения длинного материала остаётся). Поиск по истории открывает вкладку текста.
- Оригинал показывается по формату: PDF — просмотрщиком браузера во фрейме и «Открыть в новой вкладке»; DOCX — оформленным документом (заголовки, списки, таблицы, жирный, курсив) нашими шрифтами, HTML очищается; MD — отрисованным Markdown. У TXT, Fountain, FDX и STARC вкладок нет: показывается текст для соавтора с подписью, что его видит соавтор.
- Новое действие «Удалить оригинал, оставить текст»: оригинал удаляется навсегда, место по тарифу освобождается, заметка становится обычной. Маршрут `DELETE /api/v1/notes/{id}/file` с `If-Match`.
- Новое действие «Вернуть текст из оригинала»: текст заметки заменяется заново извлечённым из оригинала. Маршрут `POST /api/v1/notes/{id}/text-from-file` с `If-Match`.
- Извлечение текста из PDF склеивает строки страницы в абзацы и убирает перенос слов по дефису. Действует на новые загрузки, на файлы чата и на «Вернуть текст из оригинала»; старые заметки не переписываются.
- Шапка заметки: название правится прямо в заголовке, карточка «Название» уходит; имя файла, размер и «Скачать» — одна строка под заголовком. Лист текста получает отступы и ширину шапки.
- В навигаторе у заметки с оригиналом значок вида файла (PDF, DOCX, текст, сценарий) вместо значка заметки.
- Справка соавтора о сервисе описывает новый экран заметки.

## Capabilities

### New Capabilities
- нет

### Modified Capabilities
- `api/stories`: два новых действия над заметкой с оригиналом — удалить оригинал и вернуть текст из оригинала.
- `api/files`: извлечение текста из PDF абзацами; оригинал заметки удаляется и действием заметки, не только вместе с ней.
- `web/workspace`: вид заметки с оригиналом (вкладки, показ по формату, шапка, два действия), значки в навигаторе; «Отдельного удаления оригинала MUST NOT быть» отменяется.

## Scope

- `agno/core/files.py` (склейка строк PDF), `agno/core/notes.py` (удаление оригинала, текст из оригинала).
- `agno/app/api/notes.py` — два маршрута; тесты в `agno/tests/`.
- `web/src/data/` — две операции в `apiProvider` и отказ с причиной в `fixturesProvider`.
- `web/src/screens/project/docs/NoteDoc.tsx` и новые компоненты показа оригинала, `Navigator.tsx`, `workspace.css`; `web/src/components/ui/tabs.tsx` через CLI shadcn.
- `web/package.json` — `mammoth` и `dompurify` с точными версиями.
- `agno/skills/coauthor/SKILL.md` — раздел «О сервисе «Соавтор»».

## Non-goals

- Вид сценария для Fountain, FDX и STARC; свой просмотрщик PDF (pdf.js); точная вёрстка Word.
- Разметка и комментарии в оригинале, замена оригинала, несколько оригиналов.
- Переизвлечение текста у старых заметок.
- Новые инструменты соавтора: соавтор не удаляет оригинал и не возвращает текст.
- Перенос заголовка-поля на другие документы (персонажи, локации и т. п.).
- Картинки, ссылки, голос, сканы (`story-materials`, шаги 2–3).

## Impact

- API: два новых маршрута под `/api/v1/notes/{id}`; схема `NoteOut` не меняется; миграций нет.
- Поведение ядра: текст новых PDF идёт абзацами, это меняет `body` новых заметок и текст файлов чата, который читает соавтор.
- Фронтенд: две новые зависимости, загружаются отдельным куском только при открытии заметки из DOCX.
- Промпт соавтора: обновлённая справка; перезапуск API после правки.
