# Spec Delta

## MODIFIED Requirements

### Requirement: Оригинал заметки
Заметка с оригиналом MUST показывать под заголовком одну строку с именем файла, его размером и «Скачать», которое MUST скачивать файл с исходным именем. Текст такой заметки MUST правиться как у обычной заметки. Оригинал MUST удаляться вместе с заметкой или действием «Удалить оригинал, оставить текст». Заметка без оригинала MUST NOT показывать строку файла.

#### Scenario: Скачать оригинал
- GIVEN открыта заметка «Эпоха» из `Эпоха.pdf`
- WHEN автор нажимает «Скачать» в строке файла
- THEN MUST скачаться `Эпоха.pdf` с теми же байтами

#### Scenario: Обычная заметка
- GIVEN открыта заметка «Финал» без оригинала
- WHEN автор смотрит на заметку
- THEN строки файла, «Скачать» и вкладок MUST NOT быть

### Requirement: Длинный материал для чтения
Текст заметки с оригиналом длиннее 50 000 знаков MUST показываться для чтения: листом, без поля ввода, там, где показывается текст для соавтора. «Править текст» MUST включать правку до закрытия заметки. Заметка без оригинала и короткая заметка с оригиналом MUST давать правку сразу. Правка соавтора в тексте, открытом для чтения, MUST показываться без перезагрузки.

#### Scenario: Книга открывается для чтения
- GIVEN заметка «Книга» с оригиналом `Книга.txt` и текстом на 500 000 знаков
- WHEN автор открывает её
- THEN текст MUST быть виден листом без поля ввода, и MUST быть «Править текст»

#### Scenario: Книга из PDF
- GIVEN заметка «Книга» с оригиналом `Книга.pdf` и текстом на 500 000 знаков
- WHEN автор открывает вкладку «Текст для соавтора»
- THEN текст MUST быть виден листом без поля ввода, и MUST быть «Править текст»

#### Scenario: Править текст
- GIVEN текст заметки «Книга» открыт для чтения
- WHEN автор нажимает «Править текст»
- THEN текст MUST стать полем ввода с автосохранением

#### Scenario: Короткий материал правится сразу
- GIVEN заметка «Эпоха» с оригиналом `Эпоха.txt` и текстом на 80 знаков
- WHEN автор открывает её
- THEN текст MUST сразу быть полем ввода, а «Править текст» MUST NOT быть

## ADDED Requirements

### Requirement: Название заметки в заголовке
Название заметки MUST правиться прямо в заголовке документа; отдельной карточки «Название» у заметки MUST NOT быть. Правка MUST сохраняться автоматически, как текст. Пустое название MUST NOT сохраняться: при уходе из пустого заголовка он MUST вернуться к последнему сохранённому названию.

#### Scenario: Переименование в заголовке
- GIVEN открыта заметка «Финал»
- WHEN автор меняет заголовок на «Концовка»
- THEN статус MUST стать «Сохранено», и навигатор MUST показывать «Концовка» без перезагрузки

#### Scenario: Пустой заголовок
- GIVEN открыта заметка «Финал»
- WHEN автор стирает заголовок и уходит из него
- THEN заголовок MUST снова показать «Финал», и после перезагрузки заметка MUST называться «Финал»

### Requirement: Вкладки заметки с оригиналом
Заметка с оригиналом PDF, DOCX или MD MUST иметь вкладки «Оригинал» и «Текст для соавтора»; при открытии заметки MUST быть выбрана «Оригинал». На вкладке текста MUST быть подпись, что этот текст видит соавтор. Заметка с оригиналом TXT, Fountain, FDX или STARC MUST NOT иметь вкладок: она показывает текст для соавтора с той же подписью.

#### Scenario: PDF открывается оригиналом
- GIVEN заметка «Эпоха» из `Эпоха.pdf`
- WHEN автор открывает её
- THEN MUST быть выбрана вкладка «Оригинал»

#### Scenario: Правка текста для соавтора
- GIVEN открыта заметка «Эпоха» из `Эпоха.pdf`
- WHEN автор переходит на «Текст для соавтора» и меняет текст
- THEN статус MUST стать «Сохранено», и вкладка MUST подписывать, что этот текст видит соавтор

#### Scenario: Сценарий без вкладок
- GIVEN заметка «Пилот» из `Пилот.fdx`
- WHEN автор открывает её
- THEN вкладок MUST NOT быть, и текст MUST идти с подписью, что его видит соавтор

#### Scenario: Переход из поиска
- GIVEN поиск по истории нашёл слово в тексте заметки из `Эпоха.pdf`
- WHEN автор открывает результат
- THEN MUST быть выбрана вкладка «Текст для соавтора», и найденное MUST быть выделено

### Requirement: Показ оригинала по формату
Вкладка «Оригинал» MUST показывать PDF самим документом со страницами, с действием «Открыть в новой вкладке»; DOCX — документом с заголовками, абзацами, списками, таблицами, жирным и курсивом, шрифтами дизайн-системы; MD — отрисованным Markdown. Скрипты, обработчики событий и внешние ресурсы из файла MUST NOT выполняться и загружаться. Если оригинал не удаётся показать, вкладка MUST показывать причину и «Скачать».

#### Scenario: PDF
- GIVEN заметка из `Эпоха.pdf`
- WHEN открыта вкладка «Оригинал»
- THEN MUST быть виден сам PDF, и «Открыть в новой вкладке» MUST открывать его в новой вкладке браузера

#### Scenario: DOCX с заголовками
- GIVEN заметка из DOCX с заголовком «Глава 1», списком и таблицей
- WHEN открыта вкладка «Оригинал»
- THEN заголовок MUST быть заголовком, список — списком, таблица — таблицей

#### Scenario: Markdown
- GIVEN заметка из MD со строкой `# План` и словом `**важно**`
- WHEN открыта вкладка «Оригинал»
- THEN «План» MUST быть заголовком, «важно» — жирным, а символов `#` и `**` MUST NOT быть видно

#### Scenario: Ссылка на картинку в DOCX
- GIVEN DOCX ссылается на картинку по внешнему адресу
- WHEN открыта вкладка «Оригинал»
- THEN браузер MUST NOT запрашивать этот адрес

#### Scenario: Оригинал не показался
- GIVEN оригинал не удалось получить или разобрать
- WHEN открыта вкладка «Оригинал»
- THEN вкладка MUST показать причину и «Скачать»

### Requirement: Удалить оригинал, оставить текст
Меню «…» заметки с оригиналом MUST давать «Удалить оригинал, оставить текст». Подтверждение MUST называть имя и размер файла и MUST говорить, что вернуть оригинал нельзя. После подтверждения заметка MUST стать обычной: без строки файла и вкладок, с прежними названием и текстом. Отказ MUST показываться с причиной. У заметки без оригинала действия MUST NOT быть.

#### Scenario: Оригинал удалён
- GIVEN открыта заметка «Эпоха» из `Эпоха.pdf` на 233 КБ
- WHEN автор выбирает «Удалить оригинал, оставить текст» и подтверждает
- THEN подтверждение MUST называть `Эпоха.pdf` и 233 КБ, а после него заметка MUST показывать текст без строки файла и вкладок

#### Scenario: Отмена
- WHEN автор открывает подтверждение и отменяет его
- THEN оригинал MUST остаться

### Requirement: Вернуть текст из оригинала
Меню «…» заметки с оригиналом MUST давать «Вернуть текст из оригинала». Подтверждение MUST говорить, что правки текста пропадут. После подтверждения текст для соавтора MUST замениться текстом из оригинала без перезагрузки. Отказ MUST показываться с причиной. У заметки без оригинала действия MUST NOT быть.

#### Scenario: Текст вернулся
- GIVEN автор стёр часть текста заметки из `Эпоха.pdf`
- WHEN он выбирает «Вернуть текст из оригинала» и подтверждает
- THEN на вкладке «Текст для соавтора» MUST снова быть весь текст файла

### Requirement: Значок материала в навигаторе
В навигаторе и в списке заметок заметка с оригиналом MUST показываться значком вида файла: свой для PDF, для DOCX, для текста (TXT, MD) и для сценария (Fountain, FDX, STARC). Заметка без оригинала MUST показываться значком заметки. После удаления оригинала значок MUST смениться на значок заметки без перезагрузки.

#### Scenario: PDF и своя заметка
- GIVEN в истории заметка из `Эпоха.pdf` и заметка «Финал» без оригинала
- WHEN автор раскрывает «Заметки» в навигаторе
- THEN у «Эпоха» MUST быть значок PDF, а у «Финал» — значок заметки
