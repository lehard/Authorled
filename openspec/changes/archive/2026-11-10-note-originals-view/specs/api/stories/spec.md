# Spec Delta

## ADDED Requirements

### Requirement: Удаление оригинала заметки
`DELETE /api/v1/notes/{id}/file` с `If-Match`, равным ревизии заметки, MUST удалять её оригинал навсегда, оставлять название и текст, увеличивать ревизию на 1 и возвращать `200` с заметкой, у которой `file` `null`, и новой ревизией в `ETag`. Без `If-Match` MUST быть `428`, со старой ревизией — `409`. Заметка без оригинала, заметка в корзине и заметка истории в корзине MUST давать `409`, ничего не меняя. Чужая заметка MUST давать `404`.

#### Scenario: Оригинал удалён, текст остался
- GIVEN заметка «Эпоха» с оригиналом `Эпоха.pdf` на ревизии 2
- WHEN автор вызывает удаление оригинала с `If-Match: 2`
- THEN ответ MUST быть `200` с `file` `null`, прежними `title` и `body`, `revision` 3 и `ETag` «3», а метаданные бывшего оригинала MUST отвечать `404`

#### Scenario: Место освобождается
- GIVEN оригиналы заметок пользователя заняли место до предела тарифа
- WHEN автор удаляет оригинал заметки и загружает в заметки файл того же размера
- THEN загрузка MUST пройти

#### Scenario: Заметка без оригинала
- WHEN автор вызывает удаление оригинала у заметки без оригинала
- THEN ответ MUST быть `409`, и заметка MUST NOT меняться

#### Scenario: Заметка в корзине
- GIVEN заметка с оригиналом лежит в корзине
- WHEN автор вызывает удаление её оригинала
- THEN ответ MUST быть `409`, и оригинал MUST остаться

#### Scenario: Старая ревизия
- GIVEN заметка с оригиналом на ревизии 3
- WHEN удаление оригинала пришло с `If-Match: 2`
- THEN ответ MUST быть `409`, и оригинал MUST остаться

#### Scenario: Чужая заметка
- WHEN пользователь удаляет оригинал заметки чужой истории
- THEN ответ MUST быть `404`, и оригинал MUST остаться

### Requirement: Текст заметки из оригинала
`POST /api/v1/notes/{id}/text-from-file` с `If-Match`, равным ревизии заметки, MUST заменять `body` текстом, заново извлечённым из байтов оригинала по текущим правилам извлечения, увеличивать ревизию на 1 и возвращать `200` с заметкой и новой ревизией в `ETag`. Ошибки `If-Match` — как у изменения заметки. Заметка без оригинала, в корзине или в истории в корзине MUST давать `409`; текст длиннее 500 000 знаков — `422`. Чужая заметка MUST давать `404`.

#### Scenario: Испорченный текст вернулся
- GIVEN заметка из `Эпоха.pdf` с текстом «Москва, 1913», и автор заменил текст на «черновик»
- WHEN автор вызывает возврат текста из оригинала с текущей ревизией
- THEN ответ MUST быть `200`, `body` MUST содержать «Москва, 1913» и MUST NOT содержать «черновик», а байты оригинала MUST остаться прежними

#### Scenario: Старая заметка получает новые правила
- GIVEN заметка из PDF загружена до склейки строк, и её текст разорван по строкам страницы
- WHEN автор возвращает текст из оригинала
- THEN `body` MUST идти абзацами по правилам извлечения текста из PDF

#### Scenario: Заметка без оригинала
- WHEN автор вызывает возврат текста у заметки без оригинала
- THEN ответ MUST быть `409`, и заметка MUST NOT меняться

#### Scenario: Без If-Match
- WHEN автор вызывает возврат текста без `If-Match`
- THEN ответ MUST быть `428`, и заметка MUST NOT меняться

#### Scenario: Чужая заметка
- WHEN пользователь вызывает возврат текста у заметки чужой истории
- THEN ответ MUST быть `404`
