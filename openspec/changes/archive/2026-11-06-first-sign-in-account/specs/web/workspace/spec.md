# Spec Delta

## ADDED Requirements

### Requirement: Аккаунт до экранов
При источнике данных `api` экраны за входом и запросы их данных MUST начинаться только после ответа `GET /api/v1/me`. Пока ответа нет, MUST показываться экран ожидания. Если аккаунт получить не удалось, MUST показываться причина с кнопками «Повторить» и «Выйти». При источнике данных `fixtures` экраны MUST открываться без ожидания сервера.

#### Scenario: Первый вход нового пользователя
- GIVEN у пользователя с верным токеном ещё нет записи в `users`
- WHEN он впервые открывает `/` после кода из письма
- THEN `GET /api/v1/me` MUST завершиться раньше первого `GET /api/v1/projects`
- AND пользователь MUST увидеть пустой список историй, а не экран ошибки

#### Scenario: Вход с существующим аккаунтом
- GIVEN у пользователя есть аккаунт и истории
- WHEN он открывает `/`
- THEN после экрана ожидания MUST открыться его список историй

#### Scenario: Прямая ссылка на экран истории
- GIVEN пользователь вошёл, а аккаунт в приложении ещё не загружен
- WHEN он открывает `/p/water/text`
- THEN запросы данных истории MUST начаться только после ответа `GET /api/v1/me`

#### Scenario: Аккаунт получить не удалось
- GIVEN API не отвечает на `GET /api/v1/me`
- WHEN пользователь вошёл и открывает `/`
- THEN MUST показываться причина с кнопками «Повторить» и «Выйти»
- AND запрос `GET /api/v1/projects` MUST NOT уходить

#### Scenario: Повтор после сбоя
- GIVEN показана причина сбоя, а API снова отвечает
- WHEN пользователь нажимает «Повторить»
- THEN MUST открыться экран адреса, на котором он был

#### Scenario: Аккаунт удалён
- GIVEN `GET /api/v1/me` отвечает `410`
- WHEN пользователь вошёл и открывает `/`
- THEN MUST показываться причина от сервера с кнопками «Повторить» и «Выйти»
- AND нажатие «Выйти» MUST завершить вход и открыть экран входа

#### Scenario: Сбой фонового обновления
- GIVEN аккаунт получен и открыт экран истории
- WHEN повторный запрос `GET /api/v1/me` завершился ошибкой
- THEN экран истории MUST остаться открытым

#### Scenario: Демо-данные
- GIVEN источник данных `fixtures`, а API не отвечает
- WHEN пользователь вошёл и открывает `/`
- THEN MUST открыться список демо-историй
