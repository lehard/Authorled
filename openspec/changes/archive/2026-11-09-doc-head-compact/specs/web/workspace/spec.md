# Spec Delta

## ADDED Requirements

### Requirement: Шапка документа
Шапка документа истории (название, статус сохранения, действия) MUST стоять у верхнего края рабочего поля без пустой полосы над ней. На ширине больше 900 px шапка MUST быть на одной линии с меню пользователя, и меню MUST NOT перекрывать её кнопки и предупреждение о запертом драфте при любой ширине рабочего поля. На ширине до 900 px шапка документа MUST идти сразу под шапкой окна.

#### Scenario: Шапка на одной линии с меню
- GIVEN окно шириной 1440 px, чат развёрнут
- WHEN открыт `/p/water/text`
- THEN заголовок «Текст сценария» MUST быть по вертикали на одной линии с меню пользователя, а между верхним краем рабочего поля и шапкой MUST NOT быть пустой полосы выше меню пользователя

#### Scenario: Меню не закрывает кнопки шапки
- GIVEN окно шириной 1240 px
- WHEN открыт `/p/water/text` при развёрнутом и затем при свёрнутом чате
- THEN «Сохранено», история и переключатель «Текст / Карточки» MUST быть видны целиком и нажиматься, и меню пользователя MUST открываться

#### Scenario: Запертый драфт
- GIVEN окно шириной 1240 px, драфт заперт
- WHEN открыт `/p/water/synopsis`
- THEN предупреждение о запертом драфте и его кнопки MUST NOT уходить под меню пользователя

#### Scenario: Узкий экран
- GIVEN окно шириной 375 px
- WHEN открыт `/p/water/text`
- THEN шапка документа MUST идти сразу под шапкой окна без пустой полосы, панель инструментов MUST быть в одну строку, а ширина страницы MUST NOT превышать ширину окна
