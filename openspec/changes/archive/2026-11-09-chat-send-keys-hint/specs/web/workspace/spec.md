# Spec Delta

## ADDED Requirements

### Requirement: Подсказка клавиш в поле чата
Пустое поле ввода чата соавтора MUST показывать клавишу новой строки в записи системы автора: на macOS «⇧↵: новая строка», на других системах «Shift+Enter: новая строка». Подсказка MUST помещаться в одну строку поля при самой узкой колонке чата. Подсказка клавиш в поле MUST быть мелким приглушённым текстом: мельче и бледнее текста, который набирает автор. У кнопки «Отправить» при наведении MUST появляться подсказка дизайн-системы «Отправить» с клавишей: ↵ на macOS, Enter на других системах. На устройстве без мыши подсказок клавиш MUST NOT быть: поле MUST показывать «Напишите соавтору».

#### Scenario: macOS
- **GIVEN** окно истории открыто в Safari на macOS, поле чата пустое
- **WHEN** автор смотрит на поле и наводит указатель на «Отправить»
- **THEN** поле MUST показывать «⇧↵: новая строка», а у кнопки MUST появиться «Отправить» с ↵

#### Scenario: Windows
- **GIVEN** окно истории открыто в Chrome на Windows, поле чата пустое
- **WHEN** автор смотрит на поле и наводит указатель на «Отправить»
- **THEN** поле MUST показывать «Shift+Enter: новая строка», у кнопки MUST появиться «Отправить» с Enter, и символов ↵ и ⇧ MUST NOT быть

#### Scenario: Узкая колонка
- **GIVEN** окно шириной 1100 px, колонка чата самой узкой ширины, поле пустое
- **WHEN** показана подсказка клавиш
- **THEN** подсказка MUST быть в одну строку, и поле MUST быть высотой в одну строку, и подсказка MUST быть мельче набранного текста

#### Scenario: Телефон
- **GIVEN** окно истории открыто на устройстве с сенсорным экраном без мыши
- **WHEN** поле чата пустое
- **THEN** поле MUST показывать «Напишите соавтору», и подсказок клавиш MUST NOT быть

#### Scenario: Клавиши как прежде
- **GIVEN** в поле набран текст
- **WHEN** автор нажимает Shift+Enter, затем Enter
- **THEN** Shift+Enter MUST перевести строку, Enter MUST отправить сообщение, а подсказка MUST NOT показываться, пока в поле есть текст
