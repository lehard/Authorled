## MODIFIED Requirements

### Requirement: Проверка после деплоя
После запуска деплой MUST проверять по публичному адресу, что `/health` отвечает успехом, а `/agents` без токена отказывает. Деплой MUST также проверять, что `admin.soavtor.app` без клиентского сертификата отклоняет соединение, `https://auth.soavtor.app/if/admin/` отвечает `404`, а поток Authentik по умолчанию на домене Authentik и домене сервиса отвечает `404`. Деплой MUST также проверять сайт на домене продукта: главная, страница политики заявки в бету и страницы документов `/legal/offer/`, `/legal/privacy/` и `/pricing/` отвечают `200`, неизвестный адрес — `404`, а `POST /os/api/v1/beta-requests` с пустым телом получает отказ маршрута заявки `422`; настоящую заявку проверка MUST NOT создавать. Если проверка не прошла, запуск MUST завершиться ошибкой. Автоматический откат MUST NOT выполняться.

#### Scenario: API не поднялся
- GIVEN после запуска `/health` не отвечает успехом
- WHEN проходит проверка
- THEN запуск MUST стать красным, и прошлая версия MUST NOT возвращаться сама

#### Scenario: Доступ без токена
- GIVEN `/agents` без токена отвечает успехом
- WHEN проходит проверка
- THEN запуск MUST завершиться ошибкой

#### Scenario: Сайт не отдаётся
- GIVEN `https://soavtor.app/` отвечает не `200` или маршрут заявки на домене продукта отвечает не `422` на пустое тело
- WHEN проходит проверка
- THEN запуск MUST завершиться ошибкой с адресом и полученным кодом

#### Scenario: Документ не отдаётся
- GIVEN `https://soavtor.app/legal/offer/` отвечает `404`
- WHEN проходит проверка
- THEN запуск MUST завершиться ошибкой с адресом и полученным кодом

#### Scenario: Админка открыта без сертификата
- GIVEN `https://admin.soavtor.app/` отвечает по HTTP без клиентского сертификата
- WHEN проходит проверка
- THEN запуск MUST завершиться ошибкой с адресом
