## MODIFIED Requirements

### Requirement: Окно истории
Окно истории MUST состоять из навигатора слева, рабочего поля посередине и колонки чата справа. Колонка чата MUST быть на всех экранах истории. На ширине больше 900 px колонку чата MUST быть можно свернуть кнопкой в её шапке в узкую полосу справа с кнопкой соавтора; нажатие полосы MUST разворачивать чат, а освободившееся место MUST получать рабочее поле. Свёрнутость MUST сохраняться в этом браузере для всех историй. На ширине до 900 px навигатор MUST открываться кнопкой поверх рабочего поля, а чат — листом снизу.

#### Scenario: Узкий экран
- GIVEN окно шириной 375 px
- WHEN открыт `/p/water/text`
- THEN рабочее поле MUST занимать ширину экрана без горизонтальной прокрутки, навигатор MUST открываться кнопкой, чат — листом снизу

#### Scenario: Свернуть чат
- GIVEN окно шириной 1280 px, открыт `/p/water/text`
- WHEN автор нажимает «Свернуть» в шапке чата
- THEN справа MUST остаться узкая полоса с кнопкой соавтора, а рабочее поле MUST стать шире на освободившееся место

#### Scenario: Свёрнутый чат после перезагрузки
- GIVEN автор свернул чат
- WHEN он перезагружает страницу или открывает другую историю в этом же браузере
- THEN чат MUST быть свёрнут

#### Scenario: Развернуть чат
- GIVEN чат свёрнут
- WHEN автор нажимает кнопку соавтора на полосе
- THEN колонка чата MUST вернуться с прежней беседой и текстом в поле ввода

### Requirement: Обсудить предложение в чате
«Обсудить в чате» MUST выделять убираемый текст предложения, чтобы он ушёл в чат как «Выделено: …», и закрывать карточку; на узком экране MUST открываться чат, а свёрнутый на десктопе чат MUST разворачиваться.

#### Scenario: Обсудить
- GIVEN открыта карточка предложения в реплике Дяди Коли
- WHEN автор нажимает «Обсудить в чате»
- THEN над полем чата MUST быть «Выделено: «Он утонул. Всё.»»

#### Scenario: Обсудить при свёрнутом чате
- GIVEN окно шириной 1280 px, чат свёрнут, открыта карточка предложения
- WHEN автор нажимает «Обсудить в чате»
- THEN колонка чата MUST развернуться, и над полем чата MUST быть «Выделено: …» с убираемым текстом

## ADDED Requirements

### Requirement: Карточки у текста
Карточка ветки комментария, нового комментария или предложения соавтора MUST NOT закрывать строки текста листа. Если справа от листа есть место для карточки, она MUST стоять там на высоте фрагмента. Иначе карточка MUST вставать под абзацем с фрагментом и сдвигать следующий текст вниз; после закрытия карточки текст MUST возвращаться на место. Сдвиг MUST NOT менять документ, его сохранение и отмену правок.

#### Scenario: Место справа от листа
- GIVEN окно шириной 1920 px, чат свёрнут, открыт `/p/water/text`
- WHEN автор кликает по предложению в реплике Дяди Коли
- THEN карточка MUST стоять справа от листа на высоте реплики и MUST NOT перекрывать лист

#### Scenario: Места справа нет
- GIVEN окно шириной 1280 px, открыт `/p/water/text`
- WHEN автор кликает по комментарию в реплике Веры
- THEN карточка MUST стоять под абзацем реплики, следующие абзацы MUST быть ниже карточки, и ни одна строка текста MUST NOT быть под карточкой

#### Scenario: Закрытие карточки
- GIVEN карточка открыта под абзацем и сдвинула текст
- WHEN автор нажимает Escape
- THEN текст MUST вернуться на прежнее место, статус MUST остаться «Сохранено», а «Отменить» MUST NOT отменять открытие карточки

### Requirement: Загрузка окна истории
Одинаковые запросы чтения к API, которые экраны окна истории делают одновременно, MUST уходить одним запросом с общим ответом. Комментарии и предложения открытого драфта MUST запрашиваться вместе с остальными данными окна, не дожидаясь открытия редактора.

#### Scenario: Один запрос на адрес
- GIVEN приложение собрано для продакшена, автор вошёл
- WHEN он открывает `/p/water/text`
- THEN каждый адрес API MUST быть запрошен при открытии один раз

#### Scenario: Комментарии вместе с текстом
- GIVEN автор вошёл
- WHEN он открывает «Текст сценария» истории
- THEN запросы комментариев и предложений драфта MUST начаться, не дожидаясь ответа на запрос текста сценария
