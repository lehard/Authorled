## ADDED Requirements

### Requirement: Регистрация на экране входа
Экран входа `/login` MUST вести регистрацию своими экранами по дизайн-системе через API шагов Authentik:
- почта без аккаунта — вместо ошибки сообщение «Аккаунта с почтой … ещё нет» с действиями «Создать аккаунт» и «Другая почта»;
- «Как вас зовут?» — имя и фамилия; пустое — ошибка у поля;
- «Подтвердите почту» — тот же ввод кода, что при входе, с «Отправить ещё раз» и «Другая почта»;
- после верного кода — токены по OIDC и возврат на открытый адрес, как после входа.

#### Scenario: Регистрация новой почты
- GIVEN аккаунта с почтой `new@authorled.test` нет
- WHEN пользователь вводит почту, выбирает «Создать аккаунт», вводит имя и код из письма
- THEN MUST открыться полка историй, а меню пользователя MUST показывать введённое имя

#### Scenario: Другая почта вместо регистрации
- GIVEN показано «Аккаунта с почтой … ещё нет»
- WHEN пользователь выбирает «Другая почта»
- THEN MUST открыться шаг почты с прежним адресом для правки, без отправки писем

#### Scenario: Пустое имя
- GIVEN открыт шаг «Как вас зовут?»
- WHEN пользователь продолжает с пустым полем
- THEN у поля MUST показываться ошибка, и письмо MUST NOT отправляться

### Requirement: Регистрация: существующая почта и повтор
Почта, у которой есть аккаунт, MUST вести во вход, а не в регистрацию. Перезагрузка посреди регистрации MUST начинать с почты без ошибки.

#### Scenario: Перезагрузка на шаге имени
- GIVEN открыт шаг «Как вас зовут?»
- WHEN страница перезагружена
- THEN MUST показываться шаг почты без ошибки

#### Scenario: Возврат после брошенной регистрации
- GIVEN регистрация брошена на шаге кода
- WHEN пользователь снова вводит ту же почту
- THEN MUST открыться шаг кода входа, и после верного кода MUST открыться приложение
