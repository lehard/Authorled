## MODIFIED Requirements

### Requirement: Главная страница
Главная MUST содержать блоки в таком порядке:
1. первый экран: суть продукта, закрытая бета, «Хочу в бету», «Войти», живая правка;
2. крупная фраза о видении;
3. песочница «Спросите соавтора»;
4. что есть в бете, вкладками;
5. «Путь истории» из 22 этапов, «Концепт»;
6. схема последствий изменения решения, «Концепт»;
7. вопросы и ответы;
8. форма заявки;
9. подвал: политика, «Войти».

#### Scenario: Первый экран
- GIVEN собранная главная
- WHEN читается первый экран
- THEN он MUST говорить, что это редактор сценариев с ИИ-соавтором, который предлагает правки, а не пишет за автора, и что идёт закрытая бета

#### Scenario: Возможности беты
- GIVEN собранная главная
- WHEN читается блок беты со всеми вкладками
- THEN он MUST называть редактор сценария, персонажей, локации и миры, драфты, сохранения, рецензирование, импорт Fountain, FDX, STARC, DOCX и TXT и соавтора, который предлагает правки

#### Scenario: Порядок блоков
- GIVEN собранная главная
- WHEN перечисляются её блоки сверху вниз
- THEN порядок MUST совпадать со списком требования

### Requirement: Правда на главной
На сайте MUST NOT быть цифр, отзывов и логотипов клиентов, которых нет. Возможность, которой нет в бете, MAY быть только в блоках «Путь истории» и схемы последствий с пометкой «Концепт» и фразой, что в бете этого пока нет. Заготовленные ответы песочницы MUST быть подписаны «пример ответа». Скриншоты беты MUST быть подписаны как экраны беты, кадры концепта — как концепт.

#### Scenario: Методология помечена
- GIVEN собранная главная
- WHEN читаются блок методологии «Путь истории» и схема последствий
- THEN у каждого MUST быть пометка «Концепт»
- AND текст MUST говорить, что в бете этого пока нет

#### Scenario: Телефон
- GIVEN главная открыта в окне шириной 390 px
- WHEN страница прокручивается до конца
- THEN горизонтальной прокрутки MUST NOT быть
- AND кнопки «Хочу в бету» и «Войти» MUST быть видны на первом экране

## ADDED Requirements

### Requirement: Живая правка в первом экране
В первом экране MUST быть лист сценария демо-истории с предложением соавтора: зачёркнутое, новое, зачем, «Принять» и «Отклонить». «Принять» MUST заменять реплику новой, «Отклонить» — оставлять прежнюю; после выбора MUST быть способ показать предложение снова. Кнопки MUST работать мышью и с клавиатуры. Без JavaScript лист MUST показывать предложение неподвижно.

#### Scenario: Принять правку
- GIVEN первый экран загружен, предложение показано
- WHEN посетитель нажимает «Принять»
- THEN на листе MUST стоять новая реплика, зачёркнутой не остаётся

#### Scenario: Отклонить с клавиатуры
- GIVEN фокус на кнопке «Отклонить»
- WHEN посетитель нажимает Enter
- THEN на листе MUST остаться прежняя реплика

### Requirement: Крупная фраза о видении
Блок MUST содержать фразу о видении продукта не короче двух строк. При прокрутке слова MUST переходить от приглушённого цвета к основному по одному, в порядке чтения. Полный текст MUST быть в готовом HTML.

#### Scenario: Без движения
- GIVEN у посетителя включено «уменьшить движение»
- WHEN блок появляется на экране
- THEN фраза MUST быть видна сразу целиком в основном цвете

### Requirement: Песочница «Спросите соавтора»
Блок MUST показывать фрагмент сцены демо-истории и не меньше трёх вопросов к соавтору. Выбор вопроса MUST печатать в чате свой заготовленный ответ с подписью «пример ответа». Песочница MUST NOT отправлять запросы к API и вызывать модель. Кнопки вопросов MUST работать с клавиатуры.

#### Scenario: Свой ответ на каждый вопрос
- GIVEN песочница на экране
- WHEN посетитель по очереди выбирает каждый вопрос
- THEN для каждого MUST появиться свой ответ с подписью «пример ответа»
- AND сетевых запросов MUST NOT быть

### Requirement: Бета вкладками
Блок беты MUST переключать скриншоты беты вкладками не меньше пяти: сценарий, карточки, драфты, рецензирование, соавтор. У каждой вкладки MUST быть короткий текст о пользе. Вкладки MUST управляться с клавиатуры (стрелки, Tab) и иметь роли вкладок для экранного диктора. Без JavaScript тексты всех вкладок MUST быть в готовом HTML.

#### Scenario: Переключение стрелкой
- GIVEN фокус на вкладке «Сценарий»
- WHEN посетитель нажимает стрелку вправо
- THEN MUST открыться следующая вкладка с её скриншотом и текстом

### Requirement: Путь истории
Блок MUST показывать 22 этапа методологии с названиями из глоссария, разделённые на общий замысел (1–12) и полный метр (13–22). Линия пути MUST прорисовываться при появлении блока. Выбор этапа или группы этапов MUST показывать кадр концепта «Кабинет» с подписью. Над блоком MUST быть пометка «Концепт».

#### Scenario: Кадр этапа
- GIVEN блок на экране
- WHEN посетитель выбирает этап «Карта импульсов»
- THEN MUST показаться кадр карты импульсов с подписью о концепте

### Requirement: Схема последствий
Блок MUST показывать, как изменение утверждённого решения задевает связанные документы: посетитель меняет решение, и связанные документы подсвечиваются с пометкой «устарело» или «противоречит» и итогом вида «Задето N документов из M». Блок MUST иметь пометку «Концепт» и MUST работать с клавиатуры.

#### Scenario: Изменить решение
- GIVEN схема на экране в исходном виде
- WHEN посетитель нажимает «Изменить решение»
- THEN задетые документы MUST подсветиться, а итог MUST назвать их число

### Requirement: Вопросы и ответы списком
Вопросы MUST раскрываться и сворачиваться по одному, с клавиатуры тоже. Все вопросы и ответы MUST быть в готовом HTML и читаться без JavaScript.

#### Scenario: Без JavaScript
- GIVEN собранная главная
- WHEN `index.html` читается без выполнения скриптов
- THEN в нём MUST быть текст каждого вопроса и ответа

### Requirement: Движение на сайте
Первый экран MUST появляться при загрузке один раз; остальные блоки — при появлении на экране, один раз, без слушателя прокрутки. Повторяющиеся анимации MUST останавливаться вне экрана. Анимироваться MAY только `transform`, `opacity`, `filter` (размытие до 2 px), `clip-path` и `stroke-dashoffset` линий SVG. При `prefers-reduced-motion: reduce` всё MUST сразу показываться в конечном виде.

#### Scenario: Уменьшить движение
- GIVEN у посетителя включено «уменьшить движение»
- WHEN главная загружается и прокручивается
- THEN ни один блок MUST NOT двигаться, все показаны в конечном виде

### Requirement: Бюджет скриптов главной
Скрипты, которые загружает главная, MUST весить не больше 120 КБ в gzip; проверка сборки MUST падать при превышении и называть размер. Кадры MUST грузиться в WebP нескольких ширин; кадры ниже первого экрана — лениво.

#### Scenario: Превышение бюджета
- GIVEN скрипты главной весят больше 120 КБ gzip
- WHEN выполняется сборка сайта
- THEN проверка сборки MUST завершиться ошибкой с фактическим размером
