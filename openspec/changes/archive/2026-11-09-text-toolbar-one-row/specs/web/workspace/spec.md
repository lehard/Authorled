# Spec Delta

## MODIFIED Requirements

### Requirement: Панель инструментов текста
Над листом «Текста сценария» MUST быть панель: «Отменить», «Повторить», список типов абзаца, «Показать биты», «Найти и заменить», «Только текущая сцена» и меню «⋯» с действиями «Импорт», «Экспорт» и «Печать». Кнопки MUST иметь доступные названия и подсказки дизайн-системы. Панель MUST помещаться в одну строку на любой ширине рабочей колонки, и ни одна кнопка MUST NOT обрезаться или уходить за край панели. Подсказка списка типов MUST называть текущий тип абзаца.

Когда ширины самой панели не хватает для названий (порог считается по ширине панели, а не окна), панель MUST стать узкой:
- кнопка типа абзаца MUST показывать только значок без названия типа;
- «Показать биты» и «Только текущая сцена» MUST уйти из строки в меню «⋯». Там они MUST быть пунктами, которые переключают вид и показывают, включён ли он. В «Поэпизоднике» меню «⋯» на узкой панели MUST содержать «Только текущая сцена».

На широкой панели название типа MUST быть видно целиком, а виды MUST стоять кнопками в строке.

#### Scenario: Отмена кнопкой
- GIVEN автор допечатал слово в реплике
- WHEN он нажимает «Отменить»
- THEN слово MUST исчезнуть, а «Повторить» MUST вернуть его

#### Scenario: Телефон
- GIVEN окно шириной 375 px и открыт `/p/water/text`
- WHEN экран отрисован
- THEN все кнопки панели MUST быть в одной строке, а ширина страницы MUST NOT превышать ширину окна

#### Scenario: Тип абзаца значком
- GIVEN окно шириной 375 px, открыт `/p/water/text`, курсор в реплике
- WHEN автор наводит указатель на кнопку типа абзаца или переводит на неё фокус
- THEN кнопка MUST показывать значок без названия, а подсказка MUST гласить «Тип абзаца: Реплика»

#### Scenario: Виды в меню на узкой панели
- GIVEN окно шириной 375 px и открыт `/p/water/text`
- WHEN автор открывает «⋯» и выбирает «Показать биты»
- THEN биты MUST стать видны, а при следующем открытии «⋯» пункт «Показать биты» MUST быть отмечен включённым

#### Scenario: Поэпизодник на узкой панели
- GIVEN окно шириной 375 px и открыт «Поэпизодник»
- WHEN экран отрисован
- THEN панель MUST быть в одной строке, а «Только текущая сцена» MUST быть в меню «⋯»

#### Scenario: Узкая колонка при развёрнутом чате
- GIVEN окно шириной 1000 px, чат развёрнут и открыт `/p/water/text`
- WHEN курсор стоит в абзаце с самым длинным названием типа
- THEN все кнопки панели MUST быть в одной строке

#### Scenario: Широкая панель
- GIVEN окно шириной 1440 px и открыт `/p/water/text`
- WHEN курсор стоит в абзаце с самым длинным названием типа
- THEN название типа MUST быть видно целиком, а «Показать биты» и «Только текущая сцена» MUST быть кнопками в строке панели
