## ADDED Requirements

### Requirement: Команда администратора beta-requests
Скрипт администратора MUST давать команду `beta-requests` с целью `local` или `prod`, выполняемую в контейнере API через операции ядра: список заявок в бету от новых к старым — время заявки (UTC), почта, имя, кто (сценарист, писатель, другое) и отметка, есть ли уже неудалённый пользователь с этой почтой. Команда MUST только читать; при отсутствии заявок MUST печатать, что заявок нет, и завершаться кодом `0`.

#### Scenario: Список заявок
- GIVEN есть заявки `anna@example.com` (вчера) и `boris@example.com` (сегодня), пользователь `anna@example.com` уже зарегистрирован
- WHEN администратор выполняет `beta-requests`
- THEN первой MUST идти строка `boris@example.com`, второй — `anna@example.com`
- AND у `anna@example.com` MUST стоять отметка, что пользователь уже есть

#### Scenario: Заявок нет
- GIVEN заявок нет
- WHEN администратор выполняет `beta-requests`
- THEN команда MUST напечатать, что заявок нет, и завершиться кодом `0`
