# Spec Delta

## MODIFIED Requirements

### Requirement: Абзацы сценария из файла
Импорт MUST переводить абзацы в типы сценария редактора: Fountain — по правилам Fountain и пометкам `[[@тег текст]]` нашего экспорта; FDX — по типам абзацев Final Draft; STARC — по типам абзацев текста сценария STARC; DOCX и TXT — построчно по правилам Fountain. Каждой сцене MUST выдаваться новый `uid`; параметры сцены STARC (название, день истории, цвет, теги) MUST переноситься, если они есть.

#### Scenario: Русские заголовки в TXT
- WHEN импортируется TXT со строками «ИНТ. КУХНЯ — ДЕНЬ» и «ВЕРА» над репликой
- THEN текст MUST содержать заголовок сцены, персонажа и реплику

#### Scenario: Круг через наш Fountain
- WHEN импортируется Fountain, выгруженный экспортом редактора, с абзацами «Участники сцены» и «Бит»
- THEN эти абзацы MUST вернуться своих типов

#### Scenario: Параметры сцены из STARC
- WHEN импортируется `.starc`, где у сцены есть название, день истории, цвет и теги
- THEN у заголовка этой сцены MUST быть те же название, день, цвет и теги

### Requirement: Персонажи и локации из импорта
Импорт MUST добавлять эпизодическими персонажей из абзацев «Персонаж» (без пометок в скобках) и локации из заголовков сцен (между «ИНТ.»/«НАТ.»/«INT.»/«EXT.» и тире), которых в истории нет без учёта регистра. Из STARC MUST переноситься персонажи и локации проекта с их именами и ролью.

#### Scenario: Без дублей
- WHEN в истории есть персонаж «Вера», а в импортируемом тексте реплики «ВЕРА» и «ОЛЕГ»
- THEN MUST добавиться только «Олег»

#### Scenario: Персонажи проекта STARC
- WHEN импортируется `.starc` с главным персонажем «Вера», которая в тексте не говорит
- THEN в истории MUST появиться «Вера» с ролью «главный»

## ADDED Requirements

### Requirement: Отказ импорта STARC
Файл `.starc` MUST читаться только на чтение как база SQLite STARC с документом структуры и текстом сценария. Файл другой структуры, без сценария, с несколькими сценариями, неизвестным типом абзаца, неизвестным элементом или неизвестной ролью MUST давать `422` с причиной; частичного импорта MUST NOT быть.

#### Scenario: Проект романа
- WHEN импортируется `.starc` с романом и без сценария
- THEN ответ MUST быть `422` с причиной «в файле нет сценария»

### Requirement: Что импорт STARC не переносит
Известные данные STARC, для которых в редакторе нет места (номер, описание, штамп, время и ресурсы сцены, параметры бита и акта, закладки, зачёркивание, выравнивание, комментарии и правки рецензирования), импорт MUST NOT отклонять и MUST NOT переносить.

#### Scenario: Сцена со штампом
- WHEN импортируется `.starc`, где у сцены есть штамп и закладка
- THEN импорт MUST пройти, а текст сцены MUST перенестись без них
