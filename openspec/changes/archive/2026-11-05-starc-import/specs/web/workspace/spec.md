# Spec Delta

## MODIFIED Requirements

### Requirement: Полка историй
Полка MUST показывать истории обложками с названием и действия: создать, переименовать, удалить в корзину. Создание MUST спрашивать название и MAY принимать файл рукописи (Fountain, FDX, STARC, DOCX, TXT): с файлом история создаётся из него импортом ядра. Пустое название MUST давать ошибку у поля; отказ импорта MUST показываться с причиной, и история MUST NOT создаваться. Новая история MUST быть полнометражным сценарием и MUST открываться сразу на тексте сценария. На полке MUST NOT быть приветствия, поиска, режима фокуса и статуса сохранения.

#### Scenario: Новая история
- GIVEN открыта полка
- WHEN пользователь создаёт историю «Маяк»
- THEN MUST открыться `/p/<id>/text` новой истории с одним пустым заголовком сцены

#### Scenario: Пустое название
- GIVEN открыт диалог новой истории
- WHEN пользователь нажимает «Создать» с пустым названием
- THEN MUST показываться ошибка у поля, и история MUST NOT создаваться

#### Scenario: История из файла
- GIVEN источник `api` и открыт диалог новой истории
- WHEN пользователь вводит «Паром», выбирает `паром.fountain` и нажимает «Создать»
- THEN MUST открыться текст новой истории со сценами из файла, а в навигаторе MUST быть персонажи из реплик

#### Scenario: Битый файл при создании
- GIVEN источник `api` и открыт диалог новой истории
- WHEN пользователь создаёт историю из битого `.fdx`
- THEN под полем файла MUST показываться причина, диалог MUST остаться открытым, и история MUST NOT появиться на полке

### Requirement: Импорт, экспорт и печать на экране
Над листом «Текста сценария» MUST быть действия «Импорт» (файл Fountain, Final Draft, STARC, DOCX или TXT с диска, разбирается ядром), «Экспорт» (Fountain, Final Draft) и «Печать» с титульной страницей из документа «Титульная страница». Импорт MUST спрашивать подтверждение перед заменой текста, загружать файл и вызывать импорт ядра с ревизией открытого текста; после импорта MUST показываться новый текст и добавленные персонажи и локации. Ошибка импорта или печати MUST показываться с причиной, и текст MUST NOT меняться.

#### Scenario: Битый файл
- GIVEN открыт «Текст сценария»
- WHEN автор импортирует файл `.fdx` без корневого элемента `FinalDraft`
- THEN MUST показаться ошибка с причиной из ядра, и текст MUST остаться прежним

#### Scenario: Импорт DOCX
- GIVEN источник `api` и открыт «Текст сценария»
- WHEN автор импортирует DOCX с заголовком «ИНТ. КУХНЯ — ДЕНЬ» и репликой Веры и подтверждает замену
- THEN текст MUST содержать эту сцену, а «Вера» MUST появиться в «Персонажах»

### Requirement: Файлы в чат
Поле ввода чата MUST принимать файлы скрепкой, перетаскиванием на колонку чата и вставкой из буфера: DOCX, PDF, TXT, MD, Fountain, FDX, STARC, до 20 МБ и до 5 файлов в сообщении. Файл MUST загружаться в ядро к текущей беседе. Отказ (тип, размер, антивирус, нечитаемый файл) MUST показываться под полем с причиной, и файл MUST NOT прикрепляться.

#### Scenario: Неподходящий файл
- GIVEN открыта беседа
- WHEN автор перетаскивает `обложка.png`
- THEN под полем MUST показаться причина, и файл MUST NOT прикрепиться
