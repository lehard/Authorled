## MODIFIED Requirements

### Requirement: Тарифы как данные
Тарифы MUST задаваться файлом данных биллинга, а не кодом. У тарифа MUST быть код (`[a-z0-9-]+`), название, цена в рублях за период, длина периода в месяцах (не меньше 1), лимит расхода в рублях за период, место для оригиналов заметок в мегабайтах (целое, не меньше 1) и признак «можно купить»; все поля обязательны, другие поля MUST отклоняться. Файл MUST называть тариф новых аккаунтов, и он MUST быть в списке тарифов. В поставке MUST быть тариф `beta`: 0 ₽, период 1 месяц, лимит 500 ₽, место 500 МБ, купить нельзя; он же тариф новых аккаунтов. Ошибка в файле MUST останавливать старт API с ошибкой, называющей файл и поле.

#### Scenario: Тариф beta
- GIVEN файл тарифов из поставки
- WHEN API стартует
- THEN тариф `beta` MUST иметь цену 0 ₽, период 1 месяц, лимит 500 ₽, место 500 МБ, признак «можно купить» = нет, и он MUST быть тарифом новых аккаунтов

#### Scenario: Поле пропущено
- GIVEN в тарифе нет лимита
- WHEN API стартует
- THEN старт MUST завершиться ошибкой, называющей тариф и поле

#### Scenario: Тариф новых аккаунтов не из списка
- GIVEN файл называет тарифом новых аккаунтов `trial`, а такого тарифа в нём нет
- WHEN API стартует
- THEN старт MUST завершиться ошибкой, называющей `trial`

#### Scenario: Место не задано
- GIVEN в тарифе нет места для оригиналов заметок
- WHEN API стартует
- THEN старт MUST завершиться ошибкой, называющей тариф и поле `storage_mb`

## ADDED Requirements

### Requirement: Место для файлов по тарифу
Биллинг MUST давать место для оригиналов заметок пользователя в байтах по тарифу его действующей подписки на данный момент; выданная подписка с кончившимся периодом MUST сначала продлеваться, как при проверке лимита. Нет подписки, подписка кончилась без продления или тариф не из файла MUST давать ошибку с причиной, а не место по умолчанию.

#### Scenario: Место беты
- GIVEN у пользователя действующая подписка `beta`
- WHEN запрашивается его место
- THEN ответ MUST быть 524 288 000 байт

#### Scenario: Нет подписки
- GIVEN у пользователя нет действующей подписки
- WHEN запрашивается его место
- THEN MUST быть ошибка «нет подписки»
