## MODIFIED Requirements

### Requirement: Допустимые файлы
Размер файла MUST быть не больше 20 МБ, иначе `413`. Тип определяется по расширению и содержимому: для `chat` и для оригинала заметки — DOCX, PDF, TXT, MD, Fountain, FDX, STARC; для `import` — Fountain, FDX, STARC, DOCX, TXT. Другой тип или несовпадение расширения и содержимого MUST давать `422` с причиной. Пустой файл MUST давать `422`.

#### Scenario: Слишком большой
- WHEN автор загружает файл 25 МБ
- THEN ответ MUST быть `413`, файл MUST NOT сохраняться

#### Scenario: Изображение
- WHEN автор загружает `обложка.png`
- THEN ответ MUST быть `422` с причиной «тип файла не поддерживается»

#### Scenario: PDF для импорта
- WHEN автор загружает PDF с `purpose` `import`
- THEN ответ MUST быть `422`

#### Scenario: Не SQLite под видом STARC
- WHEN автор загружает `проект.starc`, внутри которого текст, а не база SQLite
- THEN ответ MUST быть `422`, файл MUST NOT сохраняться

#### Scenario: Изображение в заметки
- WHEN автор загружает в заметки `обложка.png`
- THEN ответ MUST быть `422` с причиной «тип файла не поддерживается», и заметка MUST NOT появиться

### Requirement: Удаление файла
`DELETE /api/v1/files/{id}` MUST удалять файл навсегда с содержимым; ответ `204`. Оригинал заметки MUST удаляться только вместе с заметкой: `DELETE` для него MUST давать `409` с причиной, и файл MUST остаться. Удаление истории навсегда MUST удалять все её файлы.

#### Scenario: Удалённый файл
- WHEN автор удалил файл и запрашивает его метаданные
- THEN ответ MUST быть `404`

#### Scenario: Оригинал заметки
- GIVEN у заметки есть оригинал
- WHEN автор вызывает `DELETE` для этого файла
- THEN ответ MUST быть `409`, и заметка и её оригинал MUST остаться
