# Proposal: материалы истории в заметках

Бизнес-интент: `business-intents/story-materials.md` (шаг 1).

## Why

Автор собирает к истории материалы: статьи, PDF, свои записи. Сейчас файл можно только приложить к сообщению в чате, и он остаётся в той беседе: в проекте его не видно, а соавтор знает его только в ход, где файл приложен. Хранение исследований есть у 11 из 19 разобранных продуктов (BI-15), а у нас материалы нужны ещё и соавтору, чтобы он их разбирал. Почти всё для этого уже есть: ядро хранит файл парой «оригинал и текст» и извлекает текст без ИИ.

## What Changes

- Материал — это заметка с приложенным оригиналом. Новой сущности и нового раздела нет.
- «Загрузить файл» в разделе «Заметки» (меню раздела и страница списка) и в «Добавить документ». Форматы и проверки — как у файлов чата: DOCX, PDF, TXT, MD, Fountain, FDX, STARC, до 20 МБ, ClamAV, тип по содержимому, PDF без текста отклоняется.
- Загрузка создаёт заметку: название — имя файла без расширения, текст — извлечённый из файла. Текст правится как у обычной заметки, оригинал не меняется и скачивается из заметки. Текст длиннее 500 000 знаков отклоняется с причиной.
- Файл, приложенный в поле ввода чата, сохраняется в заметки действием «В заметки» на его значке. Соавтор по просьбе автора тоже сохраняет файл беседы в заметку: новый меняющий инструмент, с подтверждением, как создание заметки.
- Заметка с оригиналом уходит в корзину и восстанавливается вместе с ним; удаление заметки навсегда удаляет и оригинал. Удалить оригинал отдельно от заметки нельзя (`409`).
- Место для оригиналов заметок ограничено тарифом: новое обязательное поле тарифа `storage_mb`, у `beta` — 500. Считаются оригиналы заметок всех историй пользователя, включая корзину. Загрузка сверх предела отклоняется с причиной.
- Соавтор видит в списке заметок, что у заметки есть оригинал, и длину текста; длинную заметку он читает частями по 20 000 знаков.
- Заметка с оригиналом, текст которой длиннее 50 000 знаков, открывается для чтения; «Править текст» включает правку. Предел длины 500 000 знаков остаётся (владелец, 2026-11-10: правка такой заметки тормозит, около 1,5 с на нажатие).
- Замер действий соавтора не берёт инструменты, которым нужен файл в сообщении; сейчас это сохранение файла беседы в заметку (владелец, 2026-11-10).

### Modified Capabilities
- `api/stories`: «Заметки истории» (оригинал в ответе), «Корзина заметок» (удаление навсегда удаляет оригинал); новые «Заметка из файла», «Заметка из файла беседы», «Место для оригиналов заметок».
- `api/files`: «Допустимые файлы» (файлы заметок), «Удаление файла» (оригинал заметки отдельно не удаляется).
- `core/database`: «Таблицы файлов» (назначение `note`), «Таблица заметок» (ссылка на оригинал).
- `billing/subscriptions`: «Тарифы как данные» (поле `storage_mb`).
- `billing/module`: «Интерфейс биллинга» (операция «место для файлов по тарифу»).
- `api/agents`: «Инструменты соавтора» (оригинал и длина в списке заметок, чтение частями, сохранение файла беседы в заметку).
- `web/workspace`: «Действия навигатора» («Загрузить файл»); новые «Загрузка файла в заметки», «Оригинал заметки», «Файл чата в заметки», «Длинный материал для чтения».
- `coauthor-actions-eval`: «Набор просьб замера действий» (инструменты с файлом в сообщении не входят в набор).

## Scope

- `agno/core/`: назначение файла `note`, связь заметки с оригиналом, заметка из файла и из файла беседы, предел длины текста, подсчёт места, корзина и удаление вместе с заметкой; `agno/migrations/`: миграция `0014`.
- `agno/billing/`: поле `storage_mb` в `plans.toml` и `Plan`, операция места по тарифу.
- `agno/app/api/`: маршруты загрузки файла в заметки и сохранения файла беседы, `file` в ответе заметки, отказы.
- `agno/agents/coauthor_tools.py`, `agno/skills/coauthor/SKILL.md`: список и чтение заметок частями, инструмент сохранения файла беседы.
- `web/src/data/`, `web/src/screens/project/`: «Загрузить файл», оригинал в заметке со скачиванием, «В заметки» у файла в поле чата, отказы; провайдер `fixtures` отказывает в загрузке, как сейчас с файлами.
- `agno/tests/`: ядро, маршруты, таблицы, биллинг, доступ к чужой заметке и чужому файлу.
- ADR-006, глоссарий, `AGENTS.md`: заметка может нести оригинал.

## Non-goals

- Шаги 2–4 интента: ссылки на веб-страницы, картинки, голос, сканы и фото, поиск по смыслу внутри материалов.
- Любая обработка файлов ИИ и списание рублей за неё.
- Новые форматы сверх списка чата; несколько оригиналов у одной заметки; замена оригинала.
- Папки и теги материалов; поиск по заметкам (интент `project-search`).
- Список файлов беседы и «В заметки» у уже отправленных сообщений: история чата хранит только имена файлов.
- Показ занятого места автору (кроме причины отказа).
- Перенос файлов из базы в объектное хранилище.

## Impact

- API: новые `POST /api/v1/projects/{id}/notes/files` и `POST /api/v1/files/{id}/note`; у заметки новое поле `file` (может быть `null`); `DELETE /api/v1/files/{id}` для оригинала заметки отвечает `409`. Остальное без изменений.
- База: `files.purpose` получает `note`, у `notes` — `file_id`; существующие данные не меняются. Миграцию `0014` надо применить до выкладки API.
- Тарифы: `storage_mb` обязательно в `plans.toml`; без него API не стартует.
- Соавтор: новый меняющий инструмент; `read_story_note` отдаёт часть текста с номером части и их числом.
