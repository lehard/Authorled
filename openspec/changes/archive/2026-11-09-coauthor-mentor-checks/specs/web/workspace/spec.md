# Spec Delta

## MODIFIED Requirements

### Requirement: Чат с соавтором
Колонка чата окна истории MUST быть чатом с агентом `coauthor` через AG-UI: заголовок «Соавтор», строка «Видит: <открытый документ>», сообщения автора и ответы соавтора, поле ввода (Enter — отправить, Shift+Enter — новая строка). Ответ MUST появляться по мере генерации; Markdown в ответе MUST отображаться оформленным текстом; у ответа MUST быть «Скопировать». Пустая беседа MUST показывать «О чём эта история?» и проверки наставника (требование «Проверки наставника»), которые отправляются по клику. Если запуск не удался, текст автора MUST остаться в поле, а чат MUST показать сообщение для автора без технических подробностей (текста исключения, JSON, идентификаторов запроса, названий моделей, провайдеров и компонентов сервера):
- отказ продукта (причина `usage_limit_reached`, `subscription_ended`, `usage_check_failed` или `usage_record_failed` в данных `RUN_ERROR`) — сообщение бэкенда как есть, без «Соавтор не смог ответить»; отказ по лимиту — уведомлением, а не ошибкой;
- любой другой сбой запуска, в том числе сбой модели, — «Соавтор сейчас недоступен. Попробуйте позже.»;
- запрос не дошёл до сервера — «Нет связи с сервером. Проверьте интернет и попробуйте ещё раз.»
Полный текст сбоя MUST оставаться в консоли браузера.

#### Scenario: Вопрос и ответ
- GIVEN открыт текст сценария «Тихой воды»
- WHEN автор отправляет «О чём эта история?»
- THEN в чате MUST появиться его сообщение и ответ соавтора, который нарастает по мере генерации

#### Scenario: Пустая беседа
- GIVEN автор начал новую беседу
- WHEN чат показывает пустую беседу
- THEN в ней MUST быть «О чём эта история?» и восемь проверок наставника, и MUST NOT быть других подсказок

#### Scenario: Ошибка
- GIVEN API недоступен
- WHEN автор отправляет сообщение
- THEN в чате MUST появиться «Нет связи с сервером. Проверьте интернет и попробуйте ещё раз.» без причины сбоя в скобках, а текст автора MUST остаться в поле, чтобы отправить его снова

#### Scenario: Сбой модели
- GIVEN провайдер модели отклоняет запрос соавтора (например, на счёте провайдера нет денег), и `RUN_ERROR` содержит текст исключения LiteLLM
- WHEN автор отправляет сообщение
- THEN в чате MUST появиться «Соавтор сейчас недоступен. Попробуйте позже.» и MUST NOT быть текста исключения, JSON, идентификатора запроса и названий LiteLLM, DeepSeek и модели, а текст автора MUST остаться в поле

#### Scenario: Лимит исчерпан
- GIVEN лимит соавтора автора на этот период исчерпан и обновится 7 декабря
- WHEN автор пишет соавтору
- THEN в чате MUST появиться «Лимит соавтора на этот период исчерпан. Он обновится 7 декабря.» без «Соавтор не смог ответить», а текст автора MUST остаться в поле

#### Scenario: Отказ продукта
- GIVEN проверка лимита не удалась, и `RUN_ERROR` содержит причину `usage_check_failed` и сообщение «Не удалось проверить лимит соавтора. Напишите в поддержку.»
- WHEN автор пишет соавтору
- THEN в чате MUST появиться ошибка «Не удалось проверить лимит соавтора. Напишите в поддержку.» без «Соавтор не смог ответить», а текст автора MUST остаться в поле

#### Scenario: Неизвестная причина
- GIVEN `RUN_ERROR` содержит в данных причину, которой нет в списке отказов продукта
- WHEN автор пишет соавтору
- THEN в чате MUST появиться «Соавтор сейчас недоступен. Попробуйте позже.», а не сообщение из события

## ADDED Requirements

### Requirement: Проверки наставника
Чат MUST знать восемь проверок наставника, у каждой — название и текст просьбы: «Где вода?», «Чего хочет герой?», «Темп», «Голоса», «Тон», «Конфликт», «Показано или рассказано», «Противоречия». Кнопка «Проверки» у поля ввода MUST открывать их список в любой беседе. Клик по проверке MUST отправлять её текст просьбы сообщением автора с тем же контекстом, что у набранного вопроса. Пока соавтор отвечает, проверки MUST NOT отправляться.

#### Scenario: Проверка из списка
- GIVEN в беседе уже есть ответы, в тексте сценария выделена реплика
- WHEN автор открывает «Проверки» и выбирает «Голоса»
- THEN в чате MUST появиться сообщение автора с текстом просьбы «Голоса», а контекст AG-UI MUST содержать выделенную реплику

#### Scenario: Проверка без выделения
- GIVEN открыт текст сценария, ничего не выделено
- WHEN автор выбирает «Где вода?»
- THEN просьба MUST уйти с открытым документом в контексте

#### Scenario: Соавтор ещё отвечает
- GIVEN соавтор пишет ответ
- WHEN автор открывает «Проверки»
- THEN проверки MUST быть недоступны до конца ответа

#### Scenario: Узкий экран
- GIVEN ширина окна 375 px
- WHEN автор открывает «Проверки» в шторке чата
- THEN список MUST помещаться в ширину без горизонтальной прокрутки страницы

### Requirement: Проверки над выделением
В меню выделения редактора «Текста сценария» и «Поэпизодника» MUST быть «Соавтор» со списком тех же восьми проверок. Выбор проверки MUST открывать чат, если он свёрнут (на узком экране — шторку), и отправлять просьбу в текущую беседу с выделенным фрагментом в контексте. Пока соавтор отвечает, проверки в меню MUST быть недоступны. В запертом драфте «Соавтор» MUST оставаться: проверки только читают.

#### Scenario: Проверка выделенной сцены
- GIVEN чат свёрнут, в «Тексте сценария» выделена сцена
- WHEN автор выбирает в меню выделения «Соавтор» → «Темп»
- THEN чат MUST открыться, в нём MUST появиться сообщение с текстом просьбы «Темп», а контекст AG-UI MUST содержать выделенную сцену

#### Scenario: Меню на телефоне
- GIVEN ширина окна 375 px, выделена реплика
- WHEN появляется меню выделения
- THEN «Соавтор» MUST быть виден и доступен, меню MUST помещаться в ширину без горизонтальной прокрутки страницы

### Requirement: Оценка ответа соавтора
У законченного ответа соавтора MUST быть «Полезно» и «Не то». Клик MUST ставить оценку, клик по выбранной — снимать, клик по другой — менять. Выбранная оценка MUST быть видна и после перезагрузки страницы и при возврате к беседе. Пока ответ пишется, кнопок MUST NOT быть. Если сохранить оценку не удалось, кнопки MUST вернуться к прежнему состоянию, а чат MUST показать причину без технических подробностей.

#### Scenario: Оценка остаётся
- GIVEN соавтор закончил ответ
- WHEN автор нажимает «Не то» и перезагружает страницу
- THEN у этого ответа MUST быть выбрано «Не то»

#### Scenario: Снять оценку
- GIVEN у ответа выбрано «Полезно»
- WHEN автор нажимает «Полезно» ещё раз
- THEN ни одна оценка MUST NOT быть выбрана

#### Scenario: Сбой сохранения
- GIVEN API недоступен
- WHEN автор нажимает «Полезно»
- THEN выбор MUST вернуться к прежнему, а чат MUST показать «Нет связи с сервером. Проверьте интернет и попробуйте ещё раз.»
