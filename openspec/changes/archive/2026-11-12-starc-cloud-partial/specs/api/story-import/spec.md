## MODIFIED Requirements

### Requirement: Отказ импорта STARC
Файл `.starc` MUST читаться только на чтение как база SQLite STARC с документом структуры и текстом сценария. Файл другой структуры, без сценария, текст которого есть в файле, с несколькими сценариями, текст которых есть в файле, с неизвестным типом абзаца, неизвестным элементом или неизвестной ролью MUST давать `422` с причиной. Частичного импорта MUST NOT быть, кроме одного случая: запись структуры проекта, у которой в файле нет своего документа (требование «Пропущенное при импорте STARC»).

#### Scenario: Проект романа
- WHEN импортируется `.starc` с романом и без сценария
- THEN ответ MUST быть `422` с причиной «в файле нет сценария»

#### Scenario: Два сценария с текстом
- GIVEN в структуре `.starc` два сценария, и текст каждого есть в файле
- WHEN файл импортируется
- THEN ответ MUST быть `422` с причиной «в файле несколько сценариев», и история MUST NOT создаваться

#### Scenario: Ни у одного сценария нет текста в файле
- GIVEN в структуре `.starc` два сценария, и в файле нет текста ни одного из них
- WHEN файл импортируется
- THEN ответ MUST быть `422` с причиной «в файле нет сценария»

## ADDED Requirements

### Requirement: Пропущенное при импорте STARC
Запись структуры проекта STARC вне корзины, у которой в файле нет своего документа — сценарий без документа текста, персонаж или локация без профиля, — MUST считаться отсутствующей в файле: импорт MUST NOT переносить её и MUST NOT отказывать из-за неё. Ответы `POST /api/v1/projects` (история из файла) и `POST /api/v1/drafts/{id}/import` MUST содержать поле `skipped`: список пропущенных записей с видом (`screenplay`, `character`, `location`) и именем из структуры, в порядке структуры. Для файлов других форматов и для файла STARC без таких записей `skipped` MUST быть пустым списком. Запись, документ которой есть, но не разбирается, MUST давать `422`, как прежде, и в `skipped` MUST NOT попадать.

#### Scenario: Облачный проект, выгруженный не полностью
- GIVEN в структуре `.starc` сценарии «Выбор 1» и «Выбор 2», текст есть только у «Выбор 1», а у локации «Колиба» нет профиля
- WHEN автор создаёт историю из этого файла
- THEN история MUST создаться с текстом «Выбор 1» и персонажами и локациями, у которых есть профиль
- AND `skipped` MUST содержать сценарий «Выбор 2» и локацию «Колиба»

#### Scenario: То же при замене текста
- GIVEN тот же файл загружен для импорта в драфт
- WHEN автор импортирует его в драфт
- THEN текст драфта MUST стать текстом «Выбор 1», а `skipped` MUST содержать сценарий «Выбор 2» и локацию «Колиба»

#### Scenario: Полный файл
- WHEN импортируется `.starc`, у всех записей которого есть документы, или файл FDX
- THEN `skipped` MUST быть пустым списком

#### Scenario: Корзина не в списке
- GIVEN в корзине проекта `.starc` есть сценарий без текста в файле
- WHEN файл импортируется
- THEN этот сценарий MUST NOT быть в `skipped`
