## ADDED Requirements

### Requirement: Предупреждение о пропущенном при импорте
Если ядро вернуло при импорте непустой список пропущенного (`skipped`, спека `api/story-import`, «Пропущенное при импорте STARC»), экран «Текст сценария» MUST показать предупреждение после импорта в редакторе и при первом открытии истории, только что созданной из файла. Предупреждение MUST называть пропущенное по именам, сгруппированно по виду (сценарии, персонажи, локации), и MUST объяснять причину: этих данных нет в самом файле STARC, так бывает, когда облачный проект STARC выгружен не полностью; чтобы перенести их, нужно выгрузить проект из STARC целиком. Предупреждение MUST NOT выглядеть как ошибка (не цветом ошибки) и MUST закрываться автором. При пустом списке предупреждения MUST NOT быть. Предупреждение MUST NOT сохраняться: после перезагрузки страницы его нет.

#### Scenario: История из облачного файла
- GIVEN источник `api` и файл `.starc`, где у сценария «Выбор 2» нет текста в файле
- WHEN пользователь создаёт историю из этого файла на полке
- THEN MUST открыться текст сценария новой истории с предупреждением, где назван сценарий «Выбор 2» и сказано, что его нет в файле STARC

#### Scenario: Импорт в редакторе
- GIVEN открыт «Текст сценария»
- WHEN автор импортирует тот же файл и подтверждает замену
- THEN MUST показаться новый текст и то же предупреждение

#### Scenario: Полный файл
- WHEN автор импортирует DOCX или полный `.starc`
- THEN предупреждения о пропущенном MUST NOT быть

#### Scenario: Закрыть предупреждение
- GIVEN показано предупреждение о пропущенном
- WHEN автор нажимает «Закрыть»
- THEN предупреждение MUST исчезнуть, текст MUST остаться прежним
