## MODIFIED Requirements

### Requirement: Адреса экранов
Каждый экран MUST иметь свой адрес, и открытие адреса напрямую MUST показывать тот же экран:
- `/` — полка историй; `/trash` — корзина историй;
- `/p/:projectId/d/:draftId/:doc` — окно истории с документом драфта: `info`, `title`, `logline`, `synopsis`, `treatment`, `text`, `chars`, `char:<id>`, `locs`, `loc:<id>`, `worlds`, `world:<id>`, `trash`;
- `/p/:projectId` и `/p/:projectId/:doc` — переход к `/p/:projectId/d/<open_draft_id>/:doc` (без `:doc` — `text`);
- `/settings` — настройки (личный кабинет);
- `/showcase` — витрина дизайн-системы;
- `/auth/callback` — возврат из Authentik.
Неизвестный адрес, история, драфт или документ MUST показывать экран «Не найдено» со ссылкой на полку.

#### Scenario: Прямая ссылка на профиль
- GIVEN пользователь вошёл
- WHEN он открывает `/p/water/char:vera`
- THEN MUST открыться окно истории «Тихая вода» с профилем Веры в последнем открытом драфте, адрес MUST содержать этот драфт, и в навигаторе Вера MUST быть текущим пунктом

#### Scenario: Нет такого документа
- GIVEN пользователь вошёл
- WHEN он открывает `/p/water/char:nobody`
- THEN MUST показываться «Не найдено» со ссылкой на полку

#### Scenario: Сравнение с самим собой
- GIVEN пользователь вошёл
- WHEN он открывает `/p/water/compare:current:current`
- THEN MUST показываться «Не найдено» со ссылкой на полку

#### Scenario: Нет такого драфта
- GIVEN пользователь вошёл
- WHEN он открывает `/p/water/d/nobody/text`
- THEN MUST показываться «Не найдено» со ссылкой на полку

#### Scenario: Документ другого драфта
- GIVEN персонаж «Нина» есть только в драфте 2
- WHEN пользователь открывает адрес «Нины» с драфтом 1
- THEN MUST показываться «Не найдено» со ссылкой на полку

#### Scenario: Адрес бывшей страницы сценария
- GIVEN пользователь вошёл
- WHEN он открывает `/p/water/sp`
- THEN MUST показываться «Не найдено» со ссылкой на полку

### Requirement: Навигатор
Вверху навигатора MUST быть переключатель драфтов. Шапка навигатора с обложкой и названием истории MUST открывать документ «История»; отдельной строки истории в дереве MUST NOT быть. Навигатор MUST показывать дерево открытого драфта: «Персонажи», «Локации», «Миры» с документами; папку «Сценарий» с частями «Титульная страница», «Логлайн», «Синопсис», «Поэпизодник», «Текст сценария» (видимость частей задаётся в документе «История»); «Корзина» с числом документов. Папка «Сценарий» MUST называться так при любом названии истории и MUST только раскрываться, своего документа у неё нет. Открытый документ MUST быть выделен, документ «История» — выделением шапки.

#### Scenario: Поэпизодник в дереве
- GIVEN открыта история «Тихая вода»
- WHEN пользователь раскрывает сценарий в навигаторе
- THEN части MUST идти в порядке «Титульная страница», «Логлайн», «Синопсис», «Поэпизодник», «Текст сценария»

#### Scenario: Новый персонаж
- GIVEN открыта история «Тихая вода»
- WHEN пользователь добавляет персонажа «Нина Петровна»
- THEN персонаж MUST появиться в группе «Персонажи», и MUST открыться его профиль

#### Scenario: Удаление в корзину истории
- GIVEN в навигаторе есть локация «Пристань»
- WHEN пользователь выбирает «Удалить» в её меню
- THEN локация MUST пропасть из группы и появиться в «Корзине» истории, а счётчик корзины MUST увеличиться на 1

#### Scenario: Шапка открывает историю
- GIVEN открыт текст сценария истории «Тихая вода»
- WHEN пользователь нажимает на название в шапке навигатора
- THEN MUST открыться документ «История», шапка MUST быть выделена, а в дереве MUST NOT быть строки «Тихая вода»

#### Scenario: Папка только раскрывается
- GIVEN открыт профиль Веры и папка «Сценарий» раскрыта
- WHEN пользователь нажимает на «Сценарий»
- THEN папка MUST свернуться, а открытый документ и адрес MUST NOT измениться

#### Scenario: Папка не зависит от названия истории
- GIVEN история называется «Тихая вода»
- WHEN автор меняет название на «Маяк»
- THEN шапка MUST показывать «Маяк», а папка MUST называться «Сценарий»

### Requirement: Документы истории
Рабочее поле MUST показывать документы:
- «История»: название и тэглайн истории, видимость частей сценария в навигаторе, число сцен и оценка длительности открытого драфта; тэглайн MUST показываться на полке;
- «Титульная страница»: название, жанр или формат, автор, контакты, город и год — листом бумаги;
- «Логлайн»: текст листом бумаги;
- «Синопсис»: текст листом бумаги;
- списки персонажей, локаций и миров с ролью и одной строкой описания;
- профили персонажа, локации и мира с полями макета v2 (`PROFILE` в `data.js`), ролью и, для персонажа, возрастом и полом;
- «Корзина» истории: удалённые документы с «Восстановить», «Удалить навсегда» и «Очистить корзину».
Правка поля MUST сохраняться через провайдер данных и MUST отражаться в навигаторе без перезагрузки; статус «Сохранено» MUST показываться на экранах документов.

#### Scenario: Переименование персонажа
- GIVEN открыт профиль Веры
- WHEN пользователь меняет имя на «Вера Андреевна»
- THEN навигатор MUST показывать «Вера Андреевна», а статус MUST стать «Сохранено»

#### Scenario: Восстановление из корзины истории
- GIVEN в корзине истории лежит персонаж «Миша»
- WHEN пользователь нажимает «Восстановить»
- THEN Миша MUST вернуться в группу «Персонажи» со всеми полями профиля

#### Scenario: Тэглайн на полке
- GIVEN открыта «История» в драфте 2
- WHEN автор меняет тэглайн на «Двадцать лет никто не подходил к воде.»
- THEN статус MUST стать «Сохранено», полка MUST показывать этот тэглайн, а в драфте 1 документ «История» MUST показывать его же

#### Scenario: Логлайн в драфте
- GIVEN в истории два драфта с одним логлайном
- WHEN автор меняет «Логлайн» в драфте 2
- THEN в драфте 1 логлайн MUST остаться прежним

#### Scenario: Скрытый логлайн
- GIVEN в «Истории» снята галочка «Логлайн»
- WHEN автор смотрит навигатор и открывает адрес `logline`
- THEN части MUST NOT быть в папке «Сценарий», а адрес MUST показывать «Не найдено»

#### Scenario: Сбой одного из сохранений
- GIVEN открыта «История»
- WHEN автор меняет название и галочку части, и ядро отказывает второму сохранению из-за конфликта ревизий
- THEN экран MUST показывать конфликт, а не «Сохранено»

### Requirement: Запертый драфт
В запертом драфте все документы драфта MUST открываться только для чтения: текст, паспорт, логлайн, части в навигаторе, профили. Название и тэглайн принадлежат истории и MUST оставаться доступными для правки. Действия правки, комментарии, импорт и решение по предложениям MUST быть недоступны. Экран MUST показывать, что правка запрещена, и давать «Разрешить правку».

#### Scenario: Разрешить правку
- GIVEN открыт запертый драфт «После читки»
- WHEN автор нажимает «Разрешить правку» и печатает в тексте
- THEN драфт MUST сохраниться с правкой, значок замка MUST исчезнуть, а другие драфты MUST остаться прежними

#### Scenario: Профиль в запертом драфте
- GIVEN открыт запертый драфт
- WHEN автор открывает профиль персонажа
- THEN поля MUST быть только для чтения

#### Scenario: История в запертом драфте
- GIVEN открыт запертый драфт
- WHEN автор открывает документ «История»
- THEN название и тэглайн MUST быть доступны для правки, а галочки частей MUST быть закрыты
