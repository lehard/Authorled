## MODIFIED Requirements

### Requirement: Чат с соавтором
Колонка чата окна истории MUST быть чатом с агентом `coauthor` через AG-UI: заголовок «Соавтор», строка «Видит: <открытый документ>», сообщения автора и ответы соавтора, поле ввода (Enter — отправить, Shift+Enter — новая строка). Ответ MUST появляться по мере генерации; Markdown в ответе MUST отображаться оформленным текстом; у ответа MUST быть «Скопировать». Пустая беседа MUST показывать подсказки-вопросы, которые отправляются по клику. Если запуск отклонён из-за исчерпанного лимита (причина `usage_limit_reached` в данных `RUN_ERROR`), чат MUST показать сообщение бэкенда как есть, без слов об ошибке и без технических подробностей, а текст автора MUST остаться в поле.

#### Scenario: Вопрос и ответ
- GIVEN открыт текст сценария «Тихой воды»
- WHEN автор отправляет «О чём эта история?»
- THEN в чате MUST появиться его сообщение и ответ соавтора, который нарастает по мере генерации

#### Scenario: Ошибка
- GIVEN API недоступен
- WHEN автор отправляет сообщение
- THEN в чате MUST появиться сообщение об ошибке с причиной, а текст автора MUST остаться в поле, чтобы отправить его снова

#### Scenario: Лимит исчерпан
- GIVEN лимит соавтора автора на этот период исчерпан и обновится 7 декабря
- WHEN автор отправляет сообщение
- THEN в чате MUST появиться «Лимит соавтора на этот период исчерпан. Он обновится 7 декабря.» без «Соавтор не смог ответить», а текст автора MUST остаться в поле
