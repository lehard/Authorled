## MODIFIED Requirements

### Requirement: Свои маршруты в коде репозитория
HTTP API MUST предоставляться runtime `AgentOS`. Код репозитория MAY объявлять свои маршруты FastAPI только для продуктовых действий без LLM: роутером в приложении, которое возвращает AgentOS (ADR-002), под префиксом `/api/v1/`, не пересекаясь с маршрутами Agno. Параметр `base_app` MUST NOT использоваться: с ним Agno 3.1.10 не ставит свои обработчики ошибок на свои маршруты. Сейчас таких маршрутов два: `GET` и `PATCH /api/v1/me` (спека `api/me`). Очереди, lifecycle и конечные автоматы Company приложение по-прежнему не создаёт. OpenAPI MUST содержать 142 пути и 199 операций.

#### Scenario: Количество операций
- GIVEN платформа запущена
- WHEN клиент читает `GET /openapi.json`
- THEN схема MUST содержать 142 пути и 199 операций, сгруппированные по доменам `openspec/specs/api/`

#### Scenario: Маршруты Agno не перекрыты
- GIVEN платформа запущена со своими маршрутами
- WHEN клиент читает `GET /openapi.json`
- THEN все свои пути MUST начинаться с `/api/v1/`
- AND каждый путь Agno MUST обслуживаться Agno
