# Spec Delta

## MODIFIED Requirements

### Requirement: Проверки наставника
Чат MUST знать восемь проверок наставника, у каждой — название и текст просьбы: «Где «вода»?», «Чего хочет герой?», «Темп», «Голоса», «Тон», «Конфликт», «Показано или рассказано», «Противоречия». Кнопка «Проверки» у поля ввода MUST открывать их список в любой беседе. Клик по проверке MUST отправлять её текст просьбы сообщением автора с тем же контекстом, что у набранного вопроса. Пока соавтор отвечает, проверки MUST NOT отправляться.

#### Scenario: Проверка из списка
- GIVEN в беседе уже есть ответы, в тексте сценария выделена реплика
- WHEN автор открывает «Проверки» и выбирает «Голоса»
- THEN в чате MUST появиться сообщение автора с текстом просьбы «Голоса», а контекст AG-UI MUST содержать выделенную реплику

#### Scenario: Проверка без выделения
- GIVEN открыт текст сценария, ничего не выделено
- WHEN автор выбирает «Где «вода»?»
- THEN просьба MUST уйти с открытым документом в контексте

#### Scenario: Соавтор ещё отвечает
- GIVEN соавтор пишет ответ
- WHEN автор открывает «Проверки»
- THEN проверки MUST быть недоступны до конца ответа

#### Scenario: Узкий экран
- GIVEN ширина окна 375 px
- WHEN автор открывает «Проверки» в шторке чата
- THEN список MUST помещаться в ширину без горизонтальной прокрутки страницы

### Requirement: Обещание о текстах в чате
Пока в беседе соавтора нет сообщений, блок пустой беседы MUST заканчиваться строкой «Не обучаем ИИ на ваших текстах.» со ссылкой «Подробнее» на раздел «Материалы Пользователя и ИИ» оферты на `SITE_ORIGIN` в новой вкладке, под «Проверками наставника». Строка MUST быть мелким приглушённым текстом токенов дизайн-системы. Под полем ввода строки про обучение MUST NOT быть. Это не подсказка требования «Чат с соавтором». В беседе с сообщениями строки MUST NOT быть.

#### Scenario: Пустая беседа
- GIVEN приложение собрано с `SITE_ORIGIN=https://soavtor.app`, и автор начал новую беседу
- WHEN чат показывает пустую беседу
- THEN в блоке пустой беседы под «Проверками наставника» MUST быть «Не обучаем ИИ на ваших текстах.» и ссылка «Подробнее»
- AND ссылка MUST вести на `https://soavtor.app/legal/offer/#materials` и открываться в новой вкладке
- AND под полем ввода MUST быть только строка режима, без строки про обучение

#### Scenario: Широкое окно
- GIVEN окно шириной 1440 px, чат развёрнут
- WHEN чат показывает пустую беседу
- THEN строка про обучение со ссылкой MUST занимать одну строку

#### Scenario: После первого сообщения
- GIVEN в пустой беседе видна строка про обучение
- WHEN автор отправляет первое сообщение
- THEN строки про обучение MUST NOT быть, и поле ввода MUST NOT сдвинуться

#### Scenario: Беседа из истории
- GIVEN автор открывает беседу, в которой уже есть сообщения
- WHEN чат показывает беседу
- THEN строки про обучение MUST NOT быть

#### Scenario: Узкая колонка
- GIVEN окно шириной 1100 px и колонка чата самой узкой ширины
- WHEN чат показывает пустую беседу
- THEN строка и ссылка MUST занимать одну строку без горизонтальной прокрутки, и поле ввода MUST оставаться высотой в одну строку
