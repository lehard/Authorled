# Proposal: задание на исследование блоком в чате

Бизнес-интент: `business-intents/research-brief-in-chat.md`.

## Why

Задание на исследование одноразовое: его копируют в Deep Research один раз. Вторая версия (`research-brief-document`, в `main`, не выпущена) хранит его заметкой, которая открывается сама, крупной книжной гарнитурой. Владелец хочет, как в ChatGPT: задание прямо в ответе блоком с кнопкой копирования, а в заметку — по желанию. Ещё под ответом показывались строки «Разрешено: …» со значком `×`, похожим на кнопку закрытия. Строки появились потому, что чат теряет результаты действий при смене раскладки (шторка ↔ колонка). Это касается всех действий соавтора.

## What Changes

- **Блок задания в ответе.** Соавтор пишет задание в ответе блоком кода Markdown с меткой `research-brief`. Чат рисует его по-своему:
  - компактный моноширинный текст, «Развернуть целиком» и «Свернуть»;
  - «Скопировать»;
  - «Открыть Claude» и «Открыть ChatGPT», подсказка, строка о внешнем сервисе;
  - «Сохранить в заметки» — обычная заметка по нажатию автора.

  Блок живёт в тексте ответа и не пропадает.
- **Уточнения, каркас, «где искать», правила для исследования и разбиение широкой темы** остаются из второй версии.
- **BREAKING — удаляется инструмент `create_research_brief`.** Для задания больше нет подтверждения «Разрешить», заметка не создаётся сама и не открывается.
- **BREAKING — удаляется поле `research`** у заметки в базе (миграция `0017`), в API и во фронтенде. Удаляются шапка заметки задания и вложения кнопками.
- **Результаты действий соавтора хранятся рядом с беседой**, а не в компоненте чата. После смены раскладки строки о сделанном на месте.
- **Строки решения:** «Разрешено» — галочка, «Отклонено» — перечёркнутый круг, без крестика.

## Non-goals

- Свой Deep Research, приём отчёта, правка задания в чате, вложения кнопками.
- Замеры и судья: проверка глазами на локальном стенде.
- Карточка подтверждения, ждущая ответа, при пересоздании чата.

## Impact

- Миграция ядра `0017` убирает столбец `0016`. Одна голова.
- Поле `research` уходит из API заметок. Вторая версия не выпускалась, поэтому на сервере его нет.
- Меняющих инструментов соавтора снова шесть. Замер действий: просьбы на задание ожидают ответа без действия.
