# Design

## Context

В `deploy/Caddyfile` директива `encode gzip` стоит на весь домен `coauthor.glavai.ru`, поэтому действует и на `/os/*`, и на пути Authentik, и на файлы фронтенда. Caddy 2.11.9 дописывает `-gzip` к `ETag` сжатого ответа: на статическом файле сервера с `Accept-Encoding: gzip` приходит `"dmochkbbt0xn-1tyme-gzip"`, без него `"dmochkbbt0xn-1tyme"`.

API отдаёт ревизию в `ETag` (`agno/app/api/stories.py`, `agno/app/api/notes.py`), а `etag()` в `web/src/data/apiClient.ts` принимает только целое число и отказывает на остальном. Маленькие ответы Caddy не сжимает, поэтому часть запросов проходила.

Локальный стек идёт через прокси Vite без Caddy, поэтому ошибка видна только на сервере.

## Goals / Non-Goals

**Goals:**

- `ETag` ответов API доходит до фронтенда без изменений.
- Проверить поведение до релиза на настоящем Caddy, а не только на сервере.

**Non-Goals:**

- Постоянный локальный стек с Caddy.

## Decisions

**Сжатие только в блоке фронтенда.** `encode gzip` переносится с уровня домена внутрь последнего `handle`, где `file_server`. Так API и пути Authentik проходят без сжатия одной перестановкой строки, а файлы сборки, где сжатие и даёт выигрыш, сжимаются как раньше. Рядом с директивой остаётся комментарий, почему она стоит именно там: иначе её легко вернуть на уровень домена.

Альтернативы:

- Оставить сжатие и исключить только `/os/*` через matcher: сложнее, а смысла сжимать запросы Authentik нет.
- Отрезать суффикс на фронтенде: код начнёт подстраиваться под прокси и перестанет считать неизвестную ревизию ошибкой, суффикс зависит от алгоритма сжатия.
- Отдельный заголовок ревизии в API: меняет контракт `api/stories` и фронтенд ради той же цели.

**Проверка на временной копии конфигурации.** В контейнере Caddy той же версии, что на сервере, запускается копия `deploy/Caddyfile`, где домены заменены локальным портом, а на порту `8000` стоит заглушка API с `ETag: "2"` и телом больше 512 байт. Сначала копия старого файла должна показать `"2-gzip"`, затем копия нового показать `"2"` без `Content-Encoding`, а файл фронтенда остаться сжатым. Копия живёт только в scratch-каталоге, в репозиторий не попадает.

**Проверка на сервере без токена.** Публичный `/os/openapi.json` большой и сейчас приходит сжатым, поэтому на нём видно, что сжатие с API снято. Полный путь с ревизиями проходит владелец в браузере, потому что у проверки нет токена пользователя.

## Risks / Trade-offs

- [Большие сценарии передаются без сжатия] → для тестеров незаметно; если тексты начнут замедлять работу, это отдельное решение.
- [Сжатие могут вернуть на весь домен] → комментарий в `deploy/Caddyfile` и требование в спеке `runtime`.
- [Автоматической проверки ревизий на сервере нет] → полный путь проверяется вручную при этом релизе. Постоянная проверка с токеном не входит в этот change.

## Migration Plan

1. Слить правку в `main` и выпустить релиз: `deploy/deploy.sh` проверит файл и перезагрузит Caddy.
2. Откат: ручной запуск Deploy с прошлым тегом. Данные и миграции не затронуты.
