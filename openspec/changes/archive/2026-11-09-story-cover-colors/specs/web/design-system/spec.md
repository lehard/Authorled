## ADDED Requirements

### Requirement: Палитра обложек
Дизайн-система MUST задавать для каждой темы палитру обложек историй из шести цветов на своих шкалах: синий (`blue`), бирюзовый (`teal`), янтарный (`amber`), малиновый (`crimson`), сливовый (`plum`), графит (`neutral`). У каждого цвета MUST быть две точки градиента и цвет названия. Название MUST иметь контраст не ниже 4,5:1 с обеими точками градиента. Витрина MUST показывать шесть обложек.

#### Scenario: Контраст названия на обложках
- GIVEN палитра обложек в `tokens.css`
- WHEN выполняется `npm run check:contrast --prefix web`
- THEN проверка MUST пройти для цвета названия на обеих точках градиента каждой обложки во всех темах

#### Scenario: Недостаточный контраст на обложке
- GIVEN точка градиента янтарной обложки изменена так, что контраст названия в тёмной теме ниже 4,5:1
- WHEN выполняется `npm run check:contrast --prefix web`
- THEN проверка MUST завершиться ошибкой с именем темы, пары и фактическим значением

#### Scenario: Обложки на витрине
- GIVEN открыта `/showcase`
- WHEN автор переключает темы
- THEN на витрине MUST быть шесть обложек палитры с названием, в цветах текущей темы
