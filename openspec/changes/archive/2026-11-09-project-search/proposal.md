# Proposal

## Why

Когда в истории много сцен, документов и заметок, автор теряет нужное место: искать сейчас можно только внутри текста сценария (⌘F). Поиск по всему проекту есть у 7 из 21 разобранного продукта (ED-23), а соавтор, чтобы найти «все сцены с ножом», вынужден читать историю целиком (`business-intents/project-search.md`).

## What Changes

- Ядро ищет запрос в одном драфте и его истории: текст сценария (по сценам), логлайн и синопсис сценария, имена, краткие описания и поля персонажей, локаций и миров, названия и текст заметок истории. Совпадение ищется по подстроке, без учёта регистра и разницы «ё/е». Документы и заметки в корзине в поиск не попадают.
- Новый маршрут `GET /api/v1/drafts/{id}/search?q=…` без LLM отдаёт результаты тремя группами («Сцены», «Документы», «Заметки»): в каждом результате кусочек текста вокруг первого совпадения, уже разделённый на «до», «совпадение» и «после», и число совпадений. Запрос пустой, короче 2 символов или длиннее 200 символов отклоняется `422`. Чужая история даёт `404`.
- В навигаторе под шапкой истории появляется поле «Поиск по истории», ⌘K (Ctrl+K) ставит в него курсор. С 2 символов результаты по мере ввода показываются вместо дерева; Esc или крестик возвращают дерево.
- Клик по результату открывает документ или заметку, раскрывает нужное поле и выделяет в нём совпадение. Клик по сцене открывает «Текст сценария» на этой сцене со строкой ⌘F, в которой уже стоит этот запрос.
- «Найти и заменить» в редакторе тоже перестаёт различать «ё» и «е», чтобы переход из поиска по истории находил в тексте то же, что нашло ядро.
- У соавтора появляется читающий инструмент `search_story` поверх той же функции ядра, без подтверждения автора. В промпте соавтора добавляется строка о том, когда искать, а не читать всё.
- С источником данных `fixtures` поиск по истории отвечает явным «недоступно с данными примера», как сейчас импорт и файлы в чат.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `api/stories`: новое требование «Поиск по драфту истории»: маршрут, что именно ищется, как ищется, состав ответа и отказы.
- `web/workspace`: новое требование «Поиск по истории в навигаторе» (поле, ⌘K, результаты по группам, переход к совпадению, источник `fixtures`). В требовании «Найти и заменить» поиск теперь не различает «ё» и «е» и может открываться с запросом извне.
- `api/agents`: в требовании «Инструменты соавтора» к читающим инструментам добавляется поиск по истории беседы.

## Scope

- Ядро `agno/core/`: модуль поиска по драфту и его истории.
- Маршрут в `agno/app/api/` с проверкой доступа к истории драфта.
- Инструмент `search_story` в `agno/agents/coauthor_tools.py` и строка о нём в `agno/skills/coauthor/SKILL.md`.
- `web/src/data/`: запрос поиска в источниках `api` и `fixtures`.
- `web/src/screens/project/Navigator.tsx`: поле и результаты. Документы, заметки и «Текст сценария» учатся открываться с запросом: `docs/EntityDoc.tsx`, `ProseDoc.tsx`, `NoteDoc.tsx`, `TextDoc.tsx`, `web/src/editor/` (открыть ⌘F с запросом, «ё/е» в `plugins/find.ts`).
- Тесты ядра и маршрута в `agno/tests/`, проверка изоляции; разовый прогон настоящего соавтора на демо-истории с проверкой вызова `search_story`.

## Non-goals

- Замена по всей истории: заменять можно только внутри текста сценария.
- Регулярные выражения (ED-24), целые слова, области поиска по истории.
- Поиск по другим драфтам, снимкам и точкам драфта, корзине, комментариям и предложениям соавтора, файлам бесед, титульной странице.
- Поиск по смыслу через эмбеддинги, отдельный поисковый сервис, индексы в базе.
- Склонения имён: позже, опцией «все формы слова» на морфологии `business-intents/name-morphology.md` (BI-12).
- Синопсисы сцен: в ядре их пока нет. Когда их добавит change `scene-synopsis-and-cast-reports`, он же включит их в поиск.
- Поиск по не сохранённой ещё правке открытого редактора: её находит только ⌘F внутри редактора.

## Impact

- API: новый маршрут `GET /api/v1/drafts/{id}/search`, контракт OpenAPI для фронтенда. Существующие маршруты не меняются.
- Соавтор: новый инструмент в статичном списке `COAUTHOR_TOOLS` и строка в промпте. Нужен перезапуск API.
- Фронтенд: навигатор, экраны документов, заметок и текста сценария, плагин поиска редактора.
- Миграций, новых зависимостей, сервисов и настроек нет.
