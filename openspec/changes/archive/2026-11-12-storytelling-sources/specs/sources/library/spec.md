# Spec Delta

## Purpose

Библиотека первоисточников по сторителлингу: книги о драматургии в виде канона, поиск по ним для агентов и проверенные цитаты со ссылкой, на которые соавтор опирает свои советы автору.

## ADDED Requirements

### Requirement: Канон книги
Каждая книга библиотеки MUST храниться каноном — одним Markdown-файлом с шапкой метаданных и телом книги. Канон и исходные файлы книг MUST лежать вне репозитория, путь к папке канона MUST передаваться командам явно, без значения по умолчанию. Индекс MUST строиться только из канона; книга, которой нет в каноне, MUST NOT появляться в индексе.

#### Scenario: Путь к канону не задан
- GIVEN команда загрузки запущена без папки канона
- WHEN она стартует
- THEN она MUST завершиться с ошибкой, называющей отсутствующий аргумент, и MUST NOT читать какую-либо папку по умолчанию

#### Scenario: Черновики не загружаются
- GIVEN в папке канона лежат файлы книг и вложенная папка черновиков
- WHEN выполняется загрузка
- THEN MUST загружаться только файлы `*.md` верхнего уровня папки канона

### Requirement: Метаданные книги
Шапка канона MUST содержать название, автора (одного или нескольких) и язык текста (`ru` или `en`). Год первого издания оригинала, год издания экземпляра, переводчик, год перевода и название оригинала MAY отсутствовать: книга без них MUST загружаться, а отсутствующее поле MUST NOT заменяться выдуманным значением. Номеров страниц в каноне MUST NOT быть.

#### Scenario: Перевод без переводчика
- GIVEN канон «Поэтики» на русском с названием оригинала, но без переводчика
- WHEN выполняется загрузка
- THEN книга MUST загрузиться, а её поле переводчика MUST остаться пустым

#### Scenario: Нет обязательного поля
- GIVEN канон без автора
- WHEN выполняется проверка или загрузка
- THEN команда MUST завершиться с ошибкой, называющей файл и поле `authors`, и книга MUST NOT попасть в индекс

#### Scenario: Неизвестный язык
- GIVEN канон с языком `de`
- WHEN выполняется проверка
- THEN команда MUST завершиться с ошибкой, называющей файл и допустимые языки

### Requirement: Структура и содержание тела канона
Тело канона MUST быть простым текстом с заголовками Markdown по структуре книги (том, часть, глава, раздел — сколько уровней есть в книге). Схемы MUST храниться блоками Mermaid на месте схемы, иллюстрации со смыслом — строкой `[Иллюстрация: описание]`. Ссылки на файлы картинок MUST NOT присутствовать: канон с ними MUST отклоняться проверкой.

#### Scenario: Картинка в каноне
- GIVEN в теле канона осталась строка `![](images/fig1.png)`
- WHEN выполняется проверка
- THEN команда MUST завершиться с ошибкой, называющей файл и раздел, где осталась картинка

#### Scenario: Пустое описание иллюстрации
- GIVEN в теле канона есть строка `[Иллюстрация: ]`
- WHEN выполняется проверка
- THEN команда MUST завершиться с ошибкой, называющей файл и раздел

### Requirement: Подготовка черновика из файла книги
Команда подготовки MUST превращать файл книги в черновик канона в папке черновиков. Поддерживаемые форматы: EPUB, FB2, DOCX, RTF, ODT, HTML, TXT, Markdown, MOBI, AZW3, PDF и DjVu с текстовым слоем. Перед разбором файл MUST проверяться антивирусом. Найденные в файле метаданные MUST попадать в шапку черновика, картинки — заменяться заготовкой `[Иллюстрация: ]`.

#### Scenario: EPUB с метаданными
- GIVEN файл `Aristotel_._PoyetikaI.epub` с названием и автором в метаданных
- WHEN выполняется подготовка
- THEN в папке черновиков MUST появиться Markdown с этими названием и автором в шапке и с главами книги заголовками

#### Scenario: Неподдерживаемый формат
- GIVEN файл `book.cbz`
- WHEN выполняется подготовка
- THEN команда MUST завершиться с ошибкой, называющей файл и поддерживаемые форматы, и черновик MUST NOT появиться

#### Scenario: Скан без текста
- GIVEN PDF из сканов страниц без текстового слоя
- WHEN выполняется подготовка
- THEN команда MUST завершиться с ошибкой о том, что в файле нет текста, и черновик MUST NOT появиться

#### Scenario: Нет программы разбора
- GIVEN файл MOBI, а программа calibre не установлена
- WHEN выполняется подготовка
- THEN команда MUST завершиться с ошибкой, называющей недостающую программу

#### Scenario: Заражённый файл
- GIVEN антивирус находит в файле книги угрозу
- WHEN выполняется подготовка
- THEN команда MUST завершиться с ошибкой, называющей файл, и MUST NOT разбирать его

### Requirement: Куски книги
Загрузка MUST делить тело книги на куски не длиннее 1 200 знаков. Кусок MUST NOT пересекать границу самого мелкого раздела; блок Mermaid MUST целиком лежать в одном куске. У каждого куска MUST храниться путь заголовков от верхнего уровня до его раздела и его порядковый номер в книге.

#### Scenario: Граница главы
- GIVEN глава 4 заканчивается абзацем в 300 знаков, а глава 5 начинается абзацем в 300 знаков
- WHEN книга загружается
- THEN эти абзацы MUST оказаться в разных кусках с путями «… → Глава 4» и «… → Глава 5»

#### Scenario: Длинная схема
- GIVEN блок Mermaid длиннее 1 200 знаков
- WHEN выполняется проверка канона
- THEN команда MUST завершиться с ошибкой, называющей файл и раздел схемы

### Requirement: Загрузка и замена книги
Загрузка MUST записывать книгу и все её куски с векторами одной транзакцией. Повторная загрузка той же книги (того же имени файла) MUST заменять её прежние куски, а не добавлять к ним. Если расчёт векторов или запись не удались, MUST остаться прежнее состояние книги. Каждая книга MUST помнить модель эмбеддингов, которой посчитаны её векторы.

#### Scenario: Повторная загрузка
- GIVEN книга «Impro» загружена, и в каноне исправлен один абзац
- WHEN выполняется загрузка
- THEN в индексе MUST быть одна книга «Impro» с кусками нового текста и без кусков старого

#### Scenario: Модель эмбеддингов недоступна
- GIVEN модель эмбеддингов отвечает ошибкой
- WHEN выполняется загрузка книги
- THEN команда MUST завершиться с ошибкой, а прежние куски книги MUST остаться в индексе без изменений

### Requirement: Удаление книги
Команда удаления MUST убирать книгу и все её куски из индекса одним действием по имени файла канона. Удаление несуществующей книги MUST завершаться ошибкой.

#### Scenario: Удаление по претензии
- GIVEN книга «Narrative Discourse» загружена
- WHEN владелец удаляет её командой
- THEN поиск MUST NOT возвращать её куски, а список книг MUST NOT её содержать

### Requirement: Поиск по библиотеке
Поиск MUST находить куски по смыслу запроса и по его словам, сводя оба результата в один список не длиннее заданного. Поиск по словам MUST учитывать язык каждой книги. Каждый найденный кусок MUST идти с метаданными книги и путём в структуре. Сбой поиска MUST быть ошибкой, а не пустым результатом.

#### Scenario: Русский вопрос, английская книга
- GIVEN загружены «Impro» на английском и «Поэтика» на русском
- WHEN выполняется поиск «как статус персонажа меняется в сцене»
- THEN среди найденного MUST быть кусок «Impro» о статусе

#### Scenario: Сбой эмбеддингов при поиске
- GIVEN модель эмбеддингов недоступна
- WHEN выполняется поиск
- THEN поиск MUST завершиться ошибкой, а не пустым списком

#### Scenario: Векторы другой модели
- GIVEN книга загружена с моделью `gigachat-embeddings`, а сейчас `EMBEDDINGS_MODEL` равен `giga-embeddings`
- WHEN выполняется поиск
- THEN поиск MUST завершиться ошибкой, называющей книгу и требующей её перезагрузить

### Requirement: Проверка цитаты
Цитата из библиотеки MUST проверяться кодом: её текст MUST дословно содержаться в указанном куске (с точностью до пробелов и переносов строк) и MUST быть не длиннее 300 знаков. Проверенная цитата MUST возвращаться вместе со ссылкой: автор, название, переводчик и год издания, если известны, путь в структуре книги.

#### Scenario: Цитаты нет в книге
- GIVEN кусок «Поэтики» без фразы «герой должен страдать»
- WHEN проверяется цитата «герой должен страдать» по этому куску
- THEN проверка MUST вернуть отказ «цитаты нет в источнике»

#### Scenario: Длинная цитата
- GIVEN фрагмент куска длиной 450 знаков
- WHEN он проверяется как цитата
- THEN проверка MUST вернуть отказ, называющий предел в 300 знаков

#### Scenario: Ссылка без переводчика
- GIVEN цитата из переводной книги без переводчика в каноне
- WHEN цитата проверена
- THEN ссылка MUST содержать автора, название и место в книге и MUST NOT содержать слов о переводчике

### Requirement: Закрытость полного текста
Полный текст книг MUST быть доступен только коду приложения: инструментам агентов и командам владельца. Библиотека MUST NOT регистрироваться как база знаний AgentOS и MUST NOT читаться через маршруты `/knowledge/*`, MCP, Studio и свои маршруты `/api/v1/`. Тексты книг и запросов MUST NOT попадать в логи и журнал запусков.

#### Scenario: Конфигурация AgentOS
- GIVEN библиотека загружена
- WHEN клиент выполняет `GET /config`
- THEN `knowledge.knowledge_instances` MUST NOT содержать библиотеку источников

### Requirement: Команды владельца
Подготовка, проверка, загрузка, удаление и список книг MUST быть командами без интерфейса. Локально они MUST работать на хосте с базой checkout'а, а на сервере — в контейнере API с папкой канона `/srv/authorled/sources`, подключённой только для чтения. Локально и на сервере загрузка MUST быть одной и той же командой над всей папкой канона.

#### Scenario: Список книг
- GIVEN загружены пять книг
- WHEN владелец выполняет команду списка
- THEN она MUST вывести для каждой книги имя файла, название, автора, язык, число кусков, модель эмбеддингов и время загрузки

#### Scenario: Загрузка на сервере
- GIVEN канон скопирован в `/srv/authorled/sources` на сервере
- WHEN владелец выполняет загрузку на сервере
- THEN книги MUST загрузиться в базу сервера, а контейнер MUST NOT иметь права записи в папку канона
