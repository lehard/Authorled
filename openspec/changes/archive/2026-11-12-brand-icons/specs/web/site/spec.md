# Spec Delta

## MODIFIED Requirements

### Requirement: Вид сайта
Сайт MUST использовать токены, шрифты и тему «Утро» (`data-theme="light"`) из `web/src/design-system` без их копирования. Цвета в коде сайта MUST задаваться только семантическими токенами: проверка сырых цветов MUST охватывать `site/` так же, как `web/`. Знак продукта в шапке MUST быть изображением из файла знака (спека `web/brand`) с его фиксированными цветами, а не буквой на цветном круге.

#### Scenario: Сырой цвет на сайте
- GIVEN в файле `site/src` есть класс `bg-blue-500` или значение `#1a1a1a`
- WHEN выполняется `./scripts/validate.sh`
- THEN проверка MUST завершиться ошибкой с путём файла

#### Scenario: Знак в шапке сайта
- GIVEN открыта любая страница сайта
- WHEN читается шапка
- THEN перед названием «Соавтор» MUST стоять изображение знака из `/brand-mark.svg`
