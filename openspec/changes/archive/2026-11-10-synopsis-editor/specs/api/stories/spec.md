# Spec Delta

## ADDED Requirements

### Requirement: Разметка синопсиса
Поле `synopsis` сценария MUST быть текстом Markdown редактора прозы (спека `web/prose-editor`). Строка, которая начинается с трёх и более `#` и пробела (заголовок глубже второго уровня), MUST давать `422` с именем поля `synopsis` и причиной «заголовки глубже второго уровня не поддерживаются»; поле MUST NOT меняться. Остальной текст ядро MUST принимать как есть. Одинаково MUST отказывать маршрут документа и инструмент соавтора.

#### Scenario: Заголовок третьего уровня
- GIVEN синопсис драфта «Вера молчит.»
- WHEN клиент сохраняет `synopsis` с текстом «### Сцена 1\n\nВера молчит.»
- THEN ответ MUST быть `422` с полем `synopsis`, а синопсис MUST остаться «Вера молчит.»

#### Scenario: Заголовки первого и второго уровня
- WHEN клиент сохраняет `synopsis` с текстом «# Акт 1\n\n## Завязка\n\n**Вера** молчит.»
- THEN синопсис MUST сохраниться этим текстом

#### Scenario: Экранированная решётка
- WHEN клиент сохраняет `synopsis` с текстом «\\### не заголовок»
- THEN синопсис MUST сохраниться этим текстом

### Requirement: Синопсис в поиске без разметки
Поиск по драфту MUST искать совпадение в синопсисе по его тексту без знаков разметки Markdown (знаки заголовков, жирного, курсива и экранирования), и `snippet` результата синопсиса MUST быть из этого текста. Логлайн и остальные поля MUST искаться как написаны.

#### Scenario: Совпадение через выделение
- GIVEN в синопсисе «Тримиру снится **вещий** сон»
- WHEN автор ищет «вещий сон»
- THEN в `documents` MUST быть результат с `field` `synopsis`, `match` MUST быть «вещий сон», а `before` MUST заканчиваться на «снится »

#### Scenario: Знаки разметки не находятся
- GIVEN в синопсисе «# Акт 1» и нигде больше нет «#»
- WHEN автор ищет «# а»
- THEN результата синопсиса MUST NOT быть
