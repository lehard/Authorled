# Proposal: пропущенное при импорте STARC — диалогом, а не плашкой

## Why

После импорта облачного проекта STARC список пропущенного показывается плавающей плашкой внизу экрана. На сервере после v0.3.24 владелец её почти не заметил: плашка сливается с листом сценария, а внутри сплошной текст — имена в строку через запятую и причина тем же блоком (`business-intents/starc-skipped-dialog.md`, решение владельца 2026-11-12). Автор должен увидеть, что часть проекта не перенеслась, и подтвердить это.

## What Changes

- Плашку заменяет диалог по центру с затемнением экрана, в том же виде, что подтверждение «Заменить текст сценария?».
- Заголовок «Часть проекта не перенеслась»; строка «Текст сценария импортирован. В файле STARC не было:».
- Группы с числом («Сценарии (9)», «Персонажи (N)», «Локации (1)»), имена в столбик; длинный список прокручивается внутри окна.
- Отдельный абзац с причиной и тем, что делать.
- Одна кнопка «Понятно»; закрывают её и Esc, клик мимо окна — нет.
- Когда показывается — без изменений: после создания истории из файла и после импорта в редакторе; не сохраняется.

(нет)

### Modified Capabilities

- `web/workspace`: «Предупреждение о пропущенном при импорте» — диалог с затемнением, группы с числом, имена в столбик, кнопка «Понятно».

## Scope

- `web/src/screens/project/docs/ImportSkipped.tsx` (диалог вместо плашки) и его подключение в `TextDoc.tsx`.
- Дельта спеки `web/workspace`.

## Non-goals

- Название импортированного сценария в диалоге и в ответе API.
- Изменения ядра и API импорта.
- Обновление открытой вкладки после релиза.

## Impact

- Только фронтенд; ответ API и данные не меняются.
- Справка соавтора (`agno/skills/coauthor/SKILL.md`) говорит «показывает список пропущенного» и остаётся верной.
