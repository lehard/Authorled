# Spec Delta

## Purpose

Рецензирование текста сценария через `/api/v1`: ветки комментариев к фрагментам и предложения правок соавтора. Место в тексте хранится меткой в самом тексте, ветки и предложения — в ядре отдельно от текста.

## ADDED Requirements

### Requirement: Ветка комментария
`POST /api/v1/documents/{id}/comments` MUST создавать ветку к фрагменту текста сценария: `id` (совпадает с id метки `comment` в тексте), `quote` (цитата фрагмента) и непустой текст первого сообщения. Автор сообщения — вызывающий, `author_role` — его роль на момент записи. Повторный `id` в истории MUST давать `409`; пустой текст — `422`. Драфт MUST NOT принимать комментарии: `409`.

#### Scenario: Новая ветка
- WHEN автор создаёт ветку `c1` с цитатой «Вера смотрит на воду» и текстом «Слишком прямо»
- THEN `GET /api/v1/documents/{id}/comments` MUST вернуть ветку `c1` с одним сообщением автора

#### Scenario: Пустой комментарий
- WHEN автор создаёт ветку с пустым текстом
- THEN ответ MUST быть `422`, ветка MUST NOT создаваться

### Requirement: Список комментариев
`GET /api/v1/documents/{id}/comments` MUST возвращать все ветки документа: `id`, `quote`, `resolved_at`, сообщения по времени (`id`, автор, `author_role`, `body`, `created_at`, `edited_at`) и признак, что сообщение принадлежит вызывающему.

#### Scenario: Свои сообщения
- WHEN в ветке есть сообщения автора
- THEN у них MUST быть признак собственного сообщения

### Requirement: Ответы и правка сообщений
`POST /api/v1/comments/{id}/replies` MUST добавлять непустой ответ в ветку. `PATCH` и `DELETE` `/api/v1/comments/{id}/messages/{message_id}` MUST менять и удалять только собственное сообщение (`edited_at` заполняется); чужое — `403`. Удаление первого сообщения MUST удалять ветку целиком.

#### Scenario: Правка чужого
- WHEN пользователь пытается изменить сообщение другого пользователя
- THEN ответ MUST быть `403`, сообщение MUST NOT меняться

#### Scenario: Удаление первого сообщения
- WHEN автор удаляет первое сообщение ветки с двумя ответами
- THEN ветки MUST NOT остаться в списке

### Requirement: Решённые комментарии
`PATCH /api/v1/comments/{id}` с `resolved` `true` MUST отмечать ветку решённой (`resolved_at`, `resolved_by`), с `false` — возвращать в открытые.

#### Scenario: Вернуть в открытые
- WHEN автор отмечает ветку решённой, затем возвращает её
- THEN `resolved_at` MUST быть пустым

### Requirement: Предложение соавтора
Предложение MUST хранить: `id` (будущий id метки `suggestion`), документ — текст сценария, якорь (`scene_uid` и точная цитата `quote`), предлагаемый текст, «зачем», `status` `open`, беседу Agno, из которой пришло, и время. Создаёт предложения только соавтор инструментом ядра; маршрута создания для клиента MUST NOT быть. Сохранённый текст сценария при создании предложения MUST NOT меняться.

#### Scenario: Текст не меняется
- WHEN соавтор создаёт предложение к сцене с `uid` `s3`
- THEN ревизия и содержимое текста сценария MUST остаться прежними

### Requirement: Список предложений
`GET /api/v1/documents/{id}/suggestions` MUST возвращать предложения документа (`id`, `scene_uid`, `quote`, `text`, `why`, `status`, `session_id`, `created_at`, `decided_at`), по времени создания; `status=open|accepted|rejected` MUST фильтровать по статусу, неизвестный статус — `422`.

#### Scenario: Только открытые
- WHEN у текста одно открытое и одно отклонённое предложение
- THEN `GET …/suggestions?status=open` MUST вернуть только открытое

### Requirement: Решение по предложению
`PATCH /api/v1/suggestions/{id}` с `status` `accepted` или `rejected` MUST фиксировать решение автора и `decided_at`. Решённое предложение MUST NOT меняться повторно: `409`. Текст сценария этот маршрут MUST NOT менять: принятая правка сохраняется клиентом через `PUT …/text`.

#### Scenario: Повторное решение
- WHEN автор отклоняет уже принятое предложение
- THEN ответ MUST быть `409`

### Requirement: Удаление вместе с документом
При удалении навсегда документа или истории MUST удаляться их ветки комментариев, сообщения и предложения.

#### Scenario: Удаление истории
- WHEN история с комментариями и предложениями удалена навсегда
- THEN в базе MUST NOT остаться её веток, сообщений и предложений
