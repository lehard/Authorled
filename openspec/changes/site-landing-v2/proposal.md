# Proposal: вторая версия лендинга «Соавтора» — движение, интерактив, видение

Источник решений: `business-intents/site-landing-v2.md` (согласовано владельцем 2026-11-08). Первая версия — архив `openspec/changes/archive/2026-11-08-product-site/`.

## Why

Первая версия сайта честная, но слабая: перечень возможностей и неподвижные скриншоты. Она не показывает принцип «ИИ предлагает, автор решает» в действии и не передаёт видение продукта — путь из 22 этапов от замысла до финального текста, для которого уже есть кликабельный макет «Кабинет». Сайт должен увлекать и давать продукт потрогать до регистрации.

## What Changes

- **Новый порядок главной:** первый экран с живой правкой → крупная фраза о видении → песочница «Спросите соавтора» → что есть в бете (вкладки) → «Путь истории» из 22 шагов с кадрами концепта → схема последствий изменения решения → вопросы и ответы → форма заявки → подвал.
- **Первый экран:** заголовок проявляется с зачёркиванием «пишет за вас»; на листе сценария всплывает предложение соавтора, посетитель жмёт «Принять» или «Отклонить» — реплика меняется на странице.
- **Крупная фраза:** слова загораются по одному при прокрутке.
- **Песочница:** фрагмент сцены «Тихой воды» и три вопроса; заготовленный ответ печатается в чате с подписью «пример ответа»; запросов к API нет.
- **Бета вкладками:** «Сценарий», «Карточки», «Драфты», «Рецензирование», «Соавтор» переключают настоящие скриншоты беты.
- **«Путь истории»:** линия из 22 этапов прорисовывается при прокрутке; выбор этапа показывает кадр концепта «Кабинет»; пометка «Концепт: в бете этого пока нет».
- **Схема последствий:** интерактивная схема «Задето 3 документа из 7» по экрану `impact` макета, с пометкой «Концепт».
- **Вопросы и ответы** раскрывающимся списком; после отправки формы — короткая анимация подтверждения.
- **Новые тексты** по скиллам `copywriting` и `chukovsky`; заголовок первого экрана выбирает владелец из двух-трёх вариантов.
- **Правила движения:** запуск при появлении блока на экране, пауза вне экрана, без движения при `prefers-reduced-motion`; бюджет скриптов главной.
- **Скиллы:** `design-to-motion`, `stageshow`, `chukovsky` копируются из glavai в `.agents/skills/` с заметками про этот проект.
- **Кадры концепта** из glavai (`authorled-concept-*.webp`) — в `site/public/`.

## Capabilities

### New Capabilities
(нет)

### Modified Capabilities
- `web/site`: меняются «Главная страница» (порядок блоков) и «Правда на главной» (концепт и примеры ответов); добавляются требования к живой правке, крупной фразе, песочнице, вкладкам беты, «Пути истории», схеме последствий, вопросам и ответам, движению и бюджету скриптов.

## Scope

- `site/src/`: новые блоки и их компоненты, движение, тексты; `site/public/`: кадры концепта; `site/scripts/check-build.mjs`: проверки новых блоков и бюджета скриптов.
- `.agents/skills/`: `design-to-motion`, `stageshow`, `chukovsky`.
- `AGENTS.md`: строка про скиллы сайта.
- Мастер-спека `web/site` через дельту.

## Non-goals

- Настоящий вызов модели в песочнице, вход и регистрация на сайте.
- Выкладка сайта, домен, Caddy, Метрика.
- Видео и GIF анимаций (часть C `design-to-motion`).
- Перенос кода макета «Кабинет» целиком: только кадры и переписанные на токены сайта куски.
- Изменения `web/`, маршрута заявки, ядра, политики и страницы 404.
- Новые npm-зависимости (анимация, иконки) без отдельного согласия владельца.

## Impact

- **Код:** только `site/` и скиллы; API, база и сервис не меняются.
- **Размер:** главная получает больше разметки и кадров; скрипты главной ограничены бюджетом 120 КБ gzip (сейчас около 77 КБ — React и форма), кадры — WebP трёх ширин с ленивой загрузкой.
- **Правда на сайте:** всё будущее помечено «Концепт», заготовленные ответы — «пример ответа».
- **Процесс:** тексты на сайте по-прежнему меняются без OpenSpec; новые блоки — этим изменением.
