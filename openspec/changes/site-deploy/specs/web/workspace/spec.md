## MODIFIED Requirements

### Requirement: Обязательные настройки
Приложение MUST получать адрес Authentik (`AUTH_ISSUER`), клиента (`AUTH_FRONTEND_CLIENT_ID`), адрес возврата (`AUTH_FRONTEND_REDIRECT_URI`), источник данных (`VITE_DATA_SOURCE`) и адрес сайта продукта (`SITE_ORIGIN`, абсолютный адрес `http(s)`). Если любая настройка отсутствует или неверна, приложение MUST показать экран ошибки с именем настройки и MUST NOT подставлять значение по умолчанию. Если приложение открыто не с того адреса, что указан в `AUTH_FRONTEND_REDIRECT_URI` (схема, хост, порт), MUST показываться ошибка с правильным адресом.

#### Scenario: Нет настройки входа
- GIVEN `AUTH_ISSUER` не задан
- WHEN приложение открыто
- THEN MUST показываться ошибка, называющая `AUTH_ISSUER`

#### Scenario: Нет адреса сайта
- GIVEN `SITE_ORIGIN` не задан или не является абсолютным адресом `http(s)`
- WHEN приложение открыто
- THEN MUST показываться ошибка, называющая `SITE_ORIGIN`

#### Scenario: Чужой адрес
- GIVEN `AUTH_FRONTEND_REDIRECT_URI` равен `http://localhost:5173/auth/callback`
- WHEN приложение открыто по адресу `http://127.0.0.1:5173/`
- THEN MUST показываться ошибка с адресом `http://localhost:5173`

## ADDED Requirements

### Requirement: Ссылка на сайт с экрана входа
Экран входа `/login` MUST показывать на каждом шаге ссылку «О продукте», ведущую на `SITE_ORIGIN` в той же вкладке. Ссылка MUST работать с клавиатуры и MUST NOT мешать вводу почты и кода. После выхода из приложения человек MUST попадать на экран входа, как прежде, и с него — на сайт.

#### Scenario: Переход на сайт после выхода
- GIVEN приложение собрано с `SITE_ORIGIN=https://soavtor.app` и пользователь нажал «Выйти»
- WHEN открывается экран входа и человек нажимает «О продукте»
- THEN браузер MUST открыть `https://soavtor.app/`

#### Scenario: Ссылка на шаге кода
- GIVEN человек ввёл почту и видит шаг кода из письма
- WHEN он смотрит на экран входа
- THEN ссылка «О продукте» MUST быть на экране
