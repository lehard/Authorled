# Spec Delta

## ADDED Requirements

### Requirement: Отказ в регистрации по приглашению
Если поток регистрации отказал почте не из списка, экран входа MUST показать сообщение «Регистрация сейчас доступна только по приглашению.» и MUST NOT переходить к вводу кода. Пользователь MUST иметь возможность вернуться к вводу другой почты.

#### Scenario: Почта не из списка
- GIVEN почта `stranger@authorled.test` не разрешена
- WHEN пользователь выбирает «Создать аккаунт» и вводит имя
- THEN экран MUST показать «Регистрация сейчас доступна только по приглашению.»
- AND шаг «Подтвердите почту» MUST NOT открыться
