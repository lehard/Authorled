## ADDED Requirements

### Requirement: Название продукта
Интерфейс MUST называть продукт «Соавтор»: заголовок документа приложения, экран входа и шапка полки. Строки интерфейса, видимые людям, MUST NOT содержать слов Authorled и CoAuthor. Технические имена, которых человек не видит (ключи хранилища браузера, адреса потоков входа, типы перетаскивания), этим требованием не затрагиваются.

#### Scenario: Вкладка браузера
- GIVEN приложение открыто в браузере
- WHEN читается `document.title`
- THEN значение MUST быть «Соавтор»

#### Scenario: Экран входа
- GIVEN пользователь не вошёл
- WHEN он открывает `/login`
- THEN над карточкой MUST стоять название «Соавтор», а заголовок шага почты MUST быть «Вход в Соавтор»

#### Scenario: Шапка полки
- GIVEN пользователь вошёл
- WHEN открыта полка
- THEN в шапке MUST стоять название «Соавтор»

#### Scenario: Старых названий нет
- GIVEN собранное приложение `web/dist/`
- WHEN в нём ищутся строки «Authorled» и «CoAuthor» без учёта технических имён в нижнем регистре
- THEN совпадений MUST NOT быть
