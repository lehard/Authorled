### Пробелы по решениям владельца
- В `agno/core/plans.toml` нет платных тарифов (задача 2.2 открыта): страница «Тариф» говорит, что они не продаются.
- `TOCHKA_TAX_SYSTEM`, `TOCHKA_VAT_TYPE`, `TOCHKA_PAYMENT_METHOD` обязательны и без значений по умолчанию. В
  `example.env` у них `***`, поэтому API не стартует, пока их не заполнят. Настоящие значения выбирает владелец
  с бухгалтером.
- `.env` основного checkout и `/etc/authorled/authorled.env` на сервере ещё без `TOCHKA_*`. После вливания этой ветки
  API без них не стартует. Сервер я не трогал.

### Не проверено без настоящей Точки (условие начала продаж)
- Оплата по ссылке на странице Точки, возврат на `/settings/billing/return`, чек на почте.
- Регистрация вебхука (`PUT /webhook/v1.0/{client_id}`) и подпись боевых уведомлений ключом из репозитория.
- Поля операции после оплаты подписки: `Order` типа `approval`, `paymentLinkId`, `paidAt`. В тестовой среде у
  заготовки `Order` пуст: без `approval` ядро платёж не засчитает и запишет причину в лог.
- Очередное ежемесячное списание: новая операция или новый `Order` (поддержаны оба), приходит ли вебхук.
- Отмена подписки (`POST .../status`): в тестовой среде она не реализована.
- Статусы подписки после неудачного списания (`PastDue` и другие).
